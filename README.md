# Make Computer

MAKECOMPUTER/8 — 외부 MCU 없이 동작하는 8비트 브레드보드 컴퓨터 제작 프로젝트입니다.

## 최종 제작 문서

- [컴퓨터만들기.md](./컴퓨터만들기.md) — 최종 구조, 메모리 맵, 모든 IC 핀 배선, 점퍼선 색상 규칙

## 점퍼선 색상

- 빨강: POWER +5V
- 검정: GND
- 초록: DATA
- 노랑: ADDRESS
- 파랑: CLOCK / RESET
- 주황: CONTROL
- 흰색: STATUS / FLAG / SPECIAL
