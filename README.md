## 현재 주요 부품 현황

- CDP1824CE RAM: **5개 확보 / 5개 모두 사용**
- 기본 RAM 구성: **5 × 32 byte = 160 byte**
- 실제 RAM 주소: **0~159**
- 상위 주소 `A7~A5`는 74HC138 RAM Bank Decoder로 해석
- 주소 `160~255`는 현재 비어 있으며 이후 Memory-Mapped I/O/확장 기능에 사용할 수 있음

부품 수량과 설계가 변경되면 `기본설명.md`, `부품목록.md`, `명령어.md`를 함께 갱신합니다.
