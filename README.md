## 배선 기준

점퍼선의 색은 회로의 기능을 결정하지 않습니다.

배선을 확인할 때는 다음 네 가지를 기준으로 확인합니다.

1. 출발 IC
2. 출발 핀 번호
3. 도착 IC
4. 도착 핀 번호와 신호 역할

같은 전기적 연결이라면 어떤 색의 점퍼선을 사용해도 됩니다.
