## 현재 주요 부품 현황

- CDP1824CE RAM: **5개 확보**
- 기본 RAM 구성: **3개 사용 = 96 byte**
- 남는 RAM: **2개 예비/확장 실험용**

부품 수량과 설계가 변경되면 `부품목록.md`를 함께 갱신합니다.
