# 4단계 — A 레지스터와 ALU

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호**로 설명한다.

이번 순서:

```text
74HC273 A 레지스터
↓
74HC86 XOR 하위/상위
↓
74HC283 ALU 하위/상위
↓
74HC157 A/ALU 선택 MUX
↓
74HC245 A/ALU 데이터 버스 드라이버
```

---

# 4-1. A 레지스터가 뭔가

A 레지스터는 CPU가 계산에 사용할 8비트 값을 저장하는 곳이다.

예:

```text
LDA 100  → A에 RAM[100] 저장
ADD 101  → A = A + RAM[101]
SUB 102  → A = A - RAM[102]
```

## 74HC273 A 레지스터 연결

1. 1번 `/CLR` → Reset 선. 지금은 +5V에 두고 테스트할 때만 잠깐 GND
2. 2번 Q0 → 나중에 ALU A0 입력
3. 3번 D0 ← DB0
4. 4번 D1 ← DB1
5. 5번 Q1 → 나중에 ALU A1 입력
6. 6번 Q2 → 나중에 ALU A2 입력
7. 7번 D2 ← DB2
8. 8번 D3 ← DB3
9. 9번 Q3 → 나중에 ALU A3 입력
10. 10번 → GND
11. 11번 CLK → 지금은 수동 Clock 테스트선
12. 12번 Q4 → 나중에 ALU A4 입력
13. 13번 D4 ← DB4
14. 14번 D5 ← DB5
15. 15번 Q5 → 나중에 ALU A5 입력
16. 16번 Q6 → 나중에 ALU A6 입력
17. 17번 D6 ← DB6
18. 18번 D7 ← DB7
19. 19번 Q7 → 나중에 ALU A7 입력
20. 20번 → +5V

20번과 10번 가까이에 0.1µF 커패시터를 단다.

## A 레지스터 테스트

1. 74HC245 수동 입력 버스 드라이버로 DATA BUS에 `00110101`을 만든다.
2. A 레지스터 11번에 LOW→HIGH Clock 한 번을 준다.
3. Q0~Q7이 `00110101`인지 확인한다.
4. DATA BUS를 `11110000`으로 바꾼다.
5. Clock을 주지 않았을 때 A 값이 그대로인지 확인한다.
6. Clock 한 번을 주면 A가 `11110000`으로 바뀌는지 확인한다.

# 4-2. ALU가 뭔가

ALU는 계산하는 부분이다.

이 컴퓨터는 74HC283 두 개로 8비트 덧셈을 만들고, 74HC86 두 개를 이용해서 뺄셈도 같은 가산기로 처리한다.

뺄셈 원리:

```text
A - B = A + NOT(B) + 1
```

그래서 SUB_MODE=LOW면 더하기, SUB_MODE=HIGH면 빼기다.

---

# 4-3. 74HC86 ALU 하위 XOR 칩

1. 1번 ← RAM_D0
2. 2번 ← SUB_MODE 테스트 점퍼
3. 3번 → 74HC283 ALU 하위 가산기 6번(B0)
4. 4번 ← RAM_D1
5. 5번 ← SUB_MODE
6. 6번 → ALU 하위 가산기 2번(B1)
7. 7번 → GND
8. 8번 → ALU 하위 가산기 15번(B2)
9. 9번 ← RAM_D2
10. 10번 ← SUB_MODE
11. 11번 → ALU 하위 가산기 11번(B3)
12. 12번 ← RAM_D3
13. 13번 ← SUB_MODE
14. 14번 → +5V

# 4-4. 74HC86 ALU 상위 XOR 칩

1. 1번 ← RAM_D4
2. 2번 ← SUB_MODE
3. 3번 → 74HC283 ALU 상위 가산기 6번(B4 입력 자리)
4. 4번 ← RAM_D5
5. 5번 ← SUB_MODE
6. 6번 → ALU 상위 가산기 2번
7. 7번 → GND
8. 8번 → ALU 상위 가산기 15번
9. 9번 ← RAM_D6
10. 10번 ← SUB_MODE
11. 11번 → ALU 상위 가산기 11번
12. 12번 ← RAM_D7
13. 13번 ← SUB_MODE
14. 14번 → +5V

---

# 4-5. 74HC283 ALU 하위 4비트 가산기

1. 1번 S1 = ALU1
2. 2번 B1 ← 74HC86 하위 XOR 칩 6번
3. 3번 A1 ← 74HC273 A 레지스터 5번 Q1
4. 4번 S0 = ALU0
5. 5번 A0 ← A 레지스터 2번 Q0
6. 6번 B0 ← 하위 XOR 칩 3번
7. 7번 CIN ← SUB_MODE 테스트 점퍼
8. 8번 → GND
9. 9번 COUT → 74HC283 ALU 상위 가산기 7번 CIN
10. 10번 S3 = ALU3
11. 11번 B3 ← 하위 XOR 칩 11번
12. 12번 A3 ← A 레지스터 9번 Q3
13. 13번 S2 = ALU2
14. 14번 A2 ← A 레지스터 6번 Q2
15. 15번 B2 ← 하위 XOR 칩 8번
16. 16번 → +5V

# 4-6. 74HC283 ALU 상위 4비트 가산기

1. 1번 S1 = ALU5
2. 2번 B1 ← 74HC86 상위 XOR 칩 6번
3. 3번 A1 ← A 레지스터 15번 Q5
4. 4번 S0 = ALU4
5. 5번 A0 ← A 레지스터 12번 Q4
6. 6번 B0 ← 상위 XOR 칩 3번
7. 7번 CIN ← ALU 하위 가산기 9번 COUT
8. 8번 → GND
9. 9번 COUT → 지금은 연결하지 않음
10. 10번 S3 = ALU7
11. 11번 B3 ← 상위 XOR 칩 11번
12. 12번 A3 ← A 레지스터 19번 Q7
13. 13번 S2 = ALU6
14. 14번 A2 ← A 레지스터 16번 Q6
15. 15번 B2 ← 상위 XOR 칩 8번
16. 16번 → +5V

---

# 4-7. ALU 직접 테스트

## 덧셈

1. A 레지스터에 5를 저장한다. `00000101`
2. RAM_D0~RAM_D7에 3을 만든다. `00000011`
3. SUB_MODE를 LOW로 둔다.
4. ALU0~ALU7 출력이 `00001000` = 8인지 확인한다.

## 뺄셈

1. A=5 유지
2. RAM_D=3 유지
3. SUB_MODE를 HIGH로 둔다.
4. ALU 결과가 `00000010` = 2인지 확인한다.

이 두 테스트가 모두 되어야 다음으로 간다.

# 4-8. A 값과 ALU 결과 중 하나를 고르는 MUX

CPU가 DATA BUS로 내보낼 값은 두 종류다.

- 저장된 A 값
- 계산된 ALU 결과

74HC157 두 개가 둘 중 하나를 고른다.

## 74HC157 A/ALU 선택 MUX 하위칩

1. 1번 S → 테스트용 Select 점퍼
2. 2번 1A ← A 레지스터 2번 Q0
3. 3번 1B ← ALU 하위 가산기 4번 ALU0
4. 4번 1Y → 74HC245 A/ALU 버스 드라이버 2번
5. 5번 2A ← A 레지스터 5번 Q1
6. 6번 2B ← ALU 하위 가산기 1번 ALU1
7. 7번 2Y → 버스 드라이버 3번
8. 8번 → GND
9. 9번 3Y → 버스 드라이버 4번
10. 10번 3B ← ALU 하위 가산기 13번 ALU2
11. 11번 3A ← A 레지스터 6번 Q2
12. 12번 4Y → 버스 드라이버 5번
13. 13번 4B ← ALU 하위 가산기 10번 ALU3
14. 14번 4A ← A 레지스터 9번 Q3
15. 15번 `/G` → GND
16. 16번 → +5V

## 74HC157 A/ALU 선택 MUX 상위칩

1. 1번 S → 하위 선택 MUX 1번 S와 같이 연결
2. 2번 1A ← A 레지스터 12번 Q4
3. 3번 1B ← ALU 상위 가산기 4번 ALU4
4. 4번 1Y → 74HC245 A/ALU 버스 드라이버 6번
5. 5번 2A ← A 레지스터 15번 Q5
6. 6번 2B ← ALU 상위 가산기 1번 ALU5
7. 7번 2Y → 버스 드라이버 7번
8. 8번 → GND
9. 9번 3Y → 버스 드라이버 8번
10. 10번 3B ← ALU 상위 가산기 13번 ALU6
11. 11번 3A ← A 레지스터 16번 Q6
12. 12번 4Y → 버스 드라이버 9번
13. 13번 4B ← ALU 상위 가산기 10번 ALU7
14. 14번 4A ← A 레지스터 19번 Q7
15. 15번 `/G` → GND
16. 16번 → +5V

Select=LOW면 A, Select=HIGH면 ALU 결과가 선택된다.

---

# 4-9. 74HC245 A/ALU 데이터 버스 드라이버

1. 1번 DIR → +5V
2. 2번 ← 하위 A/ALU MUX 4번
3. 3번 ← 하위 MUX 7번
4. 4번 ← 하위 MUX 9번
5. 5번 ← 하위 MUX 12번
6. 6번 ← 상위 MUX 4번
7. 7번 ← 상위 MUX 7번
8. 8번 ← 상위 MUX 9번
9. 9번 ← 상위 MUX 12번
10. 10번 → GND
11. 11번 B8 → DB7
12. 12번 B7 → DB6
13. 13번 B6 → DB5
14. 14번 B5 → DB4
15. 15번 B4 → DB3
16. 16번 B3 → DB2
17. 17번 B2 → DB1
18. 18번 B1 → DB0
19. 19번 `/OE` → 지금은 테스트용 점퍼. LOW일 때만 DATA BUS로 출력
20. 20번 → +5V

## 최종 테스트

1. A와 ALU 결과를 서로 다르게 만든다.
2. MUX Select=LOW에서 DATA BUS가 A와 같은지 확인한다.
3. Select=HIGH에서 DATA BUS가 ALU와 같은지 확인한다.
4. 버스 드라이버 `/OE`=HIGH에서는 DATA BUS를 밀지 않는지 확인한다.
