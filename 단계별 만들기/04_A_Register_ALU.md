# 4단계 — A 레지스터와 ALU

이번에는 CPU가 실제 숫자를 저장하고 더하고 빼는 부분을 만든다.

순서는 다음과 같다.

```text
74HC273 A 레지스터
↓
74HC86 XOR 두 개
↓
74HC283 덧셈기 두 개
↓
8비트 ADD/SUB ALU
↓
74HC157 A/ALU 선택 MUX 두 개
↓
74HC245 A/ALU 데이터 버스 드라이버
```

## 점퍼선 색

- 🟥 빨강 = +5V / 테스트용 HIGH
- ⬛ 검정 = GND / 테스트용 LOW
- 🟩 초록 = DATA
- 🟦 파랑 = CLOCK / RESET
- 🟧 주황 = CONTROL

---

# 4-1. 74HC273 A 레지스터

A 레지스터는 계산할 값을 기억하는 CPU의 중심 레지스터다.

## 실제 배선

1. 🟦 **파랑** — 1번 `/CLR` → RESET 선
2. 🟩 **초록** — 2번 `Q0` → 74HC283 ALU 하위칩 5번, 74HC157 A/ALU MUX 하위칩 2번
3. 🟩 **초록** — 3번 `D0` ← DB0
4. 🟩 **초록** — 4번 `D1` ← DB1
5. 🟩 **초록** — 5번 `Q1` → 74HC283 ALU 하위칩 3번, A/ALU MUX 하위칩 5번
6. 🟩 **초록** — 6번 `Q2` → 74HC283 ALU 하위칩 14번, A/ALU MUX 하위칩 11번
7. 🟩 **초록** — 7번 `D2` ← DB2
8. 🟩 **초록** — 8번 `D3` ← DB3
9. 🟩 **초록** — 9번 `Q3` → 74HC283 ALU 하위칩 12번, A/ALU MUX 하위칩 14번
10. ⬛ **검정** — 10번 `GND` → GND
11. 🟦 **파랑** — 11번 `CLK` → 지금은 수동 A_CLK 테스트선
12. 🟩 **초록** — 12번 `Q4` → 74HC283 ALU 상위칩 5번, A/ALU MUX 상위칩 2번
13. 🟩 **초록** — 13번 `D4` ← DB4
14. 🟩 **초록** — 14번 `D5` ← DB5
15. 🟩 **초록** — 15번 `Q5` → 74HC283 ALU 상위칩 3번, A/ALU MUX 상위칩 5번
16. 🟩 **초록** — 16번 `Q6` → 74HC283 ALU 상위칩 14번, A/ALU MUX 상위칩 11번
17. 🟩 **초록** — 17번 `D6` ← DB6
18. 🟩 **초록** — 18번 `D7` ← DB7
19. 🟩 **초록** — 19번 `Q7` → 74HC283 ALU 상위칩 12번, A/ALU MUX 상위칩 14번
20. 🟥 **빨강** — 20번 `VCC` → +5V
21. 🟥/⬛ — 0.1µF: 20번 쪽 🟥, 10번 쪽 ⬛

### 테스트

1. 수동 입력 버스 드라이버로 DATA BUS에 `00110101`을 만든다.
2. 🟦 A 레지스터 11번에 한 번의 상승 Clock pulse를 준다.
3. Q0~Q7에 같은 값이 저장되는지 본다.
4. DATA BUS 값을 바꿔도 다음 Clock 전까지 Q가 유지되어야 한다.

# 4-2. SUB_MODE가 뭔가

74HC283은 원래 **덧셈기**다.
뺄셈은 다음 방식으로 만든다.

```text
A - B = A + NOT(B) + 1
```

그래서 RAM 데이터 B를 74HC86 XOR에 먼저 넣는다.

- `SUB_MODE=LOW` → B를 그대로 사용 → ADD
- `SUB_MODE=HIGH` → B를 반전 + Carry-in 1 → SUB

`SUB_MODE`는 🟧 **주황 CONTROL 선**이다.

---

# 4-3. 74HC86 RAM 하위 4비트 XOR

1. 🟩 **초록** — 1번 입력 ← RAM_D0
2. 🟧 **주황** — 2번 입력 ← SUB_MODE
3. 🟩 **초록** — 3번 출력 → 74HC283 ALU 하위칩 6번
4. 🟩 **초록** — 4번 입력 ← RAM_D1
5. 🟧 **주황** — 5번 입력 ← SUB_MODE
6. 🟩 **초록** — 6번 출력 → 74HC283 ALU 하위칩 2번
7. ⬛ **검정** — 7번 GND → GND
8. 🟩 **초록** — 8번 출력 → 74HC283 ALU 하위칩 15번
9. 🟩 **초록** — 9번 입력 ← RAM_D2
10. 🟧 **주황** — 10번 입력 ← SUB_MODE
11. 🟩 **초록** — 11번 출력 → 74HC283 ALU 하위칩 11번
12. 🟩 **초록** — 12번 입력 ← RAM_D3
13. 🟧 **주황** — 13번 입력 ← SUB_MODE
14. 🟥 **빨강** — 14번 VCC → +5V
15. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

# 4-4. 74HC86 RAM 상위 4비트 XOR

7. ⬛ **검정** — 7번 GND → GND
8. 🟩 **초록** — 8번 출력 → 74HC283 ALU 상위칩 15번
9. 🟩 **초록** — 9번 입력 ← RAM_D6
10. 🟧 **주황** — 10번 입력 ← SUB_MODE
11. 🟩 **초록** — 11번 출력 → 74HC283 ALU 상위칩 11번
12. 🟩 **초록** — 12번 입력 ← RAM_D7
13. 🟧 **주황** — 13번 입력 ← SUB_MODE

# 4-5. 74HC283 ALU 하위 4비트 덧셈기

1. 🟩 **초록** — 1번 `S1` → ALU 결과 bit1
2. 🟩 **초록** — 2번 `B1` ← 하위 XOR 6번
3. 🟩 **초록** — 3번 `A1` ← A 레지스터 5번
4. 🟩 **초록** — 4번 `S0` → ALU 결과 bit0
5. 🟩 **초록** — 5번 `A0` ← A 레지스터 2번
6. 🟩 **초록** — 6번 `B0` ← 하위 XOR 3번
7. 🟧 **주황** — 7번 `CIN` ← SUB_MODE
8. ⬛ **검정** — 8번 GND → GND
9. 🟩 **초록** — 9번 `COUT` → 74HC283 ALU 상위칩 7번 CIN
10. 🟩 **초록** — 10번 `S3` → ALU 결과 bit3
11. 🟩 **초록** — 11번 `B3` ← 하위 XOR 11번
12. 🟩 **초록** — 12번 `A3` ← A 레지스터 9번
13. 🟩 **초록** — 13번 `S2` → ALU 결과 bit2
14. 🟩 **초록** — 14번 `A2` ← A 레지스터 6번
15. 🟩 **초록** — 15번 `B2` ← 하위 XOR 8번
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

## ALU 단독 테스트

RAM_D0~7에는 임시 🟩 초록 데이터 입력을 넣는다.

- A=5, RAM_D=3, 🟧 SUB_MODE=LOW → ALU=8
- A=5, RAM_D=3, 🟧 SUB_MODE=HIGH → ALU=2

두 결과가 모두 맞아야 다음으로 간다.

# 4-7. 74HC157 A/ALU 선택 MUX 하위칩

`Select=LOW`면 A 레지스터 값, `Select=HIGH`면 ALU 결과를 선택한다.

1. 🟧 **주황** — 1번 `S` → ALU_SELECT 테스트선
2. 🟩 **초록** — 2번 `1A` ← A 레지스터 Q0
3. 🟩 **초록** — 3번 `1B` ← ALU bit0
4. 🟩 **초록** — 4번 `1Y` → A/ALU 버스 드라이버 2번
5. 🟩 **초록** — 5번 `2A` ← A 레지스터 Q1
6. 🟩 **초록** — 6번 `2B` ← ALU bit1
7. 🟩 **초록** — 7번 `2Y` → A/ALU 버스 드라이버 3번
8. ⬛ **검정** — 8번 GND → GND
9. 🟩 **초록** — 9번 `3Y` → A/ALU 버스 드라이버 4번
10. 🟩 **초록** — 10번 `3B` ← ALU bit2
11. 🟩 **초록** — 11번 `3A` ← A 레지스터 Q2
12. 🟩 **초록** — 12번 `4Y` → A/ALU 버스 드라이버 5번
13. 🟩 **초록** — 13번 `4B` ← ALU bit3
14. 🟩 **초록** — 14번 `4A` ← A 레지스터 Q3
15. ⬛ **검정** — 15번 `/G` → GND
16. 🟥 **빨강** — 16번 VCC → +5V

# 4-8. 74HC157 A/ALU 선택 MUX 상위칩

1. 🟧 **주황** — 1번 `S` → 하위 MUX와 같은 ALU_SELECT
2. 🟩 **초록** — 2번 `1A` ← A 레지스터 Q4
3. 🟩 **초록** — 3번 `1B` ← ALU bit4
4. 🟩 **초록** — 4번 `1Y` → A/ALU 버스 드라이버 6번
5. 🟩 **초록** — 5번 `2A` ← A 레지스터 Q5
6. 🟩 **초록** — 6번 `2B` ← ALU bit5
7. 🟩 **초록** — 7번 `2Y` → A/ALU 버스 드라이버 7번
8. ⬛ **검정** — 8번 GND → GND
9. 🟩 **초록** — 9번 `3Y` → A/ALU 버스 드라이버 8번
10. 🟩 **초록** — 10번 `3B` ← ALU bit6
11. 🟩 **초록** — 11번 `3A` ← A 레지스터 Q6
12. 🟩 **초록** — 12번 `4Y` → A/ALU 버스 드라이버 9번
13. 🟩 **초록** — 13번 `4B` ← ALU bit7
14. 🟩 **초록** — 14번 `4A` ← A 레지스터 Q7
15. ⬛ **검정** — 15번 `/G` → GND
16. 🟥 **빨강** — 16번 VCC → +5V

두 MUX 모두 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛.

# 4-9. 74HC245 A/ALU 데이터 버스 드라이버

1. 🟥 **빨강** — 1번 `DIR` → +5V, A→B 고정
2. 🟩 **초록** — 2번 `A1` ← 하위 MUX 4번
3. 🟩 **초록** — 3번 `A2` ← 하위 MUX 7번
4. 🟩 **초록** — 4번 `A3` ← 하위 MUX 9번
5. 🟩 **초록** — 5번 `A4` ← 하위 MUX 12번
6. 🟩 **초록** — 6번 `A5` ← 상위 MUX 4번
7. 🟩 **초록** — 7번 `A6` ← 상위 MUX 7번
8. 🟩 **초록** — 8번 `A7` ← 상위 MUX 9번
9. 🟩 **초록** — 9번 `A8` ← 상위 MUX 12번
10. ⬛ **검정** — 10번 GND → GND
11. 🟩 **초록** — 11번 `B8` ↔ DB7
12. 🟩 **초록** — 12번 `B7` ↔ DB6
13. 🟩 **초록** — 13번 `B6` ↔ DB5
14. 🟩 **초록** — 14번 `B5` ↔ DB4
15. 🟩 **초록** — 15번 `B4` ↔ DB3
16. 🟩 **초록** — 16번 `B3` ↔ DB2
17. 🟩 **초록** — 17번 `B2` ↔ DB1
18. 🟩 **초록** — 18번 `B1` ↔ DB0
19. 🟧 **주황** — 19번 `/OE` → 지금은 테스트용 Enable 선. 평상시 HIGH, 시험할 때 LOW
20. 🟥 **빨강** — 20번 VCC → +5V
21. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### 최종 테스트

1. A와 ALU 결과를 서로 다른 값으로 만든다.
2. 🟧 ALU_SELECT를 LOW/HIGH로 바꾸며 선택 결과가 바뀌는지 본다.
3. A/ALU 버스 드라이버 `/OE`를 LOW로 했을 때만 DB0~DB7에 선택값이 나타나야 한다.
4. 시험 후 `/OE`를 다시 HIGH로 둔다.
