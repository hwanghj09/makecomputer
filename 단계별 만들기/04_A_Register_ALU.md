# 4단계 — A Register와 ALU

3단계까지 만든 것:

```text
DATA BUS DB0~DB7
RAM 160byte
RAM_D0~RAM_D7
Manual Input U20
RAM BUS Driver U18
```

이번 단계에서는 처음으로 **값을 저장하고 계산하는 부분**을 만든다.

---

# 1. 이번 단계에서 처음 배우는 말

## Register
Register는 8bit 값을 잠깐 기억하는 저장장치다.

RAM과 다른 점은 아주 빠르고, CPU 안에서 계산용으로 바로 쓴다는 것이다.

## A Register
이 CPU의 중심 계산값을 저장하는 Register다.

예:

```text
A = 5
ADD 3
↓
A = 8
```

## ALU
ALU는 **Arithmetic Logic Unit**의 약자다.

이번 컴퓨터에서는 우선:

- 더하기 ADD
- 빼기 SUB

를 담당한다.

## XOR
74HC86 안에 들어 있는 논리게이트다.

이번에는 뺄셈할 때 RAM 데이터를 반전시키는 데 사용한다.

## Carry
4bit 덧셈에서 자릿수가 넘어갈 때 다음 4bit 덧셈기로 넘기는 값이다.

---

# 2. U14 A Register부터 만든다

U14는 74HC273이다.

3단계에서 이미 만든 DATA BUS 값을 저장하게 한다.

## U14 전원

1. U14-20 → +5V — 🟥
2. U14-10 → GND — ⬛
3. U14-1 → RESET_N — 🟦
4. U14-20과 U14-10 사이 0.1µF

## U14 데이터 입력

```text
DB0 → U14-3
DB1 → U14-4
DB2 → U14-7
DB3 → U14-8
DB4 → U14-13
DB5 → U14-14
DB6 → U14-17
DB7 → U14-18
```

모두 🟩 초록이다.

## U14 저장 Clock
아직 자동 제어회로가 없으므로 U14-11에는 테스트용 버튼 Clock을 사용한다.

```text
U14-11 ── 10kΩ ── GND
U14-11 ── 버튼 ── +5V
```

버튼을 누를 때 LOW→HIGH가 생기고 DATA BUS 값을 저장한다.

## U14 출력

```text
Q0 = U14-2
Q1 = U14-5
Q2 = U14-6
Q3 = U14-9
Q4 = U14-12
Q5 = U14-15
Q6 = U14-16
Q7 = U14-19
```

각 출력에 LED+저항을 임시로 달아도 된다.

## 테스트

1. U20을 ON
2. DATA BUS에 `00110101`
3. U14-11 버튼 1번
4. U14 Q 출력이 `00110101`인지 확인
5. U20 값은 `11110000`으로 바꿈
6. U14 Clock은 누르지 않음
7. U14 출력이 여전히 `00110101`이면 정상
8. 다시 Clock을 누르면 `11110000`으로 바뀌어야 함

A Register가 완전히 성공하기 전에는 ALU로 넘어가지 않는다.

---

# 3. 먼저 덧셈기 U10/U11을 만든다

74HC283 하나는 4bit만 더할 수 있다.

그래서 2개를 이어 8bit 덧셈기를 만든다.

- U10 = 아래 4bit
- U11 = 위 4bit

처음에는 뺄셈 회로 없이 **더하기만** 시험한다.

---

# 4. U10 하위 4bit 덧셈기

## 전원

- U10-16 → +5V — 🟥
- U10-8 → GND — ⬛
- 0.1µF: U10-16 ↔ U10-8

## A Register 하위 4bit를 U10에 연결

```text
U14-2(Q0) → U10-5(A0)
U14-5(Q1) → U10-3(A1)
U14-6(Q2) → U10-14(A2)
U14-9(Q3) → U10-12(A3)
```

🟩 초록이다.

## B 입력은 아직 임시 점퍼
처음 더하기 시험에서는 U10 B 입력을 +5V/GND 점퍼로 직접 만든다.

```text
B0 = U10-6
B1 = U10-2
B2 = U10-15
B3 = U10-11
```

## U10-7 CIN
처음 덧셈 시험에서는 GND에 둔다.

```text
U10-7 → GND
```

## U10 합 출력

```text
ALU0 = U10-4
ALU1 = U10-1
ALU2 = U10-13
ALU3 = U10-10
```

이제 처음으로 `ALU0~ALU3`이라는 이름을 사용한다.

---

# 5. U11 상위 4bit 덧셈기

## 전원

- U11-16 → +5V
- U11-8 → GND
- 0.1µF 연결

## A Register 상위 4bit

```text
U14-12(Q4) → U11-5(A0)
U14-15(Q5) → U11-3(A1)
U14-16(Q6) → U11-14(A2)
U14-19(Q7) → U11-12(A3)
```

## U11 B 입력 임시 점퍼

```text
B4 역할 = U11-6
B5 역할 = U11-2
B6 역할 = U11-15
B7 역할 = U11-11
```

## 두 덧셈기 연결

```text
U10-9(COUT) → U11-7(CIN)
```

이 선 덕분에 아래 4bit에서 올라온 Carry가 위 4bit로 전달된다.

## U11 합 출력

```text
ALU4 = U11-4
ALU5 = U11-1
ALU6 = U11-13
ALU7 = U11-10
```

U11-9 최종 Carry 출력은 지금은 연결하지 않는다.

---

# 6. 8bit 덧셈부터 시험

A Register에 5를 저장한다.

```text
00000101
```

B 입력에는 3을 만든다.

```text
00000011
```

정상 결과:

```text
00000101
+00000011
─────────
00001000
```

즉 ALU7~ALU0 = `00001000`이어야 한다.

다음도 시험한다.

```text
15 + 1 = 16
```

특히 U10-9 → U11-7 Carry 연결이 정상인지 확인하는 시험이다.

---

# 7. 이제 U12/U13 XOR 회로를 추가한다

지금까지 B입력을 점퍼로 직접 넣었다.

이제 그 임시 점퍼를 제거하고 RAM_D0~7을 ALU B입력으로 넣는다.

중간에 74HC86 XOR을 넣는다.

왜냐하면:

```text
A - B = A + NOT(B) + 1
```

방식으로 같은 덧셈기를 뺄셈에도 사용하기 때문이다.

---

# 8. U12 — 아래 4bit XOR

전원:

- U12-14 → +5V
- U12-7 → GND
- 0.1µF 연결

배선:

```text
RAM_D0 → U12-1
U12-3 → U10-6

RAM_D1 → U12-4
U12-6 → U10-2

RAM_D2 → U12-9
U12-8 → U10-15

RAM_D3 → U12-12
U12-11 → U10-11
```

U12의 제어 입력 4개:

```text
U12-2
U12-5
U12-10
U12-13
```

을 서로 묶는다.

이 공통선을 처음으로 **SUB_MODE**라고 부른다.

아직 자동회로가 없으므로 테스트 점퍼로:

- GND → 덧셈
- +5V → 뺄셈

을 선택한다.

---

# 9. U13 — 위 4bit XOR

전원:

- U13-14 → +5V
- U13-7 → GND
- 0.1µF

배선:

```text
RAM_D4 → U13-1
U13-3 → U11-6

RAM_D5 → U13-4
U13-6 → U11-2

RAM_D6 → U13-9
U13-8 → U11-15

RAM_D7 → U13-12
U13-11 → U11-11
```

U13-2,5,10,13도 같은 SUB_MODE 선에 연결한다.

그리고 U10-7(CIN)도 기존 GND 임시선을 제거하고 SUB_MODE에 연결한다.

즉:

```text
SUB_MODE=0
→ B 그대로
→ CIN=0
→ A+B

SUB_MODE=1
→ B 반전
→ CIN=1
→ A-B
```

이다.

---

# 10. RAM_D 값을 시험용으로 넣는 방법

3단계의 U20/U18을 사용한다.

1. U20 스위치로 원하는 값을 만든다
2. U18을 DATA BUS→RAM_D 방향으로 켠다
3. RAM_D0~7에 그 값이 나타나는지 확인
4. ALU 계산값을 확인

RAM 자체를 읽지 않아도 시험할 수 있다.

---

# 11. ADD/SUB 시험

## ADD

A=5, RAM_D=3, SUB_MODE=0

정상:

```text
ALU = 8
```

## SUB

A=5, RAM_D=3, SUB_MODE=1

정상:

```text
ALU = 2
```

## 추가 시험

```text
10 + 20 = 30
20 - 10 = 10
255 + 1 = 0   (8bit에서는 넘친 Carry는 지금 저장하지 않음)
```

---

# 12. U23/U24로 A와 ALU 중 하나를 선택한다

나중에는 어떤 명령은 A 자체를 DATA BUS로 내보내고, 어떤 명령은 ALU 결과를 내보내야 한다.

그래서 두 값을 선택하는 MUX를 만든다.

- U23 = 아래 4bit
- U24 = 위 4bit

Select=0 → A
Select=1 → ALU

아직 자동 Select는 없으므로 한 개의 테스트 점퍼로 U23-1과 U24-1을 같이 제어한다.

---

# 13. U23 연결

전원:

- U23-16 → +5V
- U23-8 → GND
- U23-15 → GND
- 0.1µF

배선:

```text
U23-2 ← U14-2(A0)
U23-3 ← U10-4(ALU0)
U23-4 = 선택 결과 bit0

U23-5 ← U14-5(A1)
U23-6 ← U10-1(ALU1)
U23-7 = 선택 결과 bit1

U23-11 ← U14-6(A2)
U23-10 ← U10-13(ALU2)
U23-9 = 선택 결과 bit2

U23-14 ← U14-9(A3)
U23-13 ← U10-10(ALU3)
U23-12 = 선택 결과 bit3
```

U23-1 = 테스트 Select.

---

# 14. U24 연결

전원:

- U24-16 → +5V
- U24-8 → GND
- U24-15 → GND
- 0.1µF

배선:

```text
U24-2 ← U14-12(A4)
U24-3 ← U11-4(ALU4)
U24-4 = 결과 bit4

U24-5 ← U14-15(A5)
U24-6 ← U11-1(ALU5)
U24-7 = 결과 bit5

U24-11 ← U14-16(A6)
U24-10 ← U11-13(ALU6)
U24-9 = 결과 bit6

U24-14 ← U14-19(A7)
U24-13 ← U11-10(ALU7)
U24-12 = 결과 bit7
```

U24-1은 U23-1과 같은 Select 점퍼에 연결한다.

## MUX 테스트

A와 ALU 결과를 일부러 다르게 만든다.

- Select=0 → U23/U24 출력이 A와 같아야 함
- Select=1 → U23/U24 출력이 ALU와 같아야 함

---

# 15. U19로 선택 결과를 DATA BUS에 내보낸다

U19는 74HC245다.

## 전원/방향

- U19-20 → +5V
- U19-10 → GND
- U19-1(DIR) → +5V, A→B 방향 고정
- 0.1µF

## U23/U24 → U19

```text
U23-4  → U19-2
U23-7  → U19-3
U23-9  → U19-4
U23-12 → U19-5
U24-4  → U19-6
U24-7  → U19-7
U24-9  → U19-8
U24-12 → U19-9
```

## U19 → DATA BUS

```text
U19-18 ↔ DB0
U19-17 ↔ DB1
U19-16 ↔ DB2
U19-15 ↔ DB3
U19-14 ↔ DB4
U19-13 ↔ DB5
U19-12 ↔ DB6
U19-11 ↔ DB7
```

## U19-19 /OE
아직 자동회로가 없으므로:

- +5V → OFF
- GND → ON

으로 테스트한다.

**U19를 켤 때 U20과 U18이 DATA BUS를 동시에 출력하지 않도록 주의한다.**

---

# 16. U19 최종 시험

예:

- A=5
- RAM_D=3
- SUB_MODE=0 → ALU=8

### A를 DATA BUS로

1. U23/U24 Select=0
2. U20 OFF
3. U18 OFF
4. U19 /OE=LOW
5. DB=5인지 확인

### ALU 결과를 DATA BUS로

1. Select=1
2. U19 ON 유지
3. DB=8인지 확인

성공 후 U19 /OE를 HIGH로 돌린다.

---

# 17. 지금은 연결하지 않는 것

아직 다음 자동 신호는 없다.

```text
A_CLK
SUB_MODE 자동제어
ALU Select 자동제어
U19 /OE 자동제어
Zero Flag
```

현재는 버튼과 +5V/GND 점퍼로 시험하는 것이 정상이다.

다음 단계부터 CPU가 명령어를 기억하고 실행 순서를 세는 회로를 만든다.
