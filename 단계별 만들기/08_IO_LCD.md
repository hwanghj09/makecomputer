# 8단계 — 메모리 맵 I/O와 20×4 LCD

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호**로 설명한다.

이번 단계에서는 주소 160~163을 키보드/LCD 장치용으로 나누고 LCD를 연결한다.

---

# 8-1. Memory-Mapped I/O가 뭔가

CPU가 키보드와 LCD를 특별한 전용 명령으로 다루지 않고 **메모리 주소처럼** 다루는 방식이다.

이 컴퓨터에서는:

```text
160 = KEY_STATUS
161 = KEY_DATA
162 = LCD_DATA
163 = LCD_COMMAND
```

으로 정한다.

그래서 나중에:

```text
LDA 161
```

을 하면 키보드 데이터를 읽고,

```text
STA 162
```

를 하면 LCD에 문자 데이터를 보내는 식으로 동작한다.

---

# 8-2. 74HC138 메모리 맵 I/O 주소 디코더

이 칩이 주소 160,161,162,163을 구분한다.

## 연결

1. 1번 A ← ADDRESS A0 = 74HC157 주소 선택 MUX 하위칩 4번 핀
2. 2번 B ← ADDRESS A1 = 주소 선택 MUX 하위칩 7번 핀
3. 3번 C ← ADDRESS A2 = 주소 선택 MUX 하위칩 9번 핀
4. 4번 `/G2A` ← 74HC138 RAM 뱅크 디코더 10번 Y5
5. 5번 `/G2B` ← ADDRESS A4 = 74HC157 주소 선택 MUX 상위칩 4번 핀
6. 6번 G1 ← A3_N
7. 7번 Y7 → 예약, 연결하지 않음
8. 8번 → GND
9. 9번 Y6 → 예약
10. 10번 Y5 → 예약
11. 11번 Y4 → 주소 164 예약
12. 12번 Y3 = LCD_COMMAND_N
13. 13번 Y2 = LCD_DATA_N
14. 14번 Y1 = KEY_DATA_N
15. 15번 Y0 = KEY_STATUS_N
16. 16번 → +5V

출력 Y0~Y3은 Active-Low다.

## 테스트

Active-Low LED를 달고 ADDRESS를 바꾼다.

- 160 → 15번 Y0만 LOW
- 161 → 14번 Y1만 LOW
- 162 → 13번 Y2만 LOW
- 163 → 12번 Y3만 LOW

이 네 개가 정확해야 LCD/Keyboard 주소가 섞이지 않는다.

---

# 8-3. LCD 핀부터 이해하기

HD44780 호환 20×4 병렬 LCD의 16핀은 다음과 같다.

1. VSS = GND
2. VDD = +5V
3. VO = 화면 대비 조절
4. RS = Data/Command 구분
5. R/W = 읽기/쓰기 구분
6. E = Enable pulse
7~14. D0~D7 = 8비트 데이터
15. LED+ = 백라이트 +
16. LED- = 백라이트 GND

이 설계는 LCD 읽기를 하지 않으므로 R/W는 GND에 고정한다.

---

# 8-4. LCD 전원과 대비만 먼저 연결

아직 데이터선을 연결하지 않는다.

1. LCD 1번 VSS → GND
2. LCD 2번 VDD → +5V
3. 10kΩ 가변저항 한쪽 끝 → +5V
4. 가변저항 반대쪽 끝 → GND
5. 가변저항 가운데 핀 → LCD 3번 VO
6. LCD 5번 R/W → GND
7. LCD 15번 LED+ → 모듈 사양에 따라 +5V
8. LCD 16번 LED- → GND

## 첫 테스트

전원을 켜고 10kΩ 가변저항을 천천히 돌린다.

초기화 전 LCD라면 첫 줄에 검은 네모 블록이 보일 수 있다.

네모가 보인다면 최소한 전원과 대비 회로는 살아 있는 것이다.

---

# 8-5. LCD 데이터선 연결

74HC273 출력 레지스터의 Q0~Q7을 LCD D0~D7에 연결한다.

- 출력 레지스터 2번 Q0 → LCD 7번 D0
- 출력 레지스터 5번 Q1 → LCD 8번 D1
- 출력 레지스터 6번 Q2 → LCD 9번 D2
- 출력 레지스터 9번 Q3 → LCD 10번 D3
- 출력 레지스터 12번 Q4 → LCD 11번 D4
- 출력 레지스터 15번 Q5 → LCD 12번 D5
- 출력 레지스터 16번 Q6 → LCD 13번 D6
- 출력 레지스터 19번 Q7 → LCD 14번 D7

모두 🟩 초록 DATA 선이다.

---

# 8-6. LCD RS와 E 연결

## RS

LCD 4번 RS ← 74HC138 메모리 맵 I/O 주소 디코더 12번 Y3

이 연결 때문에:

- 주소 162 = Data
- 주소 163 = Command

으로 구분된다.

## E

LCD 6번 E ← 74HC08 OUT·LCD·PS2 제어 AND 칩 8번 LCD_E

E가 짧게 HIGH가 되는 순간 LCD가 현재 RS와 D0~D7 값을 받아들인다.

---

# 8-7. LCD 초기화

LCD는 전원만 넣는다고 바로 문자를 받지 않는다. 먼저 초기화 명령을 보내야 한다.

최소한 다음 종류의 명령이 필요하다.

- 8비트 모드 설정
- Display ON
- Entry Mode
- Clear Display

정확한 명령 바이트는 Monitor ROM 프로그램을 만들 때 넣는다.

---

# 8-8. 문자 A 출력 테스트

ASCII `A`는 0x41 = `01000001`이다.

1. 74HC273 출력 레지스터에 `01000001`을 저장한다.
2. LCD가 초기화된 상태인지 확인한다.
3. 주소 162, 즉 LCD_DATA 조건을 만든다.
4. LCD E pulse를 한 번 준다.
5. 화면에 `A`가 나타나는지 확인한다.

## 안 되면

- 화면 자체가 안 보임 → VDD/VSS/VO부터 확인
- 검은 네모만 보임 → 초기화 명령 또는 E 확인
- 이상한 문자 → D0~D7 순서 확인
- 명령과 문자가 뒤바뀜 → RS 연결 확인
- 아무 반응 없음 → R/W가 GND인지 확인
