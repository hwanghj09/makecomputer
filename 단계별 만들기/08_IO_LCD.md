# 24단계 — U50 Memory-Mapped I/O + LCD

## 목표

주소 160~163을 KEY/LCD 장치로 나누고 20×4 LCD에 문자를 출력한다.

## U50 — 74HC138 I/O Decoder

1. 🟨 A ← U21-4(A0)
2. 🟨 B ← U21-7(A1)
3. 🟨 C ← U21-9(A2)
4. 🟧 /G2A ← U26-10(Y5)
5. 🟨 /G2B ← U22-4(A4)
6. 🟨 G1 ← U48-6(A3_N)
7. 배선 없음 Y7
8. ⬛ GND
9. 배선 없음 Y6
10. 배선 없음 Y5
11. 배선 없음 Y4(주소164 예약)
12. 🟧 Y3=LCD_COMMAND_N → U35-13,LCD1-4
13. 🟧 Y2=LCD_DATA_N → U35-12
14. 🟧 Y1=KEY_DATA_N → U35-2,U43-10
15. 🟧 Y0=KEY_STATUS_N → U35-1
16. 🟥 +5V

### U50 테스트

Active-Low LED를 사용한다.

- ADDRESS=160 → Y0만 선택
- 161 → Y1
- 162 → Y2
- 163 → Y3

164 이상은 V1에서 사용하지 않는다.

---

## LCD1 — HD44780 20×4

1. ⬛ VSS → GND
2. 🟥 VDD → +5V
3. ⬜ VO → 10kΩ 가변저항 중앙, 가변저항 양끝 +5V/GND
4. 🟧 RS ← U50-12
5. ⬛ R/W → GND
6. 🟧 E ← U36-8
7. 🟩 D0 ← U17-2
8. 🟩 D1 ← U17-5
9. 🟩 D2 ← U17-6
10. 🟩 D3 ← U17-9
11. 🟩 D4 ← U17-12
12. 🟩 D5 ← U17-15
13. 🟩 D6 ← U17-16
14. 🟩 D7 ← U17-19
15. 🟥 LED+ → 모듈 사양에 따라 +5V, 필요시 직렬저항
16. ⬛ LED- → GND

## LCD를 처음 연결할 때

1. DATA선보다 먼저 VSS/VDD/VO만 연결한다.
2. 전원을 켜고 VO 가변저항을 천천히 돌린다.
3. 첫 줄에 진한 블록이 보이면 전원과 대비 회로는 정상이다.
4. 그 다음 D0~D7, RS, E를 연결한다.
5. R/W는 읽기를 사용하지 않으므로 GND 고정이다.

## 데이터/명령 구분

- 주소 162 = LCD_DATA
- 주소 163 = LCD_COMMAND

현재 설계에서 U50-12(Y3)을 RS에 연결하므로 162에서는 Data, 163에서는 Command가 되도록 제어한다.

## 테스트

1. LCD 초기화 명령을 먼저 보낸다.
2. U17에 ASCII `A` = 0x41을 저장한다.
3. LCD_DATA 주소 162 경로에서 E pulse를 준다.
4. 화면에 A가 표시되는지 확인한다.

## 안 되면

- 아무것도 안 보임 → VO 대비조절부터 확인
- 네모만 보임 → 초기화/RS/E 확인
- 이상한 문자 → D0~D7 순서 확인
- LCD 전체가 먹통 → R/W가 GND인지 확인
