# 3단계 — DATA BUS와 RAM

2단계까지 만든 것:

```text
U1 Clock
U2/U3 = PC
U16 = MAR
U21/U22 = Address MUX
A0~A7 = Address Bus
U26 = RAM Bank Decoder
```

이번 단계에서는 처음으로 **Data**, **DATA BUS**, **RAM 읽기/쓰기**를 배운다.

---

# 1. 이번 단계에서 처음 배우는 말

## Data
Address가 `어디?`라면 Data는 `무슨 값?`이다.

예:

```text
주소 5에 값 42 저장
```

- 5 = Address
- 42 = Data

## DATA BUS
여러 부품이 8bit 데이터를 주고받는 공용 8개 선이다.

```text
DB0 DB1 DB2 DB3 DB4 DB5 DB6 DB7
```

이 문서에서 처음으로 `DB0~DB7`이라는 이름을 사용한다.

모두 🟩 초록선이다.

## BUS Driver
공용 DATA BUS에 어떤 장치가 값을 내보낼지 정하는 문이다.

74HC245를 사용한다.

중요:

> 한 순간에 DATA BUS를 두 장치가 서로 다른 값으로 동시에 밀면 안 된다.

그래서 `/OE`라는 출력 허용 핀으로 필요한 장치만 켠다.

## RAM
전원이 켜진 동안 데이터를 저장하는 메모리다.

이번 컴퓨터는 CDP1824CE 5개를 사용해 160 byte를 만든다.

---

# 2. U20 Manual Input부터 만든다

아직 CPU가 자동으로 DATA BUS에 값을 넣는 회로는 없다.

그래서 먼저 8개 스위치로 데이터를 직접 넣는 장치를 만든다.

U20은 74HC245다.

## U20 전원

1. U20-20 → +5V — 🟥
2. U20-10 → GND — ⬛
3. U20-20과 U20-10 사이 0.1µF
4. U20-1(DIR) → +5V — 🟥, A쪽→B쪽 방향 고정

## 스위치 8개 연결

```text
SW0 → U20-2
SW1 → U20-3
SW2 → U20-4
SW3 → U20-5
SW4 → U20-6
SW5 → U20-7
SW6 → U20-8
SW7 → U20-9
```

모두 🟩 초록이다.

각 스위치 입력은 떠 있으면 안 된다.

가장 쉬운 방법:

```text
+5V
 │
스위치
 │
 ●──── U20 입력
 │
10kΩ
 │
GND
```

스위치 OFF=0, ON=1이 된다.

## U20-19 /OE 임시 제어

아직 자동 제어회로가 없으므로 손으로 제어한다.

- U20-19 = +5V → OFF
- U20-19 = GND → ON

평상시는 +5V에 둔다.

---

# 3. U20 출력으로 DATA BUS를 만든다

U20 B쪽 출력 8개에 처음으로 이름을 붙인다.

```text
U20-18 = DB0
U20-17 = DB1
U20-16 = DB2
U20-15 = DB3
U20-14 = DB4
U20-13 = DB5
U20-12 = DB6
U20-11 = DB7
```

이 8개가 DATA BUS다.

## 테스트

1. U20-19 → GND로 내려 U20 ON
2. 스위치로 `01010101`
3. DB0~DB7을 LED+저항 또는 멀티미터로 확인
4. `10101010`도 확인
5. U20-19 → +5V로 다시 OFF

여기까지 성공하면 DATA BUS의 출발점이 만들어진 것이다.

---

# 4. U18로 RAM쪽과 DATA BUS를 연결한다

U18도 74HC245다.

이번에는:

```text
RAM 쪽 8개 선 ↔ U18 ↔ DB0~DB7
```

로 사용한다.

RAM 쪽 선 이름을 처음으로 만든다.

```text
RAM_D0 RAM_D1 RAM_D2 RAM_D3
RAM_D4 RAM_D5 RAM_D6 RAM_D7
```

모두 🟩 초록이다.

## U18 전원

1. U18-20 → +5V — 🟥
2. U18-10 → GND — ⬛
3. U18-20과 U18-10 사이 0.1µF

## U18 A쪽 = RAM 쪽

```text
U18-2 ↔ RAM_D0
U18-3 ↔ RAM_D1
U18-4 ↔ RAM_D2
U18-5 ↔ RAM_D3
U18-6 ↔ RAM_D4
U18-7 ↔ RAM_D5
U18-8 ↔ RAM_D6
U18-9 ↔ RAM_D7
```

## U18 B쪽 = DATA BUS

```text
U18-18 ↔ DB0
U18-17 ↔ DB1
U18-16 ↔ DB2
U18-15 ↔ DB3
U18-14 ↔ DB4
U18-13 ↔ DB5
U18-12 ↔ DB6
U18-11 ↔ DB7
```

## U18-1 DIR 임시 제어

- +5V → A(RAM쪽) → B(DATA BUS)
- GND → B(DATA BUS) → A(RAM쪽)

## U18-19 /OE 임시 제어

- +5V → OFF
- GND → ON

---

# 5. U18을 RAM 없이 먼저 시험한다

## DATA BUS → RAM_D

1. U20 ON
2. U18 DIR = GND
3. U18 /OE = GND
4. 스위치로 `01010101`
5. RAM_D0~7도 같은 값인지 확인

## RAM_D → DATA BUS

이 시험 전에 **U20을 OFF**한다.

1. RAM_D0~7에 임시 점퍼로 `10101010`을 만든다
2. U18 DIR = +5V
3. U18 /OE = GND
4. DB0~7이 같은 값인지 확인

시험이 끝나면 U18 /OE를 +5V로 올려 OFF한다.

---

# 6. 이제 RAM #1 U5만 꽂는다

나머지 RAM은 아직 추가하지 않는다.

U5 하나만 완전히 성공시키는 것이 목표다.

U5는 CDP1824CE이고 주소 0~31을 담당한다.

## U5 전원

- U5-18 → +5V — 🟥
- U5-9 → GND — ⬛
- U5-18과 U5-9 사이 0.1µF

## U5 주소핀
2단계에서 만든 Address Bus에 연결한다.

```text
U5-5 ← A0 = U21-4
U5-4 ← A1 = U21-7
U5-3 ← A2 = U21-9
U5-2 ← A3 = U21-12
U5-1 ← A4 = U22-4
```

모두 🟨 노랑이다.

## U5 데이터핀

```text
U5-14 ↔ RAM_D0
U5-13 ↔ RAM_D1
U5-12 ↔ RAM_D2
U5-11 ↔ RAM_D3
U5-10 ↔ RAM_D4
U5-8  ↔ RAM_D5
U5-7  ↔ RAM_D6
U5-6  ↔ RAM_D7
```

모두 🟩 초록이다.

## U5 선택핀 CS

```text
U26-15(Y0) → U5-15(CS)
```

🟧 주황이다.

A7~A5가 `000`이면 U26 Y0가 LOW가 되어 U5가 선택된다.

## U5 MRD / MWR

- U5-16 = MRD
- U5-17 = MWR

아직 U33/U49 같은 자동 제어회로는 연결하지 않는다.

각 핀은 10kΩ으로 +5V에 Pull-up해 평상시 HIGH로 둔다.

필요할 때만 점퍼나 버튼으로 GND에 내려 LOW를 만든다.

---

# 7. U5 주소 0에 직접 쓰기

MAR에 `00000000`을 저장하고 Address MUX를 MAR 쪽으로 선택한다.

그러면 주소 0을 보고 있다.

## `01010101` 쓰기

1. U20 스위치 = `01010101`
2. U20 /OE = LOW → DATA BUS에 값 출력
3. U18 DIR = LOW → DATA BUS에서 RAM_D 방향
4. U18 /OE = LOW
5. U5 MRD = HIGH
6. U5 MWR를 잠깐 LOW
7. U5 MWR를 다시 HIGH
8. U20 OFF
9. U18 OFF

이제 주소 0에 값이 저장되어 있어야 한다.

---

# 8. 주소 0 다시 읽기

1. 주소는 계속 0
2. U20 /OE = HIGH → 반드시 OFF
3. U18 DIR = HIGH → RAM_D에서 DATA BUS 방향
4. U18 /OE = LOW
5. U5 MWR = HIGH
6. U5 MRD = LOW
7. DB0~DB7 확인

정상이라면 `01010101`이 나온다.

시험 후:

- U5 MRD = HIGH
- U18 /OE = HIGH

으로 돌린다.

---

# 9. 주소 1에 다른 값 쓰기

MAR에 `00000001`을 저장한다.

주소 1에는 `10101010`을 저장한다.

그 뒤 주소 0과 주소 1을 번갈아 읽는다.

정상:

```text
주소 0 → 01010101
주소 1 → 10101010
```

U5 하나가 성공하기 전에는 U6~U9를 추가하지 않는다.

---

# 10. U6~U9를 한 개씩 추가한다

U6~U9도 U5와 같은 방식으로 연결한다.

전원, 주소핀, 데이터핀, MRD, MWR은 모두 동일하다.

다른 것은 15번 CS뿐이다.

```text
U6-15 ← U26-14   주소 32~63
U7-15 ← U26-13   주소 64~95
U8-15 ← U26-12   주소 96~127
U9-15 ← U26-11   주소 128~159
```

각 RAM을 추가할 때마다 경계 주소를 시험한다.

- U6: 32, 63
- U7: 64, 95
- U8: 96, 127
- U9: 128, 159

각 주소에 서로 다른 값을 쓰고 다시 읽는다.

---

# 11. 이번 단계에서 아직 손으로 제어하는 것

현재 아래 신호는 자동이 아니다.

```text
U20 /OE
U18 DIR
U18 /OE
RAM MRD
RAM MWR
Address MUX Select
```

이 상태가 정상이다.

지금 목적은 각 부품이 제대로 작동하는지 확인하는 것이다.

나중에 Control Logic 단계에서 이 임시선을 자동 제어선으로 하나씩 교체한다.
