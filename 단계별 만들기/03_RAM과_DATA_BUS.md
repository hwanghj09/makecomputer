# 3단계 — RAM과 DATA BUS

이번 단계부터 실제 **8비트 DATA**를 다룬다.

먼저 이름을 확실히 구분한다.

```text
ADDRESS = 어느 위치를 읽거나 쓸지 정하는 번호
DATA    = 실제로 저장하거나 옮기는 8비트 값
DATA BUS = CPU 안의 여러 장치가 함께 사용하는 DB0~DB7 공용선
```

그리고 이 단계에서는 74HC245 두 개를 사용한다.

```text
245 #1 = RAM에 연결된 74HC245
245 #2 = 수동 입력/푸시버튼에 연결된 74HC245
```

전체 구조:

```text
푸시버튼
   ↓
245 #2
   ↓
DB0~DB7 DATA BUS
   ↓
245 #1
   ↓
RAM_D0~RAM_D7
   ↓
RAM #1~#5
```

**DB0와 RAM_D0는 같은 이름이 아니다.**
245 #1을 사이에 두고 서로 다른 쪽에 있는 선이다.

예:

```text
DB0    = 245 #1의 18번 B1 쪽
RAM_D0 = 245 #1의 2번 A1 쪽
```

---

# 3-1. 먼저 RAM #1 하나만 연결

처음부터 RAM 5개를 전부 시험하지 않는다.
RAM #1 하나만 연결해서 읽기/쓰기까지 성공시킨다.

RAM #1은 주소 `0~31`을 담당한다.

CDP1824CE 핀 연결:

```text
1번  A4  ← ADDRESS A4 = 상위 주소 MUX 4번
2번  A3  ← ADDRESS A3 = 하위 주소 MUX 12번
3번  A2  ← ADDRESS A2 = 하위 주소 MUX 9번
4번  A1  ← ADDRESS A1 = 하위 주소 MUX 7번
5번  A0  ← ADDRESS A0 = 하위 주소 MUX 4번

6번  D7  ↔ RAM_D7
7번  D6  ↔ RAM_D6
8번  D5  ↔ RAM_D5
9번  VSS → GND
10번 D4  ↔ RAM_D4
11번 D3  ↔ RAM_D3
12번 D2  ↔ RAM_D2
13번 D1  ↔ RAM_D1
14번 D0  ↔ RAM_D0

15번 CS  ← 74HC138 RAM 뱅크 디코더 15번 Y0
16번 MRD → RAM Read 제어선
17번 MWR → RAM Write 제어선
18번 VDD → +5V
```

18번 VDD와 9번 GND 사이에 0.1µF 커패시터를 연결한다.

## MRD/MWR 뜻

둘 다 LOW일 때 동작하는 제어신호다.

```text
RAM 16번 MRD = LOW  → 읽기 ON
RAM 16번 MRD = HIGH → 읽기 OFF

RAM 17번 MWR = LOW  → 쓰기 동작
RAM 17번 MWR = HIGH → 쓰기 OFF
```

따라서 아무 동작도 하지 않는 기본 상태는:

```text
RAM 16번 MRD → +5V
RAM 17번 MWR → +5V
```

이다.

# 3-2. RAM_D0~RAM_D7 만들기

RAM쪽 데이터선은 다음과 같다.

```text
RAM_D0 = RAM 14번 D0
RAM_D1 = RAM 13번 D1
RAM_D2 = RAM 12번 D2
RAM_D3 = RAM 11번 D3
RAM_D4 = RAM 10번 D4
RAM_D5 = RAM 8번 D5
RAM_D6 = RAM 7번 D6
RAM_D7 = RAM 6번 D7
```

이 8개는 245 #1의 A쪽으로 간다.

---

# 3-3. 245 #1 — RAM쪽 74HC245

이 칩은 RAM 내부 데이터선과 CPU DATA BUS 사이의 방향을 바꿔준다.

```text
RAM_D0~7 ↔ 245 #1 ↔ DB0~7
```

## 전원

```text
245 #1 10번 GND → GND
245 #1 20번 VCC → +5V
```

20번과 10번 사이에 0.1µF를 연결한다.

## RAM쪽 A핀

```text
245 #1 2번 A1 ↔ RAM_D0
245 #1 3번 A2 ↔ RAM_D1
245 #1 4번 A3 ↔ RAM_D2
245 #1 5번 A4 ↔ RAM_D3
245 #1 6번 A5 ↔ RAM_D4
245 #1 7번 A6 ↔ RAM_D5
245 #1 8번 A7 ↔ RAM_D6
245 #1 9번 A8 ↔ RAM_D7
```

## DATA BUS쪽 B핀

```text
245 #1 18번 B1 ↔ DB0
245 #1 17번 B2 ↔ DB1
245 #1 16번 B3 ↔ DB2
245 #1 15번 B4 ↔ DB3
245 #1 14번 B5 ↔ DB4
245 #1 13번 B6 ↔ DB5
245 #1 12번 B7 ↔ DB6
245 #1 11번 B8 ↔ DB7
```

## 제어핀

```text
245 #1 1번 DIR
245 #1 19번 /OE
```

`19번 /OE`는 Active-Low다.

```text
19번 → GND  = 245 #1 활성화
19번 → +5V  = 245 #1 비활성화
```

`1번 DIR`은 방향을 정한다.

```text
1번 → +5V = A → B = RAM → DATA BUS
1번 → GND = B → A = DATA BUS → RAM
```

즉:

```text
RAM 읽기 때  : 245 #1 1번 HIGH
RAM 쓰기 때  : 245 #1 1번 LOW
```

---

# 3-4. CPU DATA BUS 만들기

공용 데이터선 8개를 만든다.

```text
DB0
DB1
DB2
DB3
DB4
DB5
DB6
DB7
```

브레드보드에서 한 번 정한 순서를 끝까지 바꾸지 않는다.
가능하면 한쪽부터 `DB0 → DB7` 순서로 배치한다.

# 3-5. 245 #2 — 푸시버튼/수동 입력용 74HC245

이 칩은 테스트용 8비트 값을 DATA BUS에 넣는다.

구조:

```text
푸시버튼 → 245 #2 A쪽 → 245 #2 B쪽 → DATA BUS
```

## 전원

```text
245 #2 10번 GND → GND
245 #2 20번 VCC → +5V
```

## 푸시버튼 입력

```text
245 #2 2번 A1 ← bit0
245 #2 3번 A2 ← bit1
245 #2 4번 A3 ← bit2
245 #2 5번 A4 ← bit3
245 #2 6번 A5 ← bit4
245 #2 7번 A6 ← bit5
245 #2 8번 A7 ← bit6
245 #2 9번 A8 ← bit7
```

입력은 절대로 floating 상태로 두지 않는다.
SPDT 스위치로 +5V/GND를 선택하거나 10kΩ pull-down을 사용한다.

## DATA BUS 연결

```text
245 #2 18번 B1 ↔ DB0
245 #2 17번 B2 ↔ DB1
245 #2 16번 B3 ↔ DB2
245 #2 15번 B4 ↔ DB3
245 #2 14번 B5 ↔ DB4
245 #2 13번 B6 ↔ DB5
245 #2 12번 B7 ↔ DB6
245 #2 11번 B8 ↔ DB7
```

따라서 실제 브레드보드에서는 **245 #1의 11~18번과 245 #2의 11~18번이 같은 DATA BUS에 연결**된다.

## 245 #2 제어

푸시버튼 값을 DATA BUS로 보내므로 방향은 항상 A→B로 사용한다.

```text
245 #2 1번 DIR → +5V
```

활성/비활성은 19번으로 결정한다.

```text
245 #2 19번 → GND  = 푸시버튼 값을 DATA BUS에 출력
245 #2 19번 → +5V  = DATA BUS에서 분리
```

# 3-6. 수동 입력 DATA BUS 테스트

RAM에 쓰기 전에 245 #2만 먼저 시험한다.

### 준비

245 #1은 꺼둔다.

```text
245 #1 19번 → +5V
```

245 #2는 켠다.

```text
245 #2 1번  → +5V
245 #2 19번 → GND
```

푸시버튼으로:

```text
D7~D0 = 01010101
```

을 만든다.

DATA BUS에서 다음이 보여야 한다.

```text
DB7~DB0 = 01010101
```

245 #2의 B쪽 핀으로 확인하면:

```text
11번 B8 = DB7
12번 B7 = DB6
13번 B6 = DB5
14번 B5 = DB4
15번 B4 = DB3
16번 B3 = DB2
17번 B2 = DB1
18번 B1 = DB0
```

# 3-7. RAM #1 쓰기 테스트

RAM #1 주소 0에 `01010101`을 저장한다.

## 1. 주소 설정

```text
MAR = 00000000
주소 선택 74HC157 두 개의 1번 S → +5V
```

즉 MAR 주소를 사용한다.

74HC138에서:

```text
15번 Y0 = LOW
```

가 되어 RAM #1이 선택되어야 한다.

## 2. 테스트 데이터 만들기

푸시버튼으로:

```text
D7 D6 D5 D4 D3 D2 D1 D0
 0  1  0  1  0  1  0  1
```

을 만든다.

## 3. 245 #2 켜기

```text
245 #2 1번  → +5V
245 #2 19번 → GND
```

흐름:

```text
푸시버튼 → 245 #2 → DATA BUS
```

## 4. 245 #1을 DATA BUS → RAM 방향으로 설정

```text
245 #1 1번  → GND
245 #1 19번 → GND
```

흐름:

```text
DATA BUS → 245 #1 → RAM
```

## 5. RAM Read를 끄기

```text
RAM 16번 MRD → +5V
```

이것은 **읽기 OFF**다.

## 6. 실제 Write 펄스

처음에는:

```text
RAM 17번 MWR → +5V
```

로 둔다.

저장할 순간에만:

```text
RAM 17번 MWR
HIGH → LOW → HIGH
```

로 한 번 움직인다.

그러면 이론상:

```text
RAM #1
주소 0
데이터 01010101
```

이 저장된다.

# 3-8. RAM #1 읽기 테스트

방금 쓴 주소와 값을 그대로 다시 읽는다.

주소는 계속:

```text
MAR = 00000000
```

로 유지한다.

## 1. 가장 먼저 245 #2를 끈다

```text
245 #2 19번 → +5V
```

이 단계가 중요하다.
푸시버튼 쪽 245가 켜진 상태에서 RAM도 DATA BUS를 출력하면 두 출력이 충돌할 수 있다.

## 2. 245 #1을 RAM → DATA BUS 방향으로 바꾼다

```text
245 #1 1번  → +5V
245 #1 19번 → GND
```

흐름:

```text
RAM → 245 #1 → DATA BUS
```

## 3. 쓰기를 끄고 읽기를 켠다

```text
RAM 17번 MWR → +5V   = 쓰기 OFF
RAM 16번 MRD → GND   = 읽기 ON
```

## 4. DATA BUS 측정

245 #1의 B쪽, 즉 DATA BUS에서 읽는다.

```text
245 #1 18번 = DB0
245 #1 17번 = DB1
245 #1 16번 = DB2
245 #1 15번 = DB3
245 #1 14번 = DB4
245 #1 13번 = DB5
245 #1 12번 = DB6
245 #1 11번 = DB7
```

`01010101`을 저장했다면 예상값:

```text
11번 DB7 = LOW
12번 DB6 = HIGH
13번 DB5 = LOW
14번 DB4 = HIGH
15번 DB3 = LOW
16번 DB2 = HIGH
17번 DB1 = LOW
18번 DB0 = HIGH
```

즉 D7~D0으로:

```text
01010101
```

이 나오면 Write/Read 성공이다.

# 3-9. 서로 다른 주소가 독립적인지 확인

RAM #1에서 다음 두 값을 써 본다.

```text
주소 0 → 01010101
주소 1 → 10101010
```

그다음 주소를 다시 0과 1로 바꾸며 각각 원래 값이 나오는지 확인한다.

이 테스트가 성공하면 RAM #1의 `A0~A4` 주소선도 정상이라고 볼 수 있다.

# 3-10. RAM #2~#5 연결

RAM #1이 완전히 성공한 다음 나머지를 추가한다.

RAM #2~#5의:

```text
1~14번
16~18번
```

연결은 RAM #1과 동일하다.

**15번 CS만 서로 다르다.**

```text
RAM #1 15번 CS ← 74HC138 15번 Y0
RAM #2 15번 CS ← 74HC138 14번 Y1
RAM #3 15번 CS ← 74HC138 13번 Y2
RAM #4 15번 CS ← 74HC138 12번 Y3
RAM #5 15번 CS ← 74HC138 11번 Y4
```

모든 RAM의 데이터핀은 같은 `RAM_D0~RAM_D7`을 공유한다.

모든 RAM의 MRD와 MWR도 같은 제어선을 공유한다.

---

# 3-11. RAM 뱅크 경계 테스트

최소한 다음 주소를 확인한다.

```text
RAM #1 : 0, 31
RAM #2 : 32, 63
RAM #3 : 64, 95
RAM #4 : 96, 127
RAM #5 : 128, 159
```

RAM #2만 빠르게 시험하려면 예를 들어:

```text
MAR = 00100000  = 주소 32
테스트 데이터 = 11001100
```

을 썼다가 같은 방법으로 다시 읽는다.

# 가장 중요한 상태표

## RAM 쓰기

```text
245 #2 1번  → +5V
245 #2 19번 → GND

245 #1 1번  → GND
245 #1 19번 → GND

RAM 16번 MRD → +5V
RAM 17번 MWR → HIGH → LOW → HIGH
```

## RAM 읽기

```text
245 #2 19번 → +5V

245 #1 1번  → +5V
245 #1 19번 → GND

RAM 17번 MWR → +5V
RAM 16번 MRD → GND
```

## 둘 다 사용하지 않을 때

```text
245 #1 19번 → +5V
245 #2 19번 → +5V
RAM 16번 MRD → +5V
RAM 17번 MWR → +5V
```
