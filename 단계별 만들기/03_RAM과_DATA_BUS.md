# 7~10단계 — RAM과 DATA BUS

> 전원을 끈 상태에서 배선하고, **RAM은 반드시 U5 하나부터** 시험한다.

## 7단계 — U5 CDP1824CE RAM #1

U5는 주소 0~31을 담당한다.

1. 🟨 A4 ← U22-4
2. 🟨 A3 ← U21-12
3. 🟨 A2 ← U21-9
4. 🟨 A1 ← U21-7
5. 🟨 A0 ← U21-4
6. 🟩 D7 ↔ RAM_D7
7. 🟩 D6 ↔ RAM_D6
8. 🟩 D5 ↔ RAM_D5
9. ⬛ GND
10. 🟩 D4 ↔ RAM_D4
11. 🟩 D3 ↔ RAM_D3
12. 🟩 D2 ↔ RAM_D2
13. 🟩 D1 ↔ RAM_D1
14. 🟩 D0 ↔ RAM_D0
15. 🟧 CS ← U26-15
16. 🟧 MRD ← U33-3
17. 🟧 MWR ← U49-4
18. 🟥 +5V

### U5 테스트

1. 먼저 주소 0~31에서 U26의 Y0만 선택되는지 확인한다.
2. 실제 Read/Write는 U18과 U20까지 붙인 뒤 한다.
3. 주소 0에 `01010101`, 주소 1에 `10101010`을 써서 다시 읽어 본다.
4. 두 주소의 값이 서로 바뀌지 않으면 정상이다.

## 8단계 — U6~U9 나머지 RAM

U6~U9의 1~14,16~18번은 U5와 동일하게 연결한다. **15번 CS만 다르다.**

- U6-15 ← U26-14 : 주소 32~63
- U7-15 ← U26-13 : 주소 64~95
- U8-15 ← U26-12 : 주소 96~127
- U9-15 ← U26-11 : 주소 128~159

### 공통 데이터선

- RAM_D0 = U5~U9-14
- RAM_D1 = U5~U9-13
- RAM_D2 = U5~U9-12
- RAM_D3 = U5~U9-11
- RAM_D4 = U5~U9-10
- RAM_D5 = U5~U9-8
- RAM_D6 = U5~U9-7
- RAM_D7 = U5~U9-6

### 테스트

RAM을 한 개씩 추가하면서 경계 주소를 시험한다.

- U6: 32,63
- U7: 64,95
- U8: 96,127
- U9: 128,159

각 경계 주소에 서로 다른 값을 쓰고 다시 읽는다.

## 9단계 — U18 74HC245 RAM ↔ DATA BUS

U18은 RAM과 CPU DATA BUS 사이의 양방향 문이다.

1. 🟧 DIR ← U42-6
2. 🟩 A1 ↔ RAM_D0
3. 🟩 A2 ↔ RAM_D1
4. 🟩 A3 ↔ RAM_D2
5. 🟩 A4 ↔ RAM_D3
6. 🟩 A5 ↔ RAM_D4
7. 🟩 A6 ↔ RAM_D5
8. 🟩 A7 ↔ RAM_D6
9. 🟩 A8 ↔ RAM_D7
10. ⬛ GND
11. 🟩 B8 ↔ DB7
12. 🟩 B7 ↔ DB6
13. 🟩 B6 ↔ DB5
14. 🟩 B5 ↔ DB4
15. 🟩 B4 ↔ DB3
16. 🟩 B3 ↔ DB2
17. 🟩 B2 ↔ DB1
18. 🟩 B1 ↔ DB0
19. 🟧 /OE ← U48-12
20. 🟥 +5V

### U18 테스트

- A쪽에 8bit 패턴을 넣고 A→B 방향에서 B쪽이 같은 값인지 확인한다.
- 방향을 바꿔 B→A도 확인한다.
- /OE 비활성에서는 U18이 BUS를 구동하지 않아야 한다.
- 시험할 때 다른 74HC245는 모두 비활성으로 둔다.

## 10단계 — U20 74HC245 Manual Input

1. 🟥 DIR → +5V
2. 🟩 A1 ← SW0
3. 🟩 A2 ← SW1
4. 🟩 A3 ← SW2
5. 🟩 A4 ← SW3
6. 🟩 A5 ← SW4
7. 🟩 A6 ← SW5
8. 🟩 A7 ← SW6
9. 🟩 A8 ← SW7
10. ⬛ GND
11. 🟩 B8 ↔ DB7
12. 🟩 B7 ↔ DB6
13. 🟩 B6 ↔ DB5
14. 🟩 B5 ↔ DB4
15. 🟩 B4 ↔ DB3
16. 🟩 B3 ↔ DB2
17. 🟩 B2 ↔ DB1
18. 🟩 B1 ↔ DB0
19. 🟧 /OE ← MANUAL_EN_N 스위치, 평상시 +5V
20. 🟥 +5V

### U20 테스트

1. /OE 비활성에서 스위치를 바꿔도 BUS가 변하지 않는지 확인한다.
2. /OE 활성 후 `01010101`, `10101010`을 넣어 DB0~DB7을 확인한다.
3. 시험 후 /OE를 다시 비활성으로 둔다.

> 스위치 입력은 절대 floating이면 안 된다. SPDT로 +5/GND를 선택하거나 10kΩ pull-down을 사용한다.
