# 3단계 — RAM과 DATA BUS

이 파일에서는 처음으로 **DATA**를 만든다.

지금부터 나오는 `RAM_D0~RAM_D7`, `DB0~DB7`은 이 파일에서 처음 설명한다.

아직 U33, U42, U48, U49 같은 최종 제어회로는 없다. 따라서 RAM 읽기/쓰기는 **임시 점퍼**로 시험하고, 나중 제어회로 단계에서 자동 신호로 바꾼다.

---

# 3-0. 먼저 DATA가 뭔가

ADDRESS는 "어디를 볼지" 정하는 번호였다.

DATA는 그 주소에 들어 있는 **실제 값**이다.

예를 들어:

```text
주소 5번 칸에 값 42 저장
```

이라고 하면:

- 주소 5 = ADDRESS
- 값 42 = DATA

이다.

---

# 3-1. DATA BUS란?

컴퓨터 안에서 8bit 데이터를 여러 부품이 같이 주고받는 공용선이다.

8개의 선을 쓴다.

```text
DB7 DB6 DB5 DB4 DB3 DB2 DB1 DB0
```

점퍼선 색은 **초록**이다.

아직 DB0~DB7에 다른 IC를 많이 연결하지 않는다. 이번 파일에서는 먼저 U18/U20까지만 연결한다.

---

# 3-2. RAM 내부 데이터선도 따로 만든다

RAM 5개는 CPU DATA BUS에 바로 연결하지 않고 U18 74HC245를 사이에 둔다.

그래서 RAM 쪽에만 있는 8개 선을 이렇게 부른다.

```text
RAM_D7 ... RAM_D0
```

이것도 DATA이므로 **초록색**이다.

---

# 3-3. U5 RAM #1부터 하나만 만들기

U5는 주소 0~31을 담당한다.

처음부터 RAM 5개를 다 꽂지 않는다.

U5 하나만 성공시킨 뒤 나머지를 추가한다.

## U5 — CDP1824CE

1. U5-18 → +5V **[빨강]**
2. U5-9 → GND **[검정]**
3. U5-1(A4) ← U22-4(A4) **[노랑]**
4. U5-2(A3) ← U21-12(A3) **[노랑]**
5. U5-3(A2) ← U21-9(A2) **[노랑]**
6. U5-4(A1) ← U21-7(A1) **[노랑]**
7. U5-5(A0) ← U21-4(A0) **[노랑]**
8. U5-15(CS) ← U26-15(Y0) **[주황]**

### U5 데이터 핀

- U5-14 = RAM_D0 **[초록]**
- U5-13 = RAM_D1 **[초록]**
- U5-12 = RAM_D2 **[초록]**
- U5-11 = RAM_D3 **[초록]**
- U5-10 = RAM_D4 **[초록]**
- U5-8 = RAM_D5 **[초록]**
- U5-7 = RAM_D6 **[초록]**
- U5-6 = RAM_D7 **[초록]**

### U5 읽기/쓰기 제어 핀

- U5-16 = MRD
- U5-17 = MWR

둘 다 CONTROL이므로 **주황**이다.

지금은 최종 제어회로에 연결하지 않는다.

테스트용으로 직접 HIGH/LOW를 넣는다.

---

# 3-4. U5에 값 쓰기 시험

먼저 주소를 하나 고른다.

예를 들어 주소 0:

```text
A4 A3 A2 A1 A0 = 00000
```

U26의 Y0가 선택되어 U5 CS가 LOW여야 한다.

RAM_D0~RAM_D7에는 임시 점퍼로 값을 넣는다.

예: `01010101`

그 다음 U5의 제어 핀을 쓰기 조건으로 만든다.

```text
CS = LOW
MRD = HIGH
MWR = LOW
```

짧게 쓰기 동작을 준 뒤 MWR을 다시 HIGH로 올린다.

> 전원을 끄고 배선 변경, 전원을 켜서 시험하는 습관을 유지한다.

---

# 3-5. U5 읽기 시험

같은 주소 0을 유지한다.

읽기 조건:

```text
CS = LOW
MRD = LOW
MWR = HIGH
```

RAM_D0~RAM_D7에 LED+저항 또는 로직 프로브를 달아 `01010101`이 나오는지 본다.

정상이면:

- 주소 0에 저장한 값이 그대로 읽힌다.
- 주소 1에 다른 값을 써도 주소 0 값은 바뀌지 않는다.

---

# 3-6. U18 74HC245를 붙여 RAM과 CPU 쪽을 분리

U18은 RAM 쪽 데이터선과 CPU 쪽 DATA BUS 사이의 문이다.

```text
RAM_D0~7 ↔ U18 ↔ DB0~7
```

## U18 기본 연결

1. U18-20 → +5V **[빨강]**
2. U18-10 → GND **[검정]**

### RAM 쪽 A 핀

- U18-2 ↔ RAM_D0 **[초록]**
- U18-3 ↔ RAM_D1 **[초록]**
- U18-4 ↔ RAM_D2 **[초록]**
- U18-5 ↔ RAM_D3 **[초록]**
- U18-6 ↔ RAM_D4 **[초록]**
- U18-7 ↔ RAM_D5 **[초록]**
- U18-8 ↔ RAM_D6 **[초록]**
- U18-9 ↔ RAM_D7 **[초록]**

### CPU DATA BUS 쪽 B 핀

여기서 처음으로 DB0~DB7을 만든다.

- U18-18 = DB0 **[초록]**
- U18-17 = DB1 **[초록]**
- U18-16 = DB2 **[초록]**
- U18-15 = DB3 **[초록]**
- U18-14 = DB4 **[초록]**
- U18-13 = DB5 **[초록]**
- U18-12 = DB6 **[초록]**
- U18-11 = DB7 **[초록]**

지금은 이 DB 선들을 다른 레지스터에 아직 연결하지 않는다.

### U18 제어 핀

- U18-1 = DIR **[주황]**
- U18-19 = /OE **[주황]**

지금은 최종 제어회로 대신 임시 점퍼로 시험한다.

---

# 3-7. U18만 따로 테스트

## A → B 시험

1. /OE를 활성 상태 LOW로 둔다.
2. DIR을 A→B 방향이 되게 둔다.
3. RAM_D 쪽에 `10101010` 같은 값을 넣는다.
4. DB0~DB7이 같은 값인지 확인한다.

## B → A 시험

1. 방향을 반대로 바꾼다.
2. DB 쪽에 값을 넣는다.
3. RAM_D 쪽이 같은지 확인한다.

## OFF 시험

/OE를 HIGH로 둔다.

이때 U18이 양쪽 버스를 구동하지 않는 상태가 되어야 한다.

---

# 3-8. U20 Manual Input 만들기

U20은 사람이 스위치로 8bit 값을 DATA BUS에 넣기 위한 장치다.

## U20 연결

1. U20-20 → +5V **[빨강]**
2. U20-10 → GND **[검정]**
3. U20-1(DIR) → +5V **[빨강]**

### 스위치 입력

- U20-2 ← SW0 **[초록]**
- U20-3 ← SW1 **[초록]**
- U20-4 ← SW2 **[초록]**
- U20-5 ← SW3 **[초록]**
- U20-6 ← SW4 **[초록]**
- U20-7 ← SW5 **[초록]**
- U20-8 ← SW6 **[초록]**
- U20-9 ← SW7 **[초록]**

스위치는 floating이면 안 된다.

가장 쉬운 방법은 각 입력을:

```text
+5V / GND 중 하나를 확실히 선택
```

하게 만드는 것이다.

### DATA BUS 연결

- U20-18 ↔ DB0 **[초록]**
- U20-17 ↔ DB1 **[초록]**
- U20-16 ↔ DB2 **[초록]**
- U20-15 ↔ DB3 **[초록]**
- U20-14 ↔ DB4 **[초록]**
- U20-13 ↔ DB5 **[초록]**
- U20-12 ↔ DB6 **[초록]**
- U20-11 ↔ DB7 **[초록]**

U20-19(/OE)는 지금 수동으로 제어한다.

- HIGH = U20 꺼짐
- LOW = U20이 DATA BUS에 값 출력

---

# 3-9. U20 테스트

1. U20-19를 HIGH로 둔다.
2. 스위치를 바꿔도 DB가 U20 때문에 변하지 않는지 확인한다.
3. U20-19를 LOW로 둔다.
4. 스위치를 `01010101`로 만든다.
5. DB0~DB7이 같은 값인지 확인한다.
6. `10101010`도 확인한다.
7. 테스트 후 U20-19는 다시 HIGH로 둔다.

---

# 3-10. 이제 U5를 U20+U18로 다시 Read/Write 시험

이제 사람이 U20으로 값을 DATA BUS에 넣고, U18을 통해 RAM에 전달할 수 있다.

### RAM에 쓰기

```text
U20 ON
DB → U18 → RAM_D
RAM Write
```

### RAM에서 읽기

```text
RAM_D → U18 → DB
U20 OFF
```

중요:

> DATA BUS는 한 번에 한 장치만 값을 밀어야 한다.

U20과 RAM이 서로 반대 값을 동시에 밀면 안 된다.

---

# 3-11. U6~U9를 하나씩 추가

U5가 완전히 정상일 때만 추가한다.

각 RAM의 1~14,16~18번은 U5와 같은 역할이다.

15번 CS만 다르다.

- U6-15 ← U26-14(Y1) : 주소 32~63
- U7-15 ← U26-13(Y2) : 주소 64~95
- U8-15 ← U26-12(Y3) : 주소 96~127
- U9-15 ← U26-11(Y4) : 주소 128~159

모든 RAM의 데이터 핀은 같은 RAM_D0~RAM_D7에 묶는다.

### 각 RAM 경계 테스트

- U5: 0, 31
- U6: 32, 63
- U7: 64, 95
- U8: 96, 127
- U9: 128, 159

각 주소에 서로 다른 값을 써서 다시 읽는다.

---

# 3-12. 아직 연결하지 않는 것

최종 설계에서는 나중에:

- U5~U9 MRD ← 자동 제어
- U5~U9 MWR ← 자동 제어
- U18 DIR ← 자동 제어
- U18 /OE ← 자동 제어
- U20 /OE ← 수동 Enable 회로

가 들어간다.

하지만 지금은 **테스트용 점퍼로 직접 HIGH/LOW를 넣는 단계**다.

---
