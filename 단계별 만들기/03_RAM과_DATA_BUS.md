# 3단계 — RAM과 DATA BUS

이 단계부터 처음으로 **DATA**를 만든다.

## 먼저 뜻부터

- **ADDRESS** = 어디를 읽거나 쓸지 정하는 번호 → 🟨 노랑
- **DATA** = 실제로 옮기는 8비트 값 → 🟩 초록
- **DATA BUS** = 여러 장치가 함께 사용하는 8개의 공용 데이터선

DATA BUS 8개에는 이름을 붙인다.

```text
DB0 DB1 DB2 DB3 DB4 DB5 DB6 DB7
```

모두 🟩 **초록 점퍼선**을 사용한다.

## 점퍼선 색

- 🟥 빨강 = +5V / 테스트용 HIGH
- ⬛ 검정 = GND / 테스트용 LOW
- 🟩 초록 = DATA
- 🟨 노랑 = ADDRESS
- 🟦 파랑 = CLOCK / RESET
- 🟧 주황 = CONTROL

---

# 3-1. CDP1824CE RAM #1만 먼저 연결

처음에는 RAM 다섯 개를 한꺼번에 꽂지 않는다.
**RAM #1 하나만** 연결하고 읽기/쓰기를 성공시킨다.

CDP1824CE RAM #1은 주소 `0~31`을 담당한다.

## 실제 배선

1. 🟨 **노랑** — RAM #1 1번 `A4` ← 주소 선택 MUX 상위칩 4번 `A4`
2. 🟨 **노랑** — RAM #1 2번 `A3` ← 주소 선택 MUX 하위칩 12번 `A3`
3. 🟨 **노랑** — RAM #1 3번 `A2` ← 주소 선택 MUX 하위칩 9번 `A2`
4. 🟨 **노랑** — RAM #1 4번 `A1` ← 주소 선택 MUX 하위칩 7번 `A1`
5. 🟨 **노랑** — RAM #1 5번 `A0` ← 주소 선택 MUX 하위칩 4번 `A0`
6. 🟩 **초록** — RAM #1 6번 `D7` → `RAM_D7`
7. 🟩 **초록** — RAM #1 7번 `D6` → `RAM_D6`
8. 🟩 **초록** — RAM #1 8번 `D5` → `RAM_D5`
9. ⬛ **검정** — RAM #1 9번 `GND` → GND
10. 🟩 **초록** — RAM #1 10번 `D4` → `RAM_D4`
11. 🟩 **초록** — RAM #1 11번 `D3` → `RAM_D3`
12. 🟩 **초록** — RAM #1 12번 `D2` → `RAM_D2`
13. 🟩 **초록** — RAM #1 13번 `D1` → `RAM_D1`
14. 🟩 **초록** — RAM #1 14번 `D0` → `RAM_D0`
15. 🟧 **주황** — RAM #1 15번 `CS` ← RAM 뱅크 디코더 15번 `Y0`
16. 🟧 **주황** — RAM #1 16번 `MRD` → 지금은 테스트용 Read 제어선
17. 🟧 **주황** — RAM #1 17번 `MWR` → 지금은 테스트용 Write 제어선
18. 🟥 **빨강** — RAM #1 18번 `VDD` → +5V
19. 🟥/⬛ — 0.1µF: 18번 VDD 쪽 🟥, 9번 GND 쪽 ⬛

## 지금 MRD/MWR은 어떻게 하나

아직 자동 제어회로를 만들지 않았기 때문에 수동 점퍼로 시험한다.

- 읽기 준비: 🟧 MRD 제어선을 **⬛ GND(LOW)**로
- 쓰지 않을 때: 🟧 MWR 제어선을 **🟥 +5V(HIGH)**로
- 쓰기 동작은 아래의 RAM 버스 드라이버와 수동 입력 회로를 만든 뒤 시험한다.

# 3-2. RAM 내부 데이터선 8개 만들기

RAM 칩과 CPU DATA BUS 사이에는 먼저 RAM 전용 8개 선을 만든다.

모두 🟩 **초록**이다.

```text
RAM_D0 = RAM #1 14번
RAM_D1 = RAM #1 13번
RAM_D2 = RAM #1 12번
RAM_D3 = RAM #1 11번
RAM_D4 = RAM #1 10번
RAM_D5 = RAM #1 8번
RAM_D6 = RAM #1 7번
RAM_D7 = RAM #1 6번
```

이 8개 선은 다음에 74HC245 RAM 데이터 버스 드라이버의 A쪽으로 간다.

# 3-3. 74HC245 RAM 데이터 버스 드라이버

이 칩은 RAM 내부 데이터선과 CPU DATA BUS 사이의 **문**이다.

```text
RAM_D0~7 ↔ 74HC245 ↔ DB0~7
```

## 실제 배선

1. 🟧 **주황** — 1번 `DIR` → 테스트용 방향 제어선
2. 🟩 **초록** — 2번 `A1` ↔ RAM_D0
3. 🟩 **초록** — 3번 `A2` ↔ RAM_D1
4. 🟩 **초록** — 4번 `A3` ↔ RAM_D2
5. 🟩 **초록** — 5번 `A4` ↔ RAM_D3
6. 🟩 **초록** — 6번 `A5` ↔ RAM_D4
7. 🟩 **초록** — 7번 `A6` ↔ RAM_D5
8. 🟩 **초록** — 8번 `A7` ↔ RAM_D6
9. 🟩 **초록** — 9번 `A8` ↔ RAM_D7
10. ⬛ **검정** — 10번 `GND` → GND
11. 🟩 **초록** — 11번 `B8` ↔ DB7
12. 🟩 **초록** — 12번 `B7` ↔ DB6
13. 🟩 **초록** — 13번 `B6` ↔ DB5
14. 🟩 **초록** — 14번 `B5` ↔ DB4
15. 🟩 **초록** — 15번 `B4` ↔ DB3
16. 🟩 **초록** — 16번 `B3` ↔ DB2
17. 🟩 **초록** — 17번 `B2` ↔ DB1
18. 🟩 **초록** — 18번 `B1` ↔ DB0
19. 🟧 **주황** — 19번 `/OE` → 테스트용 Enable 제어선
20. 🟥 **빨강** — 20번 `VCC` → +5V
21. 🟥/⬛ — 0.1µF: 20번 쪽 🟥, 10번 쪽 ⬛

## 단독 테스트

- A→B 테스트: 🟧 DIR을 🟥 HIGH, `/OE`를 ⬛ LOW
- B→A 테스트: 🟧 DIR을 ⬛ LOW, `/OE`를 ⬛ LOW
- 비활성 테스트: `/OE`를 🟥 HIGH

데이터 테스트선은 모두 🟩 초록을 사용한다.

# 3-4. CPU DATA BUS 8개 만들기

브레드보드에 8개의 공용 데이터선을 만든다.

```text
DB0 = 🟩 초록
DB1 = 🟩 초록
DB2 = 🟩 초록
DB3 = 🟩 초록
DB4 = 🟩 초록
DB5 = 🟩 초록
DB6 = 🟩 초록
DB7 = 🟩 초록
```

서로 섞이지 않게 왼쪽에서 오른쪽으로 `DB0 → DB7` 순서로 고정해 두는 것을 권장한다.

# 3-5. 74HC245 수동 입력 버스 드라이버

이 칩은 스위치/점퍼로 만든 8비트 값을 DATA BUS에 직접 넣는 **테스트용 입력장치**다.

## 실제 배선

1. 🟥 **빨강** — 1번 `DIR` → +5V (A→B 고정)
2. 🟩 **초록** — 2번 `A1` ← 수동 입력 bit0
3. 🟩 **초록** — 3번 `A2` ← 수동 입력 bit1
4. 🟩 **초록** — 4번 `A3` ← 수동 입력 bit2
5. 🟩 **초록** — 5번 `A4` ← 수동 입력 bit3
6. 🟩 **초록** — 6번 `A5` ← 수동 입력 bit4
7. 🟩 **초록** — 7번 `A6` ← 수동 입력 bit5
8. 🟩 **초록** — 8번 `A7` ← 수동 입력 bit6
9. 🟩 **초록** — 9번 `A8` ← 수동 입력 bit7
10. ⬛ **검정** — 10번 GND → GND
11. 🟩 **초록** — 11번 `B8` ↔ DB7
12. 🟩 **초록** — 12번 `B7` ↔ DB6
13. 🟩 **초록** — 13번 `B6` ↔ DB5
14. 🟩 **초록** — 14번 `B5` ↔ DB4
15. 🟩 **초록** — 15번 `B4` ↔ DB3
16. 🟩 **초록** — 16번 `B3` ↔ DB2
17. 🟩 **초록** — 17번 `B2` ↔ DB1
18. 🟩 **초록** — 18번 `B1` ↔ DB0
19. 🟧 **주황** — 19번 `/OE` → `MANUAL_EN_N` 테스트 스위치. 평상시 🟥 +5V, 사용할 때만 ⬛ GND
20. 🟥 **빨강** — 20번 VCC → +5V
21. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

수동 입력 bit0~7은 floating이면 안 된다. SPDT로 +5V/GND를 고르거나 10kΩ pull-down을 사용한다.

### 테스트

`01010101`, `10101010` 같은 패턴을 넣고 `/OE`를 LOW로 했을 때 DB0~DB7에 그대로 나타나는지 본다.

# 3-6. RAM #1 실제 Write/Read 테스트

이제 주소 0과 1에 다른 값을 써 본다.

## 쓰기

1. 주소 선택 MUX가 MAR를 선택하게 한다.
2. MAR에 주소 0을 넣는다.
3. 수동 입력 버스 드라이버로 `01010101`을 DATA BUS에 넣는다.
4. 🟧 RAM 데이터 버스 드라이버 DIR = LOW(B→A)
5. 🟧 RAM 데이터 버스 드라이버 /OE = LOW
6. 🟧 RAM #1 MRD = HIGH
7. 🟧 RAM #1 MWR = 짧게 LOW 후 다시 HIGH

## 읽기

1. 수동 입력 버스 드라이버 /OE를 HIGH로 꺼 둔다.
2. 🟧 RAM #1 MWR = HIGH
3. 🟧 RAM #1 MRD = LOW
4. 🟧 RAM 데이터 버스 드라이버 DIR = HIGH(A→B)
5. 🟧 RAM 데이터 버스 드라이버 /OE = LOW
6. DB0~DB7에서 `01010101`이 나오는지 확인한다.

주소 1에는 `10101010`을 써서 서로 독립적으로 저장되는지 확인한다.

# 3-7. RAM #2~#5 추가

RAM #1이 성공한 뒤에만 나머지를 하나씩 추가한다.

모든 RAM의 1~14, 16~18번 연결과 색은 RAM #1과 동일하다.
**15번 CS만 다르다.**

- 🟧 **주황** — RAM #2 15번 CS ← RAM 뱅크 디코더 14번 Y1
- 🟧 **주황** — RAM #3 15번 CS ← RAM 뱅크 디코더 13번 Y2
- 🟧 **주황** — RAM #4 15번 CS ← RAM 뱅크 디코더 12번 Y3
- 🟧 **주황** — RAM #5 15번 CS ← RAM 뱅크 디코더 11번 Y4

각 RAM의 데이터핀은 같은 🟩 RAM_D0~7 선을 공유한다.

경계 주소를 시험한다.

- RAM #1: 0, 31
- RAM #2: 32, 63
- RAM #3: 64, 95
- RAM #4: 96, 127
- RAM #5: 128, 159
