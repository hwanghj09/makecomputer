# 3단계 — DATA BUS와 RAM

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호**로 설명한다.

이번 파일은 다음 순서로 진행한다.

```text
DATA BUS 뜻 이해
↓
수동 입력용 74HC245 만들기
↓
RAM용 74HC245 만들기
↓
CDP1824CE RAM #1 하나만 연결
↓
직접 쓰기/읽기 테스트
↓
RAM #2~#5 추가
```

---

# 3-1. DATA가 뭔가

ADDRESS는 "어디인지"를 말한다.

DATA는 "그 주소에 들어 있는 값이 무엇인지"를 말한다.

이 컴퓨터는 8비트 컴퓨터이므로 데이터선도 8개다.

앞으로 이 8개를 이렇게 부른다.

```text
DB0 DB1 DB2 DB3 DB4 DB5 DB6 DB7
```

DB는 Data Bus의 줄임말이다.

브레드보드에 초록색 점퍼선 8개를 나란히 잡아두고 각각 DB0~DB7이라고 메모해 두면 좋다.

> **중요:** 한 순간에 DATA BUS를 밀어주는 장치는 하나만 켜져 있어야 한다.

---

# 3-2. 74HC245 수동 입력 버스 드라이버

이 칩은 8개의 스위치 값을 DATA BUS에 직접 넣어주는 테스트 장치다.

나중에 회로 전체를 시험할 때 매우 유용하므로 먼저 만든다.

## 74HC245 핀

```text
             홈
        ┌───────────┐
 DIR  1 │           │20 VCC
 A1   2 │ 74HC245   │19 /OE
 A2   3 │           │18 B1
 A3   4 │           │17 B2
 A4   5 │           │16 B3
 A5   6 │           │15 B4
 A6   7 │           │14 B5
 A7   8 │           │13 B6
 A8   9 │           │12 B7
 GND 10 │           │11 B8
        └───────────┘
```

## 연결

1. 1번 DIR → +5V. A쪽에서 B쪽으로만 보내게 고정한다. → 🟥 빨강
2. 2번 A1 ← 스위치 0
3. 3번 A2 ← 스위치 1
4. 4번 A3 ← 스위치 2
5. 5번 A4 ← 스위치 3
6. 6번 A5 ← 스위치 4
7. 7번 A6 ← 스위치 5
8. 8번 A7 ← 스위치 6
9. 9번 A8 ← 스위치 7
10. 10번 → GND
11. 11번 B8 → DB7
12. 12번 B7 → DB6
13. 13번 B6 → DB5
14. 14번 B5 → DB4
15. 15번 B4 → DB3
16. 16번 B3 → DB2
17. 17번 B2 → DB1
18. 18번 B1 → DB0
19. 19번 `/OE` → 테스트용 스위치. 평소 +5V, 사용할 때 GND
20. 20번 → +5V

A1~A8부터 DB0~DB7까지는 🟩 초록이다.

각 스위치는 절대 공중에 뜨면 안 된다.

가장 쉬운 방식:

```text
+5V ─ 스위치 ─ 입력핀
               │
              10kΩ
               │
              GND
```

## 테스트

1. `/OE`를 +5V로 둔다. 이때 스위치를 바꿔도 DATA BUS가 강제로 바뀌지 않아야 한다.
2. 스위치를 `01010101`로 만든다.
3. `/OE`를 GND로 내린다.
4. DB7~DB0가 `01010101`인지 LED나 멀티미터로 확인한다.
5. `10101010`도 시험한다.
6. 끝나면 `/OE`를 다시 +5V로 둔다.

# 3-3. 74HC245 RAM 데이터 버스 드라이버

RAM 데이터선과 CPU DATA BUS 사이에는 또 하나의 74HC245가 필요하다.

RAM 쪽 8개 선은 앞으로 이렇게 부른다.

```text
RAM_D0 RAM_D1 RAM_D2 RAM_D3 RAM_D4 RAM_D5 RAM_D6 RAM_D7
```

## 연결

1. 1번 DIR → 지금은 테스트용 점퍼. +5V면 RAM→DATA BUS, GND면 DATA BUS→RAM
2. 2번 A1 ↔ RAM_D0
3. 3번 A2 ↔ RAM_D1
4. 4번 A3 ↔ RAM_D2
5. 5번 A4 ↔ RAM_D3
6. 6번 A5 ↔ RAM_D4
7. 7번 A6 ↔ RAM_D5
8. 8번 A7 ↔ RAM_D6
9. 9번 A8 ↔ RAM_D7
10. 10번 → GND
11. 11번 B8 ↔ DB7
12. 12번 B7 ↔ DB6
13. 13번 B6 ↔ DB5
14. 14번 B5 ↔ DB4
15. 15번 B4 ↔ DB3
16. 16번 B3 ↔ DB2
17. 17번 B2 ↔ DB1
18. 18번 B1 ↔ DB0
19. 19번 `/OE` → 지금은 테스트용 점퍼. 사용할 때 GND, 끌 때 +5V
20. 20번 → +5V

## 단독 테스트

RAM을 연결하기 전에 74HC245 자체만 시험한다.

- DIR=HIGH, `/OE`=LOW: A쪽 값이 B쪽으로 나오는지 확인
- DIR=LOW, `/OE`=LOW: B쪽 값이 A쪽으로 나오는지 확인
- `/OE`=HIGH: 양쪽을 연결하지 않는 High-Z 상태가 되는지 확인

# 3-4. CDP1824CE RAM #1 연결

첫 번째 RAM 하나만 연결한다. 이 칩은 주소 0~31을 담당한다.

## 핀 역할

- 1~5번 = 주소 입력 A4~A0
- 6,7,8,10,11,12,13,14번 = 8비트 데이터
- 15번 = CS, 칩 선택
- 16번 = MRD, 읽기 제어
- 17번 = MWR, 쓰기 제어
- 18번 = +5V
- 9번 = GND

## 연결

1. 1번 A4 ← 74HC157 주소 선택 MUX 상위칩 4번 핀 = ADDRESS A4 → 🟨 노랑
2. 2번 A3 ← 74HC157 주소 선택 MUX 하위칩 12번 핀 = ADDRESS A3
3. 3번 A2 ← 주소 선택 MUX 하위칩 9번 핀 = ADDRESS A2
4. 4번 A1 ← 주소 선택 MUX 하위칩 7번 핀 = ADDRESS A1
5. 5번 A0 ← 주소 선택 MUX 하위칩 4번 핀 = ADDRESS A0
6. 6번 D7 ↔ RAM_D7 → 🟩 초록
7. 7번 D6 ↔ RAM_D6
8. 8번 D5 ↔ RAM_D5
9. 9번 → GND
10. 10번 D4 ↔ RAM_D4
11. 11번 D3 ↔ RAM_D3
12. 12번 D2 ↔ RAM_D2
13. 13번 D1 ↔ RAM_D1
14. 14번 D0 ↔ RAM_D0
15. 15번 CS ← 74HC138 RAM 뱅크 디코더 15번 Y0 → 🟧 주황
16. 16번 MRD → 지금은 수동 테스트 점퍼
17. 17번 MWR → 지금은 수동 테스트 점퍼
18. 18번 → +5V

18번과 9번 가까이에 0.1µF 커패시터를 단다.

# 3-5. RAM #1에 값 직접 쓰기

쓰기 테스트에서는 DATA BUS 값을 RAM으로 보내야 한다.

## 준비

1. 74HC245 수동 입력 버스 드라이버로 원하는 값을 DB0~DB7에 만든다.
2. 74HC245 RAM 데이터 버스 드라이버 DIR을 LOW로 둔다. 즉 DATA BUS→RAM 방향이다.
3. RAM 데이터 버스 드라이버 `/OE`를 LOW로 둔다.
4. ADDRESS를 0으로 만든다.
5. RAM 뱅크 디코더에서 RAM #1 선택 출력만 LOW인지 확인한다.
6. CDP1824CE RAM #1 16번 MRD는 HIGH로 둔다.
7. CDP1824CE RAM #1 17번 MWR를 HIGH→LOW→HIGH로 짧게 바꿔 값을 쓴다.

예를 들어 주소 0에 `01010101`을 쓴다.

그다음 주소 1에 `10101010`을 쓴다.

---

# 3-6. RAM #1에서 값 직접 읽기

1. 수동 입력 버스 드라이버의 `/OE`를 HIGH로 해서 DATA BUS에서 뺀다.
2. RAM 데이터 버스 드라이버 DIR을 HIGH로 둔다. RAM→DATA BUS 방향이다.
3. RAM 데이터 버스 드라이버 `/OE`를 LOW로 둔다.
4. CDP1824CE RAM #1 17번 MWR는 HIGH로 둔다.
5. 16번 MRD를 LOW로 둔다.
6. ADDRESS=0에서 DATA BUS가 `01010101`인지 확인한다.
7. ADDRESS=1에서 DATA BUS가 `10101010`인지 확인한다.

두 값이 정확히 따로 저장되면 RAM #1은 정상이다.

---

# 3-7. 나머지 RAM 네 개 추가

RAM #1이 완전히 정상일 때만 다음 네 개를 추가한다.

모든 CDP1824CE RAM은 1~14번, 16~18번 연결이 같다.

15번 CS만 다르다.

- CDP1824CE RAM #2 15번 CS ← 74HC138 RAM 뱅크 디코더 14번 Y1
- CDP1824CE RAM #3 15번 CS ← RAM 뱅크 디코더 13번 Y2
- CDP1824CE RAM #4 15번 CS ← RAM 뱅크 디코더 12번 Y3
- CDP1824CE RAM #5 15번 CS ← RAM 뱅크 디코더 11번 Y4

주소 범위:

- RAM #1 = 0~31
- RAM #2 = 32~63
- RAM #3 = 64~95
- RAM #4 = 96~127
- RAM #5 = 128~159

## 경계 주소 테스트

각 RAM을 한 개씩 추가하면서 양 끝 주소를 시험한다.

- RAM #2: 32, 63
- RAM #3: 64, 95
- RAM #4: 96, 127
- RAM #5: 128, 159

서로 다른 값을 써서 다시 읽는다.
