2. 🟧 Q0(IR0) → U51-2,U51-14
3. 🟩 D0 ← DB0
4. 🟩 D1 ← DB1

6. 🟧 Q2(IR2) → U39-2,U46-3

8. 🟩 D3 ← DB3

12. 🟧 Q4(IR4) → U63-3

### U27 — 74HC139 기본 Opcode Decoder

1. 🟧 /1G ← U15-19
2. 🟧 1A ← U15-15
3. 🟧 1B ← U15-16
4. 🟧 /1Y0=EXT_GROUP_N → U63-1
5. 🟧 /1Y1=LDA_N → U29-9,U42-9
6. 🟧 /1Y2=STA_N → U34-9,U42-4
7. 🟧 /1Y3=ADD_N → U29-10,U30-12
8. ⬛ GND
9. 🟧 /2Y3=HLT_N → U28-10,U41-10
10. 🟧 /2Y2=JMP_N → U31-12
11. 🟧 /2Y1=OUT_N → U28-5,U34-10,U44-1
12. 🟧 /2Y0=SUB_N → U29-13,U30-13,U31-1
13. 🟧 2B ← U15-16
14. 🟧 2A ← U15-15
15. 🟧 /2G ← U46-2
16. 🟥 +5V

### 테스트

U20으로 IR에 다음 값을 넣고 Active-Low 출력이 맞는지 확인한다.

- `00100000` → LDA
- `01000000` → STA
- `01100000` → ADD
- `10000000` → SUB
- `10100000` → OUT
- `11000000` → JMP
- `11100000` → HLT

Active-Low LED는 `+5V → 1kΩ → LED → 출력핀` 방식으로 본다.

## 15단계 — U4/U25 Microstep

### U4 — 74HC161

1. 🟦 RESET_N
2. 🟦 CPU_CLK ← U28-3
3~6. ⬛ A~D → GND
7. 🟥 ENP → +5V
8. ⬛ GND
9. 🟧 /LOAD ← U25-10
10. 🟥 ENT → +5V

12. 🟧 QC → U25-3
13. 🟧 QB → U25-2
14. 🟧 QA → U25-1
15. 배선 없음 RCO
16. 🟥 +5V

### U25 — 74HC138 Microstep Decoder

1. 🟧 A ← U4-14
2. 🟧 B ← U4-13
3. 🟧 C ← U4-12
4. ⬛ /G2A → GND
5. ⬛ /G2B → GND
6. 🟥 G1 → +5V
7. 배선 없음 Y7
8. ⬛ GND
9. 배선 없음 Y6
10. 🟧 Y5(T5_N) → U4-9,U32-10,U40-1,U41-1,U41-4,U41-9,U42-1,U42-5,U42-10,U42-12,U44-2
11. 🟧 Y4(T4_N) → U32-9
12. 🟧 Y3(T3_N) → U39-12,U46-9
13. 배선 없음 Y2
14. 🟧 Y1(T1_N) → U46-5
15. 배선 없음 Y0
16. 🟥 +5V

### 테스트

Clock을 느리게 하고 Y0~Y5에 Active-Low LED를 달아 T0→T1→T2→T3→T4→T5→T0가 반복되는지 확인한다.

6. 🟧 /1Y2=CMP_N → U31-2,U31-5,U32-13

### U63 — 74HC139

1. 🟧 /1G ← U27-4
2. 🟧 1A ← U15-9(IR3)
3. 🟧 1B ← U15-12(IR4)
4. 🟧 /1Y0=EXT_VALID_N → U39-1,U39-4
5~7. 배선 없음
8. ⬛ GND
9. ⬜ /2Y3=LOWPAIR_N → U48-11
10~12. 배선 없음
13. ⬜ 2B ← U64-13
14. ⬜ 2A ← U64-14
15. ⬛ /2G → GND
16. 🟥 +5V

### 확장 명령 테스트

- `00000000` → NOP
- `00000001` → LDI
- `00000010` → CMP
- `00000011` → JZ
- `00000100` → JNZ
- `00000101` → RUN

## 17단계 — U17 OUT Register

1. 🟦 RESET_N
2. 🟩 Q0 → LCD1-7
3. 🟩 D0 ← DB0
4. 🟩 D1 ← DB1
5. 🟩 Q1 → LCD1-8
6. 🟩 Q2 → LCD1-9
7. 🟩 D2 ← DB2
8. 🟩 D3 ← DB3
9. 🟩 Q3 → LCD1-10
10. ⬛ GND
11. 🟦 CLK ← U36-6
12. 🟩 Q4 → LCD1-11
13. 🟩 D4 ← DB4
14. 🟩 D5 ← DB5
15. 🟩 Q5 → LCD1-12
16. 🟩 Q6 → LCD1-13
17. 🟩 D6 ← DB6
18. 🟩 D7 ← DB7
19. 🟩 Q7 → LCD1-14
20. 🟥 +5V

### 테스트

LCD는 아직 연결하지 않아도 된다. Q0~Q7에 LED를 임시로 달고 DATA BUS에 `01000001`을 넣은 뒤 OUT_CLK 한 번으로 같은 값이 저장되는지 확인한다.
