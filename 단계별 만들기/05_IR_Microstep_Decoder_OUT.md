# 5단계 — 명령어 레지스터, 명령 디코더, 마이크로스텝, 출력 레지스터

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호**로 설명한다.

이번 파일의 순서:

```text
74HC273 명령어 레지스터(IR)
↓
74HC139 기본 명령 디코더
↓
74HC161 마이크로스텝 카운터
↓
74HC138 마이크로스텝 디코더
↓
74HC139 확장 명령 디코더
↓
74HC139 확장명령 유효·PS2 카운트 디코더의 확장명령 부분
↓
74HC273 출력 레지스터(OUT)
```

---

# 5-1. 명령어 레지스터(IR)가 뭔가

IR은 Instruction Register의 줄임말이다.

CPU가 메모리에서 읽은 8비트 명령어를 잠깐 저장한다.

예:

```text
00100000 = LDA
01000000 = STA
01100000 = ADD
10000000 = SUB
10100000 = OUT
11000000 = JMP
11100000 = HLT
```

## 74HC273 명령어 레지스터(IR) 연결

1. 1번 `/CLR` → Reset 선. 지금은 +5V, 테스트할 때만 잠깐 GND
2. 2번 Q0 = IR0 → 나중에 확장 명령 디코더 입력
3. 3번 D0 ← DB0
4. 4번 D1 ← DB1
5. 5번 Q1 = IR1 → 나중에 확장 명령 디코더 입력
6. 6번 Q2 = IR2 → 나중에 확장 제어 입력
7. 7번 D2 ← DB2
8. 8번 D3 ← DB3
9. 9번 Q3 = IR3 → 나중에 확장명령 유효 검출 입력
10. 10번 → GND
11. 11번 CLK → 지금은 수동 Clock 테스트선
12. 12번 Q4 = IR4 → 나중에 확장명령 유효 검출 입력
13. 13번 D4 ← DB4
14. 14번 D5 ← DB5
15. 15번 Q5 = IR5 → 기본 명령 디코더 입력
16. 16번 Q6 = IR6 → 기본 명령 디코더 입력
17. 17번 D6 ← DB6
18. 18번 D7 ← DB7
19. 19번 Q7 = IR7 → 기본 명령 디코더 Enable 판단
20. 20번 → +5V

## 단독 테스트

1. 74HC245 수동 입력 버스 드라이버로 `00100000`을 DATA BUS에 만든다.
2. 명령어 레지스터 11번 Clock에 한 번의 상승 펄스를 준다.
3. Q7~Q0가 `00100000`인지 확인한다.
4. `11100000`도 저장해 본다.
5. Clock 없을 때 값이 유지되는지 확인한다.

---

# 5-2. 74HC139 기본 명령 디코더

이 칩은 IR의 상위 3비트를 보고 어떤 기본 명령인지 골라낸다.

출력은 Active-Low라서 **선택된 명령 출력만 LOW**다.

## 연결

1. 1번 `/1G` ← 명령어 레지스터 19번 IR7
2. 2번 1A ← 명령어 레지스터 15번 IR5
3. 3번 1B ← 명령어 레지스터 16번 IR6
4. 4번 `/1Y0` = 확장명령 그룹 선택
5. 5번 `/1Y1` = LDA 선택
6. 6번 `/1Y2` = STA 선택
7. 7번 `/1Y3` = ADD 선택
8. 8번 → GND
9. 9번 `/2Y3` = HLT 선택
10. 10번 `/2Y2` = JMP 선택
11. 11번 `/2Y1` = OUT 선택
12. 12번 `/2Y0` = SUB 선택
13. 13번 2B ← 명령어 레지스터 16번 IR6
14. 14번 2A ← 명령어 레지스터 15번 IR5
15. 15번 `/2G` ← 지금은 테스트용으로 IR7의 반전값을 수동 입력
16. 16번 → +5V

## 기본 명령 테스트

Active-Low LED는:

```text
+5V → 1kΩ → LED → 디코더 출력
```

으로 본다.

- `00100000` 저장 → LDA 출력만 LOW
- `01000000` 저장 → STA 출력만 LOW
- `01100000` 저장 → ADD 출력만 LOW
- `10000000` 저장 → SUB 출력만 LOW
- `10100000` 저장 → OUT 출력만 LOW
- `11000000` 저장 → JMP 출력만 LOW
- `11100000` 저장 → HLT 출력만 LOW

# 5-3. Microstep이 뭔가

명령 하나를 한 번에 처리하지 않고 작은 단계로 나눈다.

```text
T0 → T1 → T2 → T3 → T4 → T5 → 다시 T0
```

74HC161이 현재 몇 번째 단계인지 세고, 74HC138이 그 숫자를 T0~T5 신호로 바꾼다.

---

# 5-4. 74HC161 마이크로스텝 카운터

1. 1번 `/CLR` → Reset 선. 지금은 +5V
2. 2번 CLK → NE555 클럭 발생기 3번 핀으로 임시 테스트
3. 3번 A → GND
4. 4번 B → GND
5. 5번 C → GND
6. 6번 D → GND
7. 7번 ENP → +5V
8. 8번 → GND
9. 9번 `/LOAD` → 나중에 마이크로스텝 디코더 Y5와 연결
10. 10번 ENT → +5V
11. 11번 QD → 사용하지 않음
12. 12번 QC → 마이크로스텝 디코더 3번 C
13. 13번 QB → 마이크로스텝 디코더 2번 B
14. 14번 QA → 마이크로스텝 디코더 1번 A
15. 15번 RCO → 사용하지 않음
16. 16번 → +5V

먼저 9번 `/LOAD`를 +5V에 두고 일반 3비트 카운터처럼 증가하는지 확인한다.

---

# 5-5. 74HC138 마이크로스텝 디코더

1. 1번 A ← 74HC161 마이크로스텝 카운터 14번 QA
2. 2번 B ← 마이크로스텝 카운터 13번 QB
3. 3번 C ← 마이크로스텝 카운터 12번 QC
4. 4번 `/G2A` → GND
5. 5번 `/G2B` → GND
6. 6번 G1 → +5V
7. 7번 Y7 → 사용하지 않음
8. 8번 → GND
9. 9번 Y6 → 사용하지 않음
10. 10번 Y5 → 74HC161 마이크로스텝 카운터 9번 `/LOAD`
11. 11번 Y4 = T4
12. 12번 Y3 = T3
13. 13번 Y2 = T2
14. 14번 Y1 = T1
15. 15번 Y0 = T0
16. 16번 → +5V

74HC138 출력은 Active-Low다.

## 테스트

Y0~Y5에 Active-Low LED를 임시로 단다.

Clock마다:

```text
T0 → T1 → T2 → T3 → T4 → T5 → T0
```

가 반복되는지 확인한다.

T5에서 Y5가 LOW가 되면서 다음 Clock에 카운터가 000으로 Load되어 T0으로 돌아온다.

---

# 5-6. 확장 명령이 뭔가

기본 명령에서 사용하지 않은 `000xxxxx` 영역을 추가 명령으로 쓴다.

```text
00000000 NOP
00000001 LDI
00000010 CMP
00000011 JZ
00000100 JNZ
00000101 RUN
```

---

# 5-7. 74HC139 확장 명령 디코더

이 칩은 IR0~IR2를 보고 위 6개 명령을 구분한다.

1. 1번 `/1G` → 나중에 확장명령 유효 신호와 연결. 지금은 테스트할 때 LOW
2. 2번 1A ← 명령어 레지스터 2번 IR0
3. 3번 1B ← 명령어 레지스터 5번 IR1
4. 4번 `/1Y0` = NOP
5. 5번 `/1Y1` = LDI
6. 6번 `/1Y2` = CMP
7. 7번 `/1Y3` = JZ
8. 8번 → GND
9. 9번 `/2Y3` → 예약
10. 10번 `/2Y2` → 예약
11. 11번 `/2Y1` = RUN
12. 12번 `/2Y0` = JNZ
13. 13번 2B ← 명령어 레지스터 5번 IR1
14. 14번 2A ← 명령어 레지스터 2번 IR0
15. 15번 `/2G` → 테스트할 때 필요한 상태로 수동 제어
16. 16번 → +5V

---

# 5-8. 74HC139 확장명령 유효·PS2 카운트 디코더의 앞쪽 절반

이 칩의 앞쪽 절반은 IR3과 IR4가 둘 다 0인지 확인해서 "정말 000xxxxx 확장 명령인가"를 판정한다.

1. 1번 `/1G` ← 74HC139 기본 명령 디코더 4번 확장그룹 출력
2. 2번 1A ← 명령어 레지스터 9번 IR3
3. 3번 1B ← 명령어 레지스터 12번 IR4
4. 4번 `/1Y0` = EXT_VALID_N
5. 5~7번 → 지금은 사용하지 않음
8. 8번 → GND
16. 16번 → +5V

뒤쪽 절반은 나중 PS/2 단계에서 사용한다.

## 확장 명령 테스트

명령어 레지스터에 다음 값을 차례로 저장해 선택되는 출력 확인:

- `00000000` → NOP
- `00000001` → LDI
- `00000010` → CMP
- `00000011` → JZ
- `00000100` → JNZ
- `00000101` → RUN

---

# 5-9. 74HC273 출력 레지스터(OUT)

출력 레지스터는 A값을 저장해 LED나 LCD 같은 외부 출력에 쓰는 8비트 레지스터다.

1. 1번 `/CLR` → Reset 선
2. 2번 Q0 → 나중에 LCD D0
3. 3번 D0 ← DB0
4. 4번 D1 ← DB1
5. 5번 Q1 → 나중에 LCD D1
6. 6번 Q2 → 나중에 LCD D2
7. 7번 D2 ← DB2
8. 8번 D3 ← DB3
9. 9번 Q3 → 나중에 LCD D3
10. 10번 → GND
11. 11번 CLK → 지금은 수동 Clock 테스트
12. 12번 Q4 → 나중에 LCD D4
13. 13번 D4 ← DB4
14. 14번 D5 ← DB5
15. 15번 Q5 → 나중에 LCD D5
16. 16번 Q6 → 나중에 LCD D6
17. 17번 D6 ← DB6
18. 18번 D7 ← DB7
19. 19번 Q7 → 나중에 LCD D7
20. 20번 → +5V

## 테스트

1. 수동 입력 버스 드라이버로 DATA BUS에 `01000001`을 만든다.
2. 출력 레지스터 11번 Clock에 한 번의 상승 펄스를 준다.
3. Q7~Q0가 `01000001`인지 확인한다.
4. DATA BUS 값을 바꿔도 Clock 없으면 출력값이 유지되어야 한다.
