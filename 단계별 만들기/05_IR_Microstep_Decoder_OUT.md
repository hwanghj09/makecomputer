# 5단계 — 명령어 레지스터, 명령 디코더, Microstep, OUT

이번 단계에서는 CPU가 **무슨 명령인지 기억하고**, 그 명령을 해석하고, 한 명령을 여러 작은 순서로 나누는 회로를 만든다.

순서는 다음과 같다.

```text
74HC273 명령어 레지스터(IR)
↓
74HC139 기본 명령 디코더
↓
74HC161 마이크로스텝 카운터
↓
74HC138 마이크로스텝 디코더
↓
74HC139 확장 명령 디코더
↓
74HC273 출력 레지스터(OUT)
```

## 점퍼선 색

- 🟥 빨강 = +5V / HIGH
- ⬛ 검정 = GND / LOW
- 🟩 초록 = DATA
- 🟦 파랑 = CLOCK / RESET
- 🟧 주황 = CONTROL / 명령 해석
- ⬜ 흰색 = STATUS / SPECIAL

---

# 5-1. 74HC273 명령어 레지스터(IR)

IR은 현재 실행할 8비트 명령어를 기억한다.

## 지금 연결

1. 🟦 **파랑** — 1번 `/CLR` → RESET 선
2. 🟧 **주황** — 2번 `Q0(IR0)` → 74HC139 확장 명령 디코더 2번, 14번
3. 🟩 **초록** — 3번 `D0` ← DB0
4. 🟩 **초록** — 4번 `D1` ← DB1
5. 🟧 **주황** — 5번 `Q1(IR1)` → 확장 명령 디코더 3번, 13번
6. 🟧 **주황** — 6번 `Q2(IR2)` → 지금은 테스트점. 자동 제어 연결은 6단계
7. 🟩 **초록** — 7번 `D2` ← DB2
8. 🟩 **초록** — 8번 `D3` ← DB3
9. 🟧 **주황** — 9번 `Q3(IR3)` → 확장명령 유효 디코더 2번
10. ⬛ **검정** — 10번 GND → GND
11. 🟦 **파랑** — 11번 `CLK` → 지금은 수동 IR_CLK 테스트선
12. 🟧 **주황** — 12번 `Q4(IR4)` → 확장명령 유효 디코더 3번
13. 🟩 **초록** — 13번 `D4` ← DB4
14. 🟩 **초록** — 14번 `D5` ← DB5
15. 🟧 **주황** — 15번 `Q5(IR5)` → 기본 명령 디코더 2번, 14번
16. 🟧 **주황** — 16번 `Q6(IR6)` → 기본 명령 디코더 3번, 13번
17. 🟩 **초록** — 17번 `D6` ← DB6
18. 🟩 **초록** — 18번 `D7` ← DB7
19. 🟧 **주황** — 19번 `Q7(IR7)` → 기본 명령 디코더 1번. 자동 제어용 추가 연결은 6단계
20. 🟥 **빨강** — 20번 VCC → +5V
21. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### IR 단독 테스트

1. 수동 입력 버스 드라이버로 DB0~DB7에 예를 들어 `00100000`을 넣는다.
2. 🟦 IR 11번에 한 번의 상승 Clock pulse를 준다.
3. Q0~Q7에 같은 값이 저장되는지 확인한다.

# 5-2. 74HC139 기본 명령 디코더

상위 세 비트 `IR7 IR6 IR5`를 보고 LDA, STA, ADD, SUB, OUT, JMP, HLT를 구분한다.
출력은 Active-Low다.

1. 🟧 **주황** — 1번 `/1G` ← IR 19번 `IR7`
2. 🟧 **주황** — 2번 `1A` ← IR 15번 `IR5`
3. 🟧 **주황** — 3번 `1B` ← IR 16번 `IR6`
4. 🟧 **주황** — 4번 `/1Y0` = EXT_GROUP_N → 확장명령 유효 디코더 1번
5. 🟧 **주황** — 5번 `/1Y1` = LDA_N → 지금은 LED 테스트점
6. 🟧 **주황** — 6번 `/1Y2` = STA_N → 지금은 LED 테스트점
7. 🟧 **주황** — 7번 `/1Y3` = ADD_N → 지금은 LED 테스트점
8. ⬛ **검정** — 8번 GND → GND
9. 🟧 **주황** — 9번 `/2Y3` = HLT_N → 지금은 LED 테스트점
10. 🟧 **주황** — 10번 `/2Y2` = JMP_N → 지금은 LED 테스트점
11. 🟧 **주황** — 11번 `/2Y1` = OUT_N → 지금은 LED 테스트점
12. 🟧 **주황** — 12번 `/2Y0` = SUB_N → 지금은 LED 테스트점
13. 🟧 **주황** — 13번 `2B` ← IR 16번 IR6
14. 🟧 **주황** — 14번 `2A` ← IR 15번 IR5
15. 🟧 **주황** — 15번 `/2G` ← IR7의 반전값이 최종 연결. **지금은 테스트를 위해 직접 LOW/HIGH를 넣어 확인**
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### 테스트

Active-Low LED는 다음처럼 연결한다.

```text
+5V ─ 🟥 ─ 1kΩ ─ LED ─ 🟧 ─ 디코더 출력
```

IR에 값을 저장해 다음이 맞는지 본다.

- `00100000` → LDA_N 선택
- `01000000` → STA_N
- `01100000` → ADD_N
- `10000000` → SUB_N
- `10100000` → OUT_N
- `11000000` → JMP_N
- `11100000` → HLT_N

# 5-3. 74HC161 마이크로스텝 카운터

CPU는 한 명령을 한 번에 처리하지 않고 `T0 → T1 → ... → T5`로 나눠 처리한다.

1. 🟦 **파랑** — 1번 `/CLR` → RESET 선
2. 🟦 **파랑** — 2번 CLK ← 지금은 NE555 Clock으로 직접 테스트. 6단계에서 CPU_CLK로 교체
3. ⬛ **검정** — 3번 A → GND
4. ⬛ **검정** — 4번 B → GND
5. ⬛ **검정** — 5번 C → GND
6. ⬛ **검정** — 6번 D → GND
7. 🟥 **빨강** — 7번 ENP → +5V
8. ⬛ **검정** — 8번 GND → GND
9. 🟧 **주황** — 9번 `/LOAD` ← 마이크로스텝 디코더 10번 Y5
10. 🟥 **빨강** — 10번 ENT → +5V
11. — **배선 없음** — 11번 QD
12. 🟧 **주황** — 12번 QC → 마이크로스텝 디코더 3번 C
13. 🟧 **주황** — 13번 QB → 마이크로스텝 디코더 2번 B
14. 🟧 **주황** — 14번 QA → 마이크로스텝 디코더 1번 A
15. — **배선 없음** — 15번 RCO
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

# 5-4. 74HC138 마이크로스텝 디코더

1. 🟧 **주황** — 1번 A ← 마이크로스텝 카운터 14번 QA
2. 🟧 **주황** — 2번 B ← 마이크로스텝 카운터 13번 QB
3. 🟧 **주황** — 3번 C ← 마이크로스텝 카운터 12번 QC
4. ⬛ **검정** — 4번 `/G2A` → GND
5. ⬛ **검정** — 5번 `/G2B` → GND
6. 🟥 **빨강** — 6번 `G1` → +5V
7. — **배선 없음** — 7번 Y7
8. ⬛ **검정** — 8번 GND → GND
9. — **배선 없음** — 9번 Y6
10. 🟧 **주황** — 10번 `Y5(T5_N)` → 마이크로스텝 카운터 9번 `/LOAD`, 6단계 제어회로에도 연결
11. 🟧 **주황** — 11번 `Y4(T4_N)` → 6단계에서 연결
12. 🟧 **주황** — 12번 `Y3(T3_N)` → 6단계에서 연결
13. — **배선 없음** — 13번 Y2
14. 🟧 **주황** — 14번 `Y1(T1_N)` → 6단계에서 연결
15. — **배선 없음** — 15번 Y0는 테스트 LED만 사용 가능
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### Microstep 테스트

Y0~Y5를 Active-Low LED로 보면서:

```text
T0 → T1 → T2 → T3 → T4 → T5 → T0
```

가 반복되는지 확인한다.

# 5-5. 74HC139 확장명령 유효 디코더

이 칩의 **첫 번째 절반**은 `000xxxxx` 확장명령이 유효한지 확인한다.
두 번째 절반은 PS/2용이므로 9단계까지 비활성으로 둔다.

1. 🟧 **주황** — 1번 `/1G` ← 기본 명령 디코더 4번 EXT_GROUP_N
2. 🟧 **주황** — 2번 `1A` ← IR 9번 IR3
3. 🟧 **주황** — 3번 `1B` ← IR 12번 IR4
4. 🟧 **주황** — 4번 `/1Y0` = EXT_VALID_N → 6단계에서 연결
5. — **배선 없음** — 5번 /1Y1
6. — **배선 없음** — 6번 /1Y2
7. — **배선 없음** — 7번 /1Y3
8. ⬛ **검정** — 8번 GND → GND
9. — **배선 없음** — 9~12번 출력은 PS/2 단계 전까지 사용 안 함
10. ⬛ **검정** — 13번 `2B` → GND 임시 고정
11. ⬛ **검정** — 14번 `2A` → GND 임시 고정
12. 🟥 **빨강** — 15번 `/2G` → +5V 임시로 비활성. 9단계에서 GND로 교체
13. 🟥 **빨강** — 16번 VCC → +5V
14. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

# 5-6. 74HC139 확장 명령 디코더

이 칩은 `NOP, LDI, CMP, JZ, JNZ, RUN`을 구분한다.

아직 자동 Enable 회로가 없으므로 테스트 때 `/1G`, `/2G`에 직접 LOW/HIGH를 넣는다.

1. 🟧 **주황** — 1번 `/1G` → 테스트용 Enable. 사용할 때 ⬛ LOW
2. 🟧 **주황** — 2번 `1A` ← IR 2번 IR0
3. 🟧 **주황** — 3번 `1B` ← IR 5번 IR1
4. 🟧 **주황** — 4번 `/1Y0` = NOP_N → 6단계에서 연결
5. 🟧 **주황** — 5번 `/1Y1` = LDI_N → 6단계에서 연결
6. 🟧 **주황** — 6번 `/1Y2` = CMP_N → 6단계에서 연결
7. 🟧 **주황** — 7번 `/1Y3` = JZ_N → 6단계에서 연결
8. ⬛ **검정** — 8번 GND → GND
9. — **배선 없음** — 9번 /2Y3 예약
10. — **배선 없음** — 10번 /2Y2 예약
11. 🟧 **주황** — 11번 `/2Y1` = RUN_N → 6단계에서 연결
12. 🟧 **주황** — 12번 `/2Y0` = JNZ_N → 6단계에서 연결
13. 🟧 **주황** — 13번 `2B` ← IR 5번 IR1
14. 🟧 **주황** — 14번 `2A` ← IR 2번 IR0
15. 🟧 **주황** — 15번 `/2G` → 테스트용 Enable. 사용할 때 ⬛ LOW
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### 테스트

IR을 다음 값으로 바꾸며 해당 출력만 LOW가 되는지 본다.

- `00000000` → NOP
- `00000001` → LDI
- `00000010` → CMP
- `00000011` → JZ
- `00000100` → JNZ
- `00000101` → RUN

# 5-7. 74HC273 출력 레지스터(OUT)

OUT은 계산 결과를 외부에서 볼 수 있도록 8비트를 저장한다.

1. 🟦 **파랑** — 1번 `/CLR` → RESET
2. 🟩 **초록** — 2번 Q0 → 지금은 LED 테스트점, 8단계에서 LCD D0
3. 🟩 **초록** — 3번 D0 ← DB0
4. 🟩 **초록** — 4번 D1 ← DB1
5. 🟩 **초록** — 5번 Q1 → LED, 나중에 LCD D1
6. 🟩 **초록** — 6번 Q2 → LED, 나중에 LCD D2
7. 🟩 **초록** — 7번 D2 ← DB2
8. 🟩 **초록** — 8번 D3 ← DB3
9. 🟩 **초록** — 9번 Q3 → LED, 나중에 LCD D3
10. ⬛ **검정** — 10번 GND → GND
11. 🟦 **파랑** — 11번 CLK → 지금은 수동 OUT_CLK. 6단계에서 자동선으로 교체
12. 🟩 **초록** — 12번 Q4 → LED, 나중에 LCD D4
13. 🟩 **초록** — 13번 D4 ← DB4
14. 🟩 **초록** — 14번 D5 ← DB5
15. 🟩 **초록** — 15번 Q5 → LED, 나중에 LCD D5
16. 🟩 **초록** — 16번 Q6 → LED, 나중에 LCD D6
17. 🟩 **초록** — 17번 D6 ← DB6
18. 🟩 **초록** — 18번 D7 ← DB7
19. 🟩 **초록** — 19번 Q7 → LED, 나중에 LCD D7
20. 🟥 **빨강** — 20번 VCC → +5V
21. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### 테스트

DATA BUS에 `01000001`을 넣고 OUT 11번에 한 번의 🟦 Clock pulse를 준다.
Q 출력이 `01000001`을 유지하면 정상이다.
