# 1단계 — 전원과 NE555 클럭

이 파일에서는 **전원과 NE555 클럭만** 만든다.

아직 `DB`, `ADDRESS`, `PC`, `MAR`, `U28` 같은 말은 몰라도 된다. **이 단계에서는 그런 선을 연결하지 않는다.**

> 원칙: 지금 만드는 부품에 필요한 것만 연결하고, 나중 부품으로 가는 선은 나중 단계에서 연결한다.

---

## 1-0. 오늘 만들 것

이번 단계가 끝나면 딱 이것만 된다.

```text
5V 전원
  ↓
NE555
  ↓
LED가 깜빡깜빡
```

이 깜빡임이 나중에 컴퓨터 전체의 박자가 된다.

---

# 1-1. 먼저 용어 4개만 알기

## +5V

IC가 동작하기 위한 전원이다.

- 점퍼선 색: **빨강**
- 브레드보드의 `+` 전원 레일에 연결한다.

## GND

전기의 기준점이다.

- 점퍼선 색: **검정**
- 브레드보드의 `-` 전원 레일에 연결한다.

## IC

NE555 같은 검은색 칩을 말한다.

## 핀 번호

IC 다리 번호다.

NE555를 위에서 보고 홈/점 표시를 기준으로 번호를 센다.

```text
        홈
     ┌─────┐
  1  │     │ 8
  2  │555  │ 7
  3  │     │ 6
  4  │     │ 5
     └─────┘
```

왼쪽 위가 1번이고 반시계 방향으로 센다.

---

# 1-2. 브레드보드 전원부터 만들기

**아직 NE555를 꽂지 말고 전원부터 확인한다.**

### 연결

1. 5V 어댑터 `+` → 브레드보드 `+` 레일  **[빨강]**
2. 5V 어댑터 `- / GND` → 브레드보드 `-` 레일 **[검정]**
3. 전원 레일이 가운데에서 끊긴 브레드보드라면:
   - `+` 왼쪽 ↔ `+` 오른쪽 **[빨강]**
   - `-` 왼쪽 ↔ `-` 오른쪽 **[검정]**

여러 브레드보드를 사용한다면 모든 `+`끼리 빨강으로, 모든 `-`끼리 검정으로 연결한다.

### 테스트

멀티미터를 **DC 전압** 모드로 놓는다.

```text
빨간 프로브 → + 레일
검은 프로브 → - 레일
```

약 `5V`가 나오면 정상이다.

### 여기서 멈춰서 확인

- [ ] + 레일이 약 5V
- [ ] - 레일이 GND
- [ ] 9V를 직접 넣고 있지 않음

정상이 아니면 NE555를 꽂지 않는다.

---

# 1-3. NE555를 브레드보드에 꽂기

NE555를 브레드보드 가운데 홈을 가로질러 꽂는다.

홈 또는 점 표시가 위쪽을 향하게 두면 핀 번호를 보기 쉽다.

```text
        홈
     ┌─────┐
1 GND│     │8 +5V
2    │ 555 │7
3 OUT│     │6
4    │     │5
     └─────┘
```

---

# 1-4. NE555 전원 핀만 먼저 연결

아직 타이밍 회로는 만들지 않는다.

1. **U1 1번 핀 → GND** **[검정]**
2. **U1 8번 핀 → +5V** **[빨강]**
3. **U1 4번 핀 → +5V** **[빨강]**

4번 핀은 RESET 핀이다. 지금은 항상 동작하게 +5V에 고정한다.

### 테스트

전원을 잠깐 켜고:

- U1 8번과 1번 사이가 약 5V인지 확인
- 칩이 뜨거워지지 않는지 확인

뜨거워지면 즉시 전원을 끄고 방향/핀 번호를 다시 본다.

---

# 1-5. 0.1µF 디커플링 커패시터 달기

NE555 바로 옆에 0.1µF 세라믹 커패시터 하나를 단다.

```text
U1 8번(+5V) ──┐
              │
            0.1µF
              │
U1 1번(GND) ──┘
```

- +5V 쪽 짧은 연결: **빨강**
- GND 쪽 짧은 연결: **검정**
- 세라믹 0.1µF는 방향이 없다.

왜 다냐면, IC가 순간적으로 전류를 사용할 때 전압이 흔들리는 것을 줄이기 위해서다.

---

# 1-6. NE555 타이밍 회로 만들기

지금 사용하는 NE555 클럭 회로는 아래처럼 연결한다.

필요한 것:

- 1kΩ 저항
- 10kΩ 가변저항 또는 현재 정상 동작 중인 저항값
- 전해 커패시터

```text
+5V
 │
1kΩ
 │
U1 7번
 │
10kΩ 가변저항
 │
●──────── U1 2번
├──────── U1 6번
│
전해 커패시터 (+)
│
전해 커패시터 (-)
│
GND
```

### 한 줄씩 연결

1. +5V → 1kΩ 저항 → **U1 7번**
2. **U1 7번** → 가변저항 → 공통점 `●`
3. 공통점 `●` → **U1 2번**
4. 공통점 `●` → **U1 6번**
5. 공통점 `●` → 전해 커패시터 `+`
6. 전해 커패시터 `-` → GND

U1 2번과 6번은 같은 공통점에 연결된다.

> 전해 커패시터는 극성이 있다. `+`와 `-`를 반대로 꽂지 않는다.

---

# 1-7. 출력 LED 연결

**U1 3번 핀**이 클럭 출력이다.

지금은 나중 회로에 연결하지 않는다.

테스트용으로만:

```text
U1 3번
  │
  ├── 1kΩ 저항 ── LED ── GND
```

- U1 3번에서 LED 테스트선: **파랑**
- LED 뒤 GND: **검정**

LED 방향이 반대면 안 켜질 수 있으므로 안 켜지면 LED 방향도 확인한다.

---

# 1-8. 최종 테스트

전원을 켠다.

정상이면:

1. LED가 켜졌다 꺼졌다 반복한다.
2. 가변저항을 돌리면 속도가 바뀐다.
3. U1이 뜨거워지지 않는다.
4. U1 8번 ↔ 1번 사이가 약 5V다.

### 안 되면 이 순서만 확인

1. U1 방향
2. U1-1 = GND
3. U1-8 = +5V
4. U1-4 = +5V
5. U1-2와 U1-6이 같은 점인지
6. U1-7 저항 연결
7. 전해 커패시터 극성
8. LED 방향

---

# 1-9. 이 단계가 끝났을 때 남겨둘 연결

최종적으로 지금 남아 있어야 하는 것은:

```text
U1-1 → GND
U1-4 → +5V
U1-8 → +5V
U1-2 ↔ U1-6 ↔ 타이밍 RC
U1-7 → 타이밍 저항망
U1-3 → 현재는 테스트 LED만
```

**U1-3을 U28 같은 나중 IC에 아직 연결하지 않는다.**

그 연결은 제어회로 단계에서 다시 알려준다.
