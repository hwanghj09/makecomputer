# 1단계 — 전원과 NE555 클럭

이 단계에서는 컴퓨터의 가장 기본이 되는 **5V 전원**과 **Clock**만 만든다.
아직 PC, RAM, DATA BUS는 연결하지 않는다.

```text
5V 전원
↓
모든 브레드보드의 공통 GND
↓
NE555 Clock
↓
LED로 Clock 확인
```

---

# 먼저 꼭 알아둘 것

이 설명서에서는 점퍼선 색으로 회로를 구분하지 않는다.
대신 항상 **부품 이름 + 핀 번호 + 연결 위치**로 설명한다.

예:

```text
NE555 8번 VCC → +5V
NE555 1번 GND → GND
```

또한 앞으로 다음 표현을 자주 사용한다.

```text
HIGH = +5V
LOW  = GND
```

`/RESET`, `/OE`, `/CLR`처럼 이름 앞에 `/`가 붙거나 `_N`으로 끝나는 신호는 대부분 **LOW일 때 동작하는 Active-Low 신호**다.

---

# 1-1. 브레드보드 전원부터 연결

반드시 **전원을 끈 상태에서 배선**한다.

## 연결

1. 5V 전원 공급기의 `+5V` → 브레드보드 `+` 전원 레일
2. 5V 전원 공급기의 `GND` → 브레드보드 `-` 전원 레일
3. 전원 레일이 중간에서 끊어진 브레드보드라면 `+5V 레일 ↔ +5V 레일`을 점퍼로 연결
4. 같은 방식으로 `GND 레일 ↔ GND 레일`도 연결
5. 브레드보드가 여러 개라면 **모든 +5V 레일끼리 연결**
6. 브레드보드가 여러 개라면 **모든 GND 레일끼리 연결**

## 전원 테스트

멀티미터를 DC 전압 모드로 둔다.

```text
검정 프로브 → GND
빨강 프로브 → +5V
```

약 `5V`가 나오면 정상이다.

브레드보드가 여러 개라면 각 보드의 전원 레일에서 똑같이 측정한다.

**어느 한 곳이라도 5V가 나오지 않으면 다음 단계로 가지 않는다.**

---

# 1-2. 0.1µF 디커플링 커패시터

앞으로 IC를 하나 추가할 때마다 그 IC의 **VCC와 GND 바로 가까운 곳에 0.1µF 세라믹 커패시터 하나**를 연결한다.

```text
IC VCC ──┐
          │
        0.1µF
          │
IC GND ──┘
```

0.1µF 세라믹 커패시터는 극성이 없으므로 방향은 상관없다.

이 커패시터는 Clock이 바뀌는 순간 전원 전압이 흔들리는 것을 줄여준다.

---

# 1-3. NE555 핀 위치 확인

NE555의 홈 또는 점 표시를 기준으로 핀 번호를 확인한다.

```text
        홈
     ┌───────┐
1 GND│       │8 VCC
2 TR │ NE555 │7 DISCH
3 OUT│       │6 THRESH
4 RST│       │5 CTRL
     └───────┘
```

칩을 반대로 보면 핀 번호도 반대로 보이므로, 배선 전에 1번 핀 위치부터 확인한다.

---

# 1-4. NE555 기본 배선

현재 이미 정상 동작하는 저항, 가변저항, 타이밍 커패시터 값은 그대로 유지한다.

## 전원과 제어핀

```text
NE555 1번 GND   → GND
NE555 4번 RESET → +5V
NE555 8번 VCC   → +5V
```

NE555 4번 RESET은 LOW가 되면 Clock이 멈추므로 평상시에는 +5V에 둔다.

## 타이밍 부분

```text
NE555 2번 TRIG   ↔ NE555 6번 THRESH
NE555 7번 DISCH  → 현재 사용 중인 타이밍 저항/가변저항 회로
NE555 5번 CTRL   → 10nF 커패시터 → GND
```

## Clock 출력

```text
NE555 3번 OUT → RAW_CLK
```

앞으로 다른 칩의 Clock 입력에는 이 `RAW_CLK`를 사용한다.

NE555 바로 옆에도:

```text
NE555 8번 VCC ↔ 0.1µF ↔ NE555 1번 GND
```

을 연결한다.

---

# 1-5. Clock LED 테스트

아직 PC 같은 다른 IC는 연결하지 않는다.

NE555 3번 OUT이 실제로 HIGH/LOW를 반복하는지만 먼저 확인한다.

## LED 연결

LED를 NE555 출력에 직접 연결하지 말고 **330Ω~1kΩ 저항을 직렬로 사용**한다.

예:

```text
NE555 3번 OUT
   ↓
330Ω~1kΩ
   ↓
LED
   ↓
GND
```

## 테스트

1. 전원을 켠다.
2. LED가 반복해서 켜졌다 꺼지는지 확인한다.
3. 가변저항을 돌린다.
4. LED 깜빡임 속도가 변하는지 확인한다.

## 정상이면

- LED가 계속 깜빡인다.
- 가변저항을 돌리면 속도가 변한다.
- NE555 8번과 1번 사이를 측정하면 약 5V가 나온다.

## LED가 계속 켜져 있거나 전혀 안 켜지면

다음 순서로 확인한다.

1. NE555 방향과 1번 핀 위치
2. NE555 1번이 GND인지
3. NE555 8번이 +5V인지
4. NE555 4번 RESET이 +5V인지
5. NE555 2번과 6번이 실제로 연결되어 있는지
6. NE555 7번의 타이밍 저항/가변저항 연결
7. 전해 타이밍 커패시터를 사용했다면 극성
8. 브레드보드 전원 레일이 중간에서 끊겨 있지 않은지

이 테스트가 성공한 뒤에만 PC를 연결한다.
