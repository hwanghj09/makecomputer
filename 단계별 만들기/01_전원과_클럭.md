# 1단계 — 전원과 NE555 클럭

이번 파일에서는 **전원과 Clock만** 만든다.

아직 `PC`, `MAR`, `DATA BUS`, `U28` 같은 것은 몰라도 된다.

---

# 1. 이번 단계에서 처음 배우는 말

## +5V
컴퓨터 IC에 공급하는 전원이다.

이 프로젝트의 74HC 계열과 CDP1824CE, EEPROM 등 논리 회로는 **+5V**를 기준으로 사용한다.

점퍼선 색은 **빨강**이다.

## GND
전기의 기준점인 0V다.

모든 브레드보드와 모든 IC의 GND는 서로 연결되어 있어야 한다.

점퍼선 색은 **검정**이다.

## HIGH / LOW
디지털 회로는 두 상태를 사용한다.

```text
HIGH ≈ +5V
LOW  ≈ 0V = GND
```

## Clock
Clock은 컴퓨터의 박자다.

```text
LOW → HIGH → LOW → HIGH → ...
```

처럼 계속 반복되는 신호다.

점퍼선 색은 **파랑**이다.

## Reset
Reset은 여러 IC를 처음 상태로 되돌리는 신호다.

이 컴퓨터에서는 나중에 여러 칩이 같은 Reset 선을 공유한다.

## 디커플링 커패시터
IC가 순간적으로 전류를 필요로 할 때 전원 흔들림을 줄여 주는 작은 커패시터다.

각 IC의 전원핀과 GND핀 사이에 **0.1µF 세라믹 커패시터**를 하나씩 둔다.

---

# 2. 가장 먼저 브레드보드 전원을 만든다

전원은 끈 상태에서 작업한다.

## 2-1. 전원 레일 확인
브레드보드 옆의 긴 줄을 전원 레일로 사용한다.

```text
빨간 레일 = +5V
파란/검은 레일 = GND
```

실제 점퍼선은:

- +5V → 🟥 빨강
- GND → ⬛ 검정

으로 통일한다.

## 2-2. 5V 전원 연결

1. 5V 전원장치의 `+` → 브레드보드 + 레일
2. 전원장치의 `-` 또는 GND → 브레드보드 GND 레일
3. 브레드보드 전원 레일이 중간에서 끊긴 타입이면 양쪽을 점퍼로 연결
4. 브레드보드를 여러 장 쓰면 모든 +5V끼리 연결
5. 모든 GND끼리 연결

## 2-3. 아직 IC를 꽂지 말고 전압부터 측정
멀티미터를 DC 전압 모드로 둔다.

- 검정 프로브 → GND
- 빨강 프로브 → +5V

정상이라면 약 5V가 나온다.

### 정상 기준

```text
약 4.8V ~ 5.2V
```

정도가 나오면 다음으로 간다.

5V가 아니면 IC를 꽂지 않는다.

---

# 3. Reset 선을 하나 만들어 둔다

아직 다른 IC에는 연결하지 않는다.

이 단계에서는 Reset이라는 공용 선만 만든다.

## 필요한 것
- 10kΩ 저항 1개
- 푸시 버튼 1개
- 파랑 점퍼선

## 연결

```text
+5V
 │
10kΩ
 │
 ●──── 앞으로 사용할 RESET 선
 │
버튼
 │
GND
```

평상시에는 10kΩ 때문에 RESET 선이 HIGH다.

버튼을 누르면 GND에 연결되어 LOW가 된다.

이 선은 앞으로 **RESET_N**이라고 부른다.

`_N`은 LOW일 때 동작하는 신호라는 뜻이다.

아직 다른 IC에는 연결하지 않는다.

---

# 4. U1 NE555를 꽂는다

NE555는 Clock을 만드는 칩이다.

IC의 홈이 위로 오게 놓는다.

```text
        홈
      ┌───────┐
1 GND │       │ 8 VCC
2 TRIG│ NE555 │ 7 DISCH
3 OUT │       │ 6 THRESH
4 RST │       │ 5 CTRL
      └───────┘
```

이번 문서에서는 이 칩을 **U1**이라고 부른다.

---

# 5. U1 전원핀부터 연결

전원을 끈다.

1. **U1-1 → GND** — ⬛ 검정
2. **U1-8 → +5V** — 🟥 빨강
3. **U1-4 → +5V** — 🟥 빨강

U1-4는 Reset 입력이다. Clock을 계속 동작시키기 위해 HIGH로 둔다.

---

# 6. U1에 0.1µF 디커플링을 단다

0.1µF 세라믹 커패시터는 극성이 없다.

U1 바로 옆에서:

```text
U1-8(+5V) ── 0.1µF ── U1-1(GND)
```

처럼 연결한다.

가능하면 선을 길게 빼지 말고 IC 바로 옆에 둔다.

---

# 7. NE555 타이밍 부분 연결

현재 이미 정상 동작한 NE555 타이밍 저항/가변저항/커패시터 조합이 있다면 **그 값을 그대로 유지**한다.

핵심 연결은 다음이다.

1. **U1-2와 U1-6을 서로 연결** — 🟦 파랑
2. U1-7은 타이밍 저항/가변저항 쪽에 연결 — 🟦 파랑
3. U1-2/U1-6 공통점은 타이밍 커패시터 쪽에 연결 — 🟦 파랑
4. U1-5는 10nF 정도를 GND로 연결하면 노이즈 억제에 도움이 된다 — ⬜ 흰색 → 커패시터 → ⬛ GND

U1-3은 아직 다른 IC에 연결하지 않는다.

U1-3이 Clock 출력이다.

---

# 8. U1-3 Clock을 LED로 시험

## 필요한 것
- LED 1개
- 330Ω~1kΩ 저항 1개

## 연결

```text
U1-3 ── 저항 ── LED ── GND
```

LED 방향이 반대면 안 켜질 수 있다.

## 시험

1. 전원을 켠다.
2. LED가 반복해서 켜졌다 꺼지는지 본다.
3. 가변저항이 있다면 천천히 돌린다.
4. 깜빡이는 속도가 달라지는지 본다.

## 정상

```text
켜짐 → 꺼짐 → 켜짐 → 꺼짐 ...
```

이 반복되고 속도 조절도 된다.

---

# 9. 멀티미터로 마지막 확인

전원을 켠 상태에서:

- U1-8 ↔ U1-1 = 약 5V
- U1-4 ↔ U1-1 = 약 5V
- U1-3은 시간에 따라 HIGH/LOW 반복

을 확인한다.
