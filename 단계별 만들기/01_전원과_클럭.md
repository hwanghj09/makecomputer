# 1단계 — 전원과 NE555 클럭

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호**로 설명한다.

## 이번 단계에서 만드는 것

딱 두 가지만 만든다.

1. 브레드보드 전체에 +5V와 GND 공급
2. NE555로 천천히 깜빡이는 Clock 만들기

아직 Program Counter, RAM, 데이터 버스 같은 것은 생각하지 않아도 된다.

---

# 1-1. 브레드보드 전원부터 만들기

## 필요한 것
- 5V 안정화 어댑터
- 브레드보드
- 빨강 점퍼선
- 검정 점퍼선
- 멀티미터

## 연결

1. 어댑터의 +5V를 브레드보드 `+` 전원 레일에 연결한다. → 🟥 빨강
2. 어댑터의 GND를 브레드보드 `-` 전원 레일에 연결한다. → ⬛ 검정
3. 전원 레일이 중간에서 끊긴 브레드보드라면 양쪽 +레일을 빨강으로 이어준다.
4. 양쪽 GND 레일도 검정으로 이어준다.
5. 브레드보드를 여러 개 쓴다면 모든 +5V끼리, 모든 GND끼리 연결한다.

## 테스트

1. 전원을 켠다.
2. 멀티미터를 DC 전압 모드로 둔다.
3. 검정 프로브는 GND, 빨강 프로브는 +5V 레일에 댄다.
4. 약 5V가 나오는지 확인한다.
5. 브레드보드 앞/뒤/중간에서 모두 약 5V인지 확인한다.
6. 확인이 끝나면 전원을 끈다.

정상이 아니면 다음으로 넘어가지 않는다.

# 1-2. 0.1µF 디커플링 커패시터 이해하기

앞으로 IC를 하나 꽂을 때마다 그 IC의 VCC와 GND 가까이에 0.1µF 세라믹 커패시터를 하나 단다.

```text
IC VCC ──┐
         │
       0.1µF
         │
IC GND ──┘
```

이 커패시터는 IC가 Clock 순간에 전류를 갑자기 필요로 할 때 전원 흔들림을 줄여준다.

0.1µF 세라믹 커패시터는 극성이 없으므로 방향은 상관없다.

# 1-3. NE555 클럭 발생기 꽂기

## NE555 핀 방향

홈 또는 점 표시를 확인한다.

```text
        홈
     ┌───────┐
  1  │       │ 8
  2  │ NE555 │ 7
  3  │       │ 6
  4  │       │ 5
     └───────┘
```

## 핀 역할

- 1번 = GND
- 2번 = Trigger
- 3번 = Clock 출력
- 4번 = Reset
- 5번 = Control
- 6번 = Threshold
- 7번 = Discharge
- 8번 = +5V

## 실제 연결

1. NE555 클럭 발생기 1번 핀 → GND → ⬛ 검정
2. NE555 클럭 발생기 8번 핀 → +5V → 🟥 빨강
3. NE555 클럭 발생기 4번 핀 → +5V → 🟥 빨강
4. NE555 클럭 발생기 2번 핀 ↔ NE555 클럭 발생기 6번 핀 → 🟦 파랑
5. +5V → 1kΩ 저항 → NE555 클럭 발생기 7번 핀
6. NE555 클럭 발생기 7번 핀 → 10kΩ 가변저항/저항 → 2번·6번이 만나는 점
7. 2번·6번이 만나는 점 → 전해커패시터 `+`
8. 전해커패시터 `-` → GND
9. NE555 클럭 발생기 5번 핀 → 10nF 커패시터 → GND 권장
10. NE555 클럭 발생기 8번 핀과 1번 핀 가까이에 0.1µF 세라믹 커패시터를 단다.

> 이미 지금 NE555 Clock이 정상 동작하고 있다면 기존 저항/가변저항/커패시터 값은 그대로 유지한다.

# 1-4. Clock 출력 테스트

Clock 출력은 **NE555 클럭 발생기 3번 핀**이다.

테스트용 LED를 이렇게 연결한다.

```text
NE555 3번 핀
   ↓
1kΩ 저항
   ↓
LED
   ↓
GND
```

## 확인 순서

1. 전원을 켠다.
2. LED가 일정하게 켜졌다 꺼지는지 본다.
3. 가변저항을 돌리면 깜빡이는 속도가 달라지는지 본다.
4. 멀티미터로 NE555 8번 핀과 1번 핀 사이가 약 5V인지 확인한다.
5. 정상이라면 전원을 끈다.

## 정상 기준

- LED가 반복해서 깜빡인다.
- 가변저항을 돌리면 속도가 바뀐다.
- NE555가 뜨겁지 않다.

## 안 되면 확인

- NE555 방향이 반대인지
- 1번이 GND인지
- 8번과 4번이 +5V인지
- 2번과 6번이 연결됐는지
- 전해커패시터 극성이 맞는지
- 7번 저항 배선이 맞는지
