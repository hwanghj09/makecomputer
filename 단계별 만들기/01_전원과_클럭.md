# 1단계 — 전원과 NE555 클럭

이 파일은 **진짜 처음부터** 시작한다. 아직 PC, RAM, DATA BUS 같은 것은 몰라도 된다.

## 이번 단계에서 만드는 것

```text
5V 전원
↓
공통 GND
↓
0.1µF 디커플링
↓
NE555 Clock
↓
LED로 깜빡임 확인
```

---

# 1-1. 점퍼선 색 규칙

이 파일에서 실제로 꽂는 점퍼선은 아래 색을 그대로 사용한다.

| 색 | 역할 |
|---|---|
| 🟥 빨강 | +5V 전원 / 테스트용 HIGH |
| ⬛ 검정 | GND / 테스트용 LOW |
| 🟦 파랑 | Clock / Reset |
| ⬜ 흰색 | 특별한 보조 연결 |

아직 DATA와 ADDRESS 선은 만들지 않는다.

---

# 1-2. 브레드보드 전원 연결

전원을 끈 상태에서 한다.

1. 🟥 **빨강** — 5V 어댑터의 `+5V` → 브레드보드 `+` 전원 레일
2. ⬛ **검정** — 5V 어댑터의 `GND` → 브레드보드 `-` 전원 레일
3. 🟥 **빨강** — 전원 레일이 중간에서 끊어진 브레드보드라면 `+5V 레일 ↔ +5V 레일`
4. ⬛ **검정** — 전원 레일이 중간에서 끊어졌다면 `GND 레일 ↔ GND 레일`
5. 🟥 **빨강** — 여러 브레드보드를 사용하면 모든 `+5V 레일끼리` 연결
6. ⬛ **검정** — 여러 브레드보드를 사용하면 모든 `GND 레일끼리` 연결

## 전원 테스트

1. 멀티미터를 DC 전압 모드로 둔다.
2. 검정 프로브를 GND 레일에 댄다.
3. 빨강 프로브를 +5V 레일에 댄다.
4. 약 `5V`가 나오면 정상이다.
5. 모든 브레드보드 구역에서 반복한다.

5V가 아니면 다음 단계로 가지 않는다.

---

# 1-3. 0.1µF 디커플링 커패시터

앞으로 IC를 하나 꽂을 때마다 **그 IC의 VCC와 GND 바로 옆에 0.1µF 세라믹 커패시터 하나**를 단다.

```text
IC VCC ── 🟥 빨강 ──┐
                     │
                   0.1µF
                     │
IC GND ── ⬛ 검정 ──┘
```

세라믹 0.1µF는 극성이 없어서 방향은 상관없다.

왜 다냐면, Clock 순간에 IC가 전류를 갑자기 필요로 할 때 전원 전압이 흔들리는 것을 줄이기 위해서다.

---

# 1-4. NE555 클럭 발생기 꽂기

NE555의 홈을 위로 둔다.

```text
        홈
     ┌───────┐
1 GND│       │8 VCC
2 TR │ NE555 │7 DISCH
3 OUT│       │6 THRESH
4 RST│       │5 CTRL
     └───────┘
```

## NE555 실제 배선

1. ⬛ **검정** — NE555 클럭 발생기 **1번 핀(GND)** → GND
2. 🟦 **파랑** — NE555 클럭 발생기 **2번 핀(TRIG)** ↔ NE555 클럭 발생기 **6번 핀(THRESH)**
3. 🟦 **파랑** — NE555 클럭 발생기 **3번 핀(OUT)** → 앞으로 사용할 `RAW_CLK` 출력점
4. 🟥 **빨강** — NE555 클럭 발생기 **4번 핀(RESET)** → +5V
5. ⬜ **흰색** — NE555 클럭 발생기 **5번 핀(CTRL)** → 10nF 커패시터 한쪽
6. ⬛ **검정** — 위 10nF 커패시터 반대쪽 → GND
7. 🟦 **파랑** — NE555 클럭 발생기 **6번 핀(THRESH)** ↔ 2번 핀과 같은 타이밍 접점
8. 🟦 **파랑** — NE555 클럭 발생기 **7번 핀(DISCH)** → 현재 사용 중인 타이밍 저항/가변저항 회로
9. 🟥 **빨강** — NE555 클럭 발생기 **8번 핀(VCC)** → +5V
10. 🟥/⬛ — NE555 바로 옆 0.1µF: VCC 쪽은 🟥 빨강, GND 쪽은 ⬛ 검정

> 현재 이미 정상 동작하는 NE555의 저항/가변저항/타이밍 커패시터 값은 그대로 유지한다.

---

# 1-5. Clock LED 테스트

아직 다음 단계 IC는 연결하지 않는다.

1. NE555 클럭 발생기 **3번 핀(OUT)**에 LED 테스트선을 단다.
2. LED에는 반드시 330Ω~1kΩ 저항을 직렬로 사용한다.
3. 전원을 켠다.
4. LED가 반복해서 켜졌다 꺼지는지 본다.
5. 가변저항을 돌렸을 때 깜빡이는 속도가 변하는지 확인한다.

## 정상

- LED가 일정하게 깜빡인다.
- 가변저항으로 속도가 바뀐다.
- NE555 8번 핀과 1번 핀 사이가 약 5V다.

## 안 되면

다음 순서로 확인한다.

1. NE555 방향
2. 1번=GND, 8번=+5V
3. 4번 RESET=+5V
4. 2번과 6번 연결
5. 7번 타이밍 저항
6. 타이밍 커패시터 극성

정상 확인 후에만 2단계로 간다.
