# 1단계 — 전원, GND, 0.1µF 디커플링

> **초보자 공통 규칙**
>
> - 전원을 끈 상태에서 배선한다.
> - IC 홈(노치)을 위로 두고 핀 번호를 확인한다.
> - 모든 IC는 +5V, 모든 GND는 공통이다.
> - 각 IC의 VCC-GND 바로 옆에 0.1µF 세라믹 커패시터를 하나 단다.
> - LED 테스트에는 반드시 330Ω~1kΩ 직렬 저항을 사용한다.
> - 사용하지 않는 74HC 입력은 떠 있게 두지 않는다.
> - 한 단계가 정상 동작한 뒤에만 다음 단계로 넘어간다.

## 목표

브레드보드 전체에 안정적인 +5V와 GND를 만든다. 아직 다른 IC 기능은 만들지 않는다.

## 가장 먼저 할 일

- 5V 어댑터의 +를 브레드보드 + 레일에 연결한다.
- 어댑터 GND를 - 레일에 연결한다.
- 브레드보드 전원 레일이 중간에서 끊긴 타입이면 빨강/검정 점퍼로 양쪽을 이어 준다.
- 여러 브레드보드를 쓰면 모든 +5V끼리, 모든 GND끼리 연결한다.

## 0.1µF 커패시터는 왜 IC마다 다나

IC가 Clock 순간에 전류를 갑자기 필요로 하면 긴 브레드보드 전원선의 전압이 아주 잠깐 흔들릴 수 있다. 0.1µF 커패시터가 IC 바로 옆에서 그 순간 전류를 공급해서 오동작을 줄인다.

```text
IC VCC ──┐
         │
       0.1µF
         │
IC GND ──┘
```

세라믹 0.1µF는 극성이 없다.

## 색

| 색 | 의미 |
|---|---|
| 🟥 빨강 | +5V 전원 |
| ⬛ 검정 | GND |
| 🟩 초록 | DATA |
| 🟨 노랑 | ADDRESS |
| 🟦 파랑 | CLOCK / RESET |
| 🟧 주황 | CONTROL |
| ⬜ 흰색 | STATUS / FLAG / SPECIAL |

## 테스트

1. 아직 IC를 많이 꽂지 않은 상태에서 전원을 켠다.
2. 멀티미터 DC 전압 모드로 +레일과 GND 사이를 잰다.
3. 모든 브레드보드 구역에서 약 5V인지 확인한다.
4. 전원을 끄고 다음 단계로 간다.

## 정상

- 모든 전원 레일에서 +5V가 나온다.
- GND끼리 저항/연속성 모드에서 연결되어 있다.

## 안 되면

- DC 잭 +/− 반대인지 확인
- 브레드보드 전원 레일이 중간에서 끊겼는지 확인
- 5V가 아니라 9V 등을 넣고 있지 않은지 확인

# 2단계 — U1 NE555 Clock

> **초보자 공통 규칙**
>
> - 전원을 끈 상태에서 배선한다.
> - IC 홈(노치)을 위로 두고 핀 번호를 확인한다.
> - 모든 IC는 +5V, 모든 GND는 공통이다.
> - 각 IC의 VCC-GND 바로 옆에 0.1µF 세라믹 커패시터를 하나 단다.
> - LED 테스트에는 반드시 330Ω~1kΩ 직렬 저항을 사용한다.
> - 사용하지 않는 74HC 입력은 떠 있게 두지 않는다.
> - 한 단계가 정상 동작한 뒤에만 다음 단계로 넘어간다.

## 이번 단계 목표

U1의 3번에서 천천히 HIGH/LOW가 반복되는 Clock을 만든다.

## 왜 이 부품이 필요한가

Clock은 PC와 Microstep Counter가 언제 움직일지 정하는 박자다. 이 회로가 불안정하면 뒤의 모든 회로가 이상해진다.

## 점퍼선 색 규칙

| 색 | 의미 |
|---|---|
| 🟥 빨강 | +5V 전원 |
| ⬛ 검정 | GND |
| 🟩 초록 | DATA |
| 🟨 노랑 | ADDRESS |
| 🟦 파랑 | CLOCK / RESET |
| 🟧 주황 | CONTROL |
| ⬜ 흰색 | STATUS / FLAG / SPECIAL |

## 실제 핀 배선

아래 핀 번호는 최종 `컴퓨터만들기.md`와 동일하다. **한 줄씩 연결하고 체크 표시하면서 진행**한다.

## U1 — NE555
**CPU 원시 Clock 생성**

1. ⬛ **검정** — GND
2. 🟦 **파랑** — U1-6과 연결 + 현재 사용 중인 타이밍 RC 접점
3. 🟦 **파랑** — RAW_CLK → U28-1
4. 🟥 **빨강** — +5V
5. ⬜ **흰색** — 10nF → GND 권장
6. 🟦 **파랑** — U1-2와 연결
7. 🟦 **파랑** — 현재 정상 동작 중인 타이밍 저항/가변저항망
8. 🟥 **빨강** — +5V

> 현재 이미 정상 동작 중인 NE555의 R/VR/C 값은 그대로 유지한다.

## 테스트 방법

1. U1-3에 LED + 1kΩ 저항을 연결한다.
2. 전원을 켠다.
3. LED가 일정한 간격으로 켜졌다 꺼지는지 본다.
4. 가변저항을 돌렸을 때 깜빡이는 속도가 변하는지 확인한다.
5. 멀티미터가 있다면 U1-8과 U1-1 사이가 약 5V인지 확인한다.

## 정상이라면

LED가 계속 켜져 있지 않고 반복해서 깜빡이며, 가변저항으로 속도가 변한다.

## 안 되면 여기부터 확인

U1 방향, 2번과 6번 연결, 7번 타이밍 저항, 전해커패시터 극성, 4번 RESET이 +5V인지 확인한다.
