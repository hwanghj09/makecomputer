# 9단계 — PS/2 키보드

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 항상 **부품명 + 역할 + 실제 핀 번호 + 점퍼선 색**으로 설명한다.

## 이 단계의 점퍼선 색

- 🟥 **빨강** = +5V / HIGH 고정
- ⬛ **검정** = GND / LOW 고정
- 🟩 **초록** = DATA
- 🟨 **노랑** = ADDRESS
- 🟦 **파랑** = CLOCK / RESET / CLEAR
- 🟧 **주황** = CONTROL
- ⬜ **흰색** = STATUS / FLAG / SPECIAL
- `— 배선 없음` = 점퍼선을 꽂지 않음

PS/2 부분은 아래 순서대로 만든다.

```text
Mini-DIN 6핀 소켓
↓
74HC14 PS/2 Schmitt Trigger
↓
74HC161 PS/2 비트 카운터
↓
74HC164 시프트 레지스터 앞단
↓
74HC164 시프트 레지스터 뒷단
↓
AT28C64B Scan Code→ASCII ROM
↓
74HC157 STATUS/DATA MUX 두 개
↓
74HC245 키보드 데이터 버스 드라이버
↓
실제 키보드 테스트
```

---

# 9-1. PS/2가 보내는 데이터

키 하나를 누르면 PS/2 키보드는 직렬로 11비트를 보낸다.

```text
Start
D0
D1
D2
D3
D4
D5
D6
D7
Parity
Stop
```

PS/2 DATA 자체는 🟩 초록, PS/2 CLOCK은 🟦 파랑으로 통일한다.

---

# 9-2. PS/2 Mini-DIN 6핀

1. 🟩 **초록** — 1번 `DATA` → 74HC14 PS/2 Schmitt Trigger 5번 입력
2. — **배선 없음** — 2번 NC
3. ⬛ **검정** — 3번 `GND` → GND
4. 🟥 **빨강** — 4번 `+5V` → +5V
5. 🟦 **파랑** — 5번 `CLOCK` → 74HC14 PS/2 Schmitt Trigger 1번 입력 + NPN Clock Hold Collector
6. — **배선 없음** — 6번 NC

## Pull-up 저항 두 개

### DATA Pull-up

- 🟥 **빨강** — +5V → 4.7kΩ 저항 한쪽
- 🟩 **초록** — 저항 반대쪽 → PS/2 1번 DATA 선

### CLOCK Pull-up

- 🟥 **빨강** — +5V → 4.7kΩ 저항 한쪽
- 🟦 **파랑** — 저항 반대쪽 → PS/2 5번 CLOCK 선

> Mini-DIN 소켓은 앞면과 납땜면이 뒤집혀 보일 수 있으므로 실제 구매한 소켓 핀 번호를 반드시 확인한다.

---

# 9-3. 74HC14 PS/2 Schmitt Trigger

PS/2 Clock/Data의 지저분한 전압 변화를 깨끗한 HIGH/LOW로 정리한다.

1. 🟦 **파랑** — 1번 `1A` ← PS/2 CLOCK raw
2. 🟦 **파랑** — 2번 `1Y` → PS2_INV_CLK
3. 🟦 **파랑** — 3번 `2A` ← 같은 칩 2번 출력
4. 🟦 **파랑** — 4번 `2Y` → PS2_POST_CLK
5. 🟩 **초록** — 5번 `3A` ← PS/2 DATA raw
6. 🟩 **초록** — 6번 `3Y` → 같은 칩 9번 `4A`
7. ⬛ **검정** — 7번 `GND` → GND
8. 🟩 **초록** — 8번 `4Y = PS2_DATA_CLEAN` → 74HC164 PS/2 시프트 레지스터 앞단 1번 A
9. 🟩 **초록** — 9번 `4A` ← 같은 칩 6번 출력
10. — **배선 없음** — 10번 `5Y`
11. ⬛ **검정** — 11번 `5A` → GND
12. — **배선 없음** — 12번 `6Y`
13. ⬛ **검정** — 13번 `6A` → GND
14. 🟥 **빨강** — 14번 `VCC` → +5V

### 0.1µF 디커플링

- 🟥 빨강 쪽 → 14번 VCC
- ⬛ 검정 쪽 → 7번 GND

## 테스트

CLOCK는 🟦 파랑, DATA는 🟩 초록 테스트선으로 HIGH/LOW를 천천히 바꿔 출력이 반전되는지 확인한다.

---

# 9-4. 74HC161 PS/2 비트 카운터

현재 PS/2 프레임에서 몇 번째 비트를 받고 있는지 센다. 카운터 출력 QA~QD는 데이터가 아니라 **현재 수신 위치 상태**이므로 ⬜ 흰색이다.

1. 🟦 **파랑** — 1번 `/CLR` ← KEY_CLR_N
2. 🟦 **파랑** — 2번 `CLK` ← PS2_SAMPLE_CLK
3. ⬛ **검정** — 3번 `A` → GND
4. ⬛ **검정** — 4번 `B` → GND
5. ⬛ **검정** — 5번 `C` → GND
6. ⬛ **검정** — 6번 `D` → GND
7. 🟥 **빨강** — 7번 `ENP` → +5V
8. ⬛ **검정** — 8번 `GND` → GND
9. 🟥 **빨강** — 9번 `/LOAD` → +5V
10. 🟥 **빨강** — 10번 `ENT` → +5V
11. ⬜ **흰색** — 11번 `QD` → 74HC08 OUT·LCD·PS2 제어 AND 칩 12번
12. ⬜ **흰색** — 12번 `QC` → 74HC04 OUT/ZERO/I/O/PS2/RAM BUS 인버터 9번
13. ⬜ **흰색** — 13번 `QB` → 74HC139 확장명령 유효·PS2 카운트 디코더 13번 2B
14. ⬜ **흰색** — 14번 `QA` → 같은 74HC139 디코더 14번 2A
15. — **배선 없음** — 15번 `RCO`
16. 🟥 **빨강** — 16번 `VCC` → +5V

### 0.1µF 디커플링

- 🟥 빨강 쪽 → 16번 VCC
- ⬛ 검정 쪽 → 8번 GND

## 테스트

🟦 Sample Clock을 한 번씩 넣어 QA/QB/QC/QD가 이진수로 증가하는지 본다. `/CLR`를 LOW로 하면 0000으로 돌아가야 한다.

---

# 9-5. 74HC139 확장명령 유효·PS2 카운트 디코더의 뒤쪽 절반

앞쪽 절반은 확장 명령 판정에 사용했고, 뒤쪽 절반은 PS/2 비트 카운터 상태를 본다.

9. ⬜ **흰색** — 9번 `/2Y3 = LOWPAIR_N` → 74HC04 OUT/ZERO/I/O/PS2/RAM BUS 인버터 11번
10. — **배선 없음** — 10번 `/2Y2`
11. — **배선 없음** — 11번 `/2Y1`
12. — **배선 없음** — 12번 `/2Y0`
13. ⬜ **흰색** — 13번 `2B` ← 74HC161 PS/2 비트 카운터 13번 QB
14. ⬜ **흰색** — 14번 `2A` ← PS/2 비트 카운터 14번 QA
15. ⬛ **검정** — 15번 `/2G` → GND

> 이 칩의 8번 GND, 16번 VCC는 앞쪽 절반을 만들 때 이미 연결되어 있어야 한다.

---

# 9-6. 74HC164 PS/2 시프트 레지스터 앞단

직렬 DATA를 Clock마다 한 칸씩 밀어서 병렬 Scan Code를 만든다.

`PS2_DATA_CLEAN`까지는 🟩 초록 DATA지만, 시프트가 끝난 Scan Code bit0~7은 **ASCII ROM의 A0~A7 주소로 사용되므로 🟨 노랑**으로 통일한다.

1. 🟩 **초록** — 1번 `A` ← 74HC14 PS/2 Schmitt Trigger 8번 PS2_DATA_CLEAN
2. 🟥 **빨강** — 2번 `B` → +5V
3. — **배선 없음** — 3번 `QA` Stop bit 위치
4. — **배선 없음** — 4번 `QB` Parity 위치
5. 🟨 **노랑** — 5번 `QC = Scan bit7` → AT28C64B Scan Code→ASCII ROM 3번 A7
6. 🟨 **노랑** — 6번 `QD = Scan bit6` → ASCII ROM 4번 A6
7. ⬛ **검정** — 7번 `GND` → GND
8. 🟦 **파랑** — 8번 `CLK` ← PS2_SAMPLE_CLK
9. 🟦 **파랑** — 9번 `/CLR` ← RESET_N
10. 🟨 **노랑** — 10번 `QE = Scan bit5` → ASCII ROM 5번 A5
11. 🟨 **노랑** — 11번 `QF = Scan bit4` → ASCII ROM 6번 A4
12. 🟨 **노랑** — 12번 `QG = Scan bit3` → ASCII ROM 7번 A3
13. 🟨 **노랑** — 13번 `QH = Scan bit2` → 74HC164 시프트 레지스터 뒷단 1번 A + ASCII ROM 8번 A2
14. 🟥 **빨강** — 14번 `VCC` → +5V

### 0.1µF 디커플링

- 🟥 빨강 쪽 → 14번 VCC
- ⬛ 검정 쪽 → 7번 GND

---

# 9-7. 74HC164 PS/2 시프트 레지스터 뒷단

1. 🟨 **노랑** — 1번 `A` ← 앞쪽 시프트 레지스터 13번 QH
2. 🟥 **빨강** — 2번 `B` → +5V
3. 🟨 **노랑** — 3번 `QA = Scan bit1` → ASCII ROM 9번 A1
4. 🟨 **노랑** — 4번 `QB = Scan bit0` → ASCII ROM 10번 A0
5. — **배선 없음** — 5번 `QC` Start bit 위치
6. — **배선 없음** — 6번 `QD`
7. ⬛ **검정** — 7번 `GND` → GND
8. 🟦 **파랑** — 8번 `CLK` ← PS2_SAMPLE_CLK
9. 🟦 **파랑** — 9번 `/CLR` ← RESET_N
10. — **배선 없음** — 10번 QE
11. — **배선 없음** — 11번 QF
12. — **배선 없음** — 12번 QG
13. — **배선 없음** — 13번 QH
14. 🟥 **빨강** — 14번 `VCC` → +5V

### 0.1µF 디커플링

- 🟥 빨강 쪽 → 14번 VCC
- ⬛ 검정 쪽 → 7번 GND

## 시프트 테스트

실제 키보드 전에 🟩 DATA에 1/0 패턴을 넣고 🟦 Sample Clock을 한 번씩 준다. Scan Code로 사용할 병렬 출력은 🟨 노랑 선에서 확인한다.

---

# 9-8. AT28C64B Scan Code→ASCII 변환 ROM

EEPROM 주소 A0~A7에 Scan Code를 넣고 해당 주소에 ASCII를 미리 기록한다.

1. — **배선 없음** — 1번 `NC`
2. ⬛ **검정** — 2번 `A12` → GND
3. 🟨 **노랑** — 3번 `A7` ← 앞쪽 시프트 레지스터 5번
4. 🟨 **노랑** — 4번 `A6` ← 앞쪽 시프트 레지스터 6번
5. 🟨 **노랑** — 5번 `A5` ← 앞쪽 시프트 레지스터 10번
6. 🟨 **노랑** — 6번 `A4` ← 앞쪽 시프트 레지스터 11번
7. 🟨 **노랑** — 7번 `A3` ← 앞쪽 시프트 레지스터 12번
8. 🟨 **노랑** — 8번 `A2` ← 앞쪽 시프트 레지스터 13번
9. 🟨 **노랑** — 9번 `A1` ← 뒤쪽 시프트 레지스터 3번
10. 🟨 **노랑** — 10번 `A0` ← 뒤쪽 시프트 레지스터 4번
11. 🟩 **초록** — 11번 `I/O0` → 74HC157 키보드 STATUS/DATA MUX 하위칩 3번 1B
12. 🟩 **초록** — 12번 `I/O1` → 하위 MUX 6번 2B
13. 🟩 **초록** — 13번 `I/O2` → 하위 MUX 10번 3B

17. 🟩 **초록** — 17번 `I/O5` → 상위 MUX 6번 2B
18. 🟩 **초록** — 18번 `I/O6` → 상위 MUX 10번 3B
19. 🟩 **초록** — 19번 `I/O7` → 상위 MUX 13번 4B
20. ⬛ **검정** — 20번 `/CE` → GND
21. ⬛ **검정** — 21번 `A10` → GND
22. ⬛ **검정** — 22번 `/OE` → GND
23. ⬛ **검정** — 23번 `A11` → GND
24. ⬛ **검정** — 24번 `A9` → GND
25. ⬛ **검정** — 25번 `A8` → GND
26. — **배선 없음** — 26번 `NC`
27. 🟥 **빨강** — 27번 `/WE` → +5V
28. 🟥 **빨강** — 28번 `VCC` → +5V

### 0.1µF 디커플링

- 🟥 빨강 쪽 → 28번 VCC
- ⬛ 검정 쪽 → 14번 GND

## 테스트

EEPROM Programmer로 A키 Scan Code 주소에 `0x41`을 기록한다. 🟨 주소 A0~A7에 해당 Scan Code를 넣었을 때 🟩 I/O7~I/O0이 `01000001`인지 확인한다.

# 9-9. KEY_STATUS와 KEY_DATA를 고르는 74HC157 두 개

`ADDRESS A0=0 → STATUS`, `ADDRESS A0=1 → DATA`이다.

8. ⬛ **검정** — 8번 `GND` → GND
9. 🟩 **초록** — 9번 `3Y` → 키보드 버스 드라이버 4번 A3
10. 🟩 **초록** — 10번 `3B` ← ASCII ROM 13번 I/O2
11. ⬛ **검정** — 11번 `3A` → GND

- 🟨 ADDRESS A0=0 → bit0만 ⬜ KEY_READY, bit7~1은 0

# 9-11. NPN 트랜지스터 PS/2 Clock Hold

키 하나를 받은 뒤 CPU가 읽을 때까지 키보드가 다음 데이터를 보내지 못하게 CLOCK을 LOW로 잡는다.

- 🟦 **파랑** — Collector → PS/2 CLOCK 선
- ⬛ **검정** — Emitter → GND
- ⬜ **흰색** — 74HC74 KEY_READY·HALT 저장칩 5번 KEY_READY → 4.7kΩ~10kΩ 저항 → Base

> 실제 E/B/C 다리 순서는 구매한 트랜지스터 모델 데이터시트를 확인한다.

---

# 9-12. 실제 키보드 최종 테스트

1. PS/2 키보드를 연결한다.
2. A키를 누른다.
3. 🟩 DATA가 시프트 레지스터로 들어오는지 확인한다.
4. ⬜ PS/2 비트 카운터 상태가 프레임 길이를 세는지 확인한다.
5. ⬜ KEY_READY가 HIGH가 되는지 확인한다.
6. 🟨 주소 161 KEY_DATA를 선택했을 때 🟩 ASCII `0x41`이 DATA BUS에 나타나는지 확인한다.
7. CPU가 KEY_DATA를 읽은 뒤 KEY_READY가 다시 LOW가 되는지 확인한다.
8. 다음 키를 다시 받을 수 있는지 확인한다.
