# 2단계 — PC → MAR → Address 선택 → RAM Bank Decoder

이 파일에서는 처음으로 **주소(Address)**를 만든다.

1단계에서 만든 것은:

- +5V
- GND
- RESET_N
- U1 NE555 Clock

뿐이라고 생각하고 시작한다.

아직 DATA BUS나 RAM 데이터는 만들지 않는다.

---

# 1. 이번 단계에서 처음 배우는 말

## PC
PC는 **Program Counter**의 약자다.

쉽게 말하면:

> 지금 몇 번째 명령어를 읽을 차례인지 기억하는 숫자

이다.

이 컴퓨터는 PC가 8bit라서 0~255를 셀 수 있다.

## bit
bit는 0 또는 1 하나다.

8bit면:

```text
00000000 ~ 11111111
```

즉 0~255를 표현할 수 있다.

## Address
Address는 **메모리에서 어디를 볼지 나타내는 번호**다.

점퍼선 색은 🟨 노랑이다.

## MAR
MAR는 **Memory Address Register**다.

쉽게 말하면:

> 명령어가 지정한 주소를 잠깐 기억하는 저장칩

이다.

## MUX
MUX는 여러 입력 중 하나를 골라 출력하는 선택기다.

이번에는:

```text
PC 주소
   ┐
   ├→ MUX → 실제 주소선
MAR 주소
   ┘
```

처럼 사용한다.

## Active-Low 출력
74HC138 같은 디코더는 선택된 출력이 LOW가 된다.

즉 LED 테스트할 때는:

```text
+5V → 저항 → LED → 출력핀
```

처럼 연결하면 선택된 출력에서 LED가 켜진다.

---

# 2. 먼저 U2 하나만 카운터로 시험한다

U2는 74HC161이고 PC의 아래 4bit를 담당한다.

아직 U3은 연결하지 않는다.

## U2 놓기
홈이 위로 오게 놓는다.

```text
             홈
        ┌───────────┐
 /CLR  1│           │16 VCC
 CLK   2│ 74HC161   │15 RCO
 A     3│           │14 QA
 B     4│           │13 QB
 C     5│           │12 QC
 D     6│           │11 QD
 ENP   7│           │10 ENT
 GND   8│           │9 /LOAD
        └───────────┘
```

## U2 지금 연결

1. **U2-16 → +5V** — 🟥
2. **U2-8 → GND** — ⬛
3. **U2-1 → RESET_N** — 🟦
4. **U2-2 → U1-3** — 🟦 테스트용 Clock
5. **U2-7 → +5V** — 🟥
6. **U2-10 → +5V** — 🟥 테스트용 Count 허용
7. **U2-9 → +5V** — 🟥 테스트 동안 /LOAD 비활성
8. **U2-3,4,5,6 → GND** — ⬛ 지금은 병렬입력을 사용하지 않으므로 임시 고정

## 0.1µF

```text
U2-16 ── 0.1µF ── U2-8
```

## 출력 LED

- U2-14 = 가장 낮은 bit
- U2-13 = 그 다음
- U2-12 = 그 다음
- U2-11 = 가장 높은 bit

각 출력에 LED+저항을 임시로 달아 본다.

## 테스트
Clock을 아주 느리게 한다.

정상이라면:

```text
0000
0001
0010
0011
0100
...
1111
0000
```

순서로 반복한다.

RESET 버튼을 누르면 0000이 되어야 한다.

성공하기 전에는 U3를 연결하지 않는다.

---

# 3. U3를 추가해 8bit PC를 만든다

U3도 74HC161이다.

U2가 아래 4bit, U3가 위 4bit다.

## U3 지금 연결

1. **U3-16 → +5V** — 🟥
2. **U3-8 → GND** — ⬛
3. **U3-1 → RESET_N** — 🟦
4. **U3-2 → U1-3** — 🟦 지금은 U2와 같은 테스트 Clock
5. **U3-7 → +5V** — 🟥
6. **U3-10 ← U2-15** — 🟧 U2가 1111을 넘길 때 U3가 증가하게 하는 연결
7. **U3-9 → +5V** — 🟥 테스트 동안 /LOAD 비활성
8. **U3-3,4,5,6 → GND** — ⬛ 아직 사용하지 않는 병렬입력

0.1µF는 U3-16과 U3-8 사이에 둔다.

## 출력 의미

```text
U3-11 = PC7
U3-12 = PC6
U3-13 = PC5
U3-14 = PC4
U2-11 = PC3
U2-12 = PC2
U2-13 = PC1
U2-14 = PC0
```

이제 이 8개를 합쳐 8bit PC라고 부른다.

## 테스트
특히 이 순간을 본다.

```text
00001111
↓ 다음 Clock
00010000
```

정확히 되면 8bit PC 성공이다.

---

# 4. U16 MAR를 단독으로 시험한다

U16은 74HC273이다.

74HC273은 8개의 bit를 한 번에 저장한다.

아직 DATA BUS는 만들지 않았으므로 입력은 임시 점퍼로 만든다.

## U16 핀

```text
                 홈
            ┌───────────┐
 /CLR    1  │           │ 20 VCC
 Q0      2  │ 74HC273   │ 19 Q7
 D0      3  │           │ 18 D7
 D1      4  │           │ 17 D6
 Q1      5  │           │ 16 Q6
 Q2      6  │           │ 15 Q5
 D2      7  │           │ 14 D5
 D3      8  │           │ 13 D4
 Q3      9  │           │ 12 Q4
 GND    10  │           │ 11 CLK
            └───────────┘
```

## U16 전원/Reset

1. U16-20 → +5V — 🟥
2. U16-10 → GND — ⬛
3. U16-1 → RESET_N — 🟦
4. U16-20 ↔ U16-10 사이 0.1µF

## 입력 D0~D7
아직 공용 데이터선이 없으므로 임시로 HIGH/LOW를 직접 넣는다.

```text
D0 = U16-3
D1 = U16-4
D2 = U16-7
D3 = U16-8
D4 = U16-13
D5 = U16-14
D6 = U16-17
D7 = U16-18
```

각 입력은 시험할 값에 따라 +5V 또는 GND에 연결한다.

## 테스트용 Clock 버튼
U16-11은 저장 Clock이다.

간단한 시험용으로:

```text
U16-11 ── 10kΩ ── GND
U16-11 ── 버튼 ── +5V
```

로 만든다.

버튼을 누르면 LOW→HIGH가 생기면서 현재 D0~D7 값을 저장한다.

## 출력

```text
Q0 = U16-2
Q1 = U16-5
Q2 = U16-6
Q3 = U16-9
Q4 = U16-12
Q5 = U16-15
Q6 = U16-16
Q7 = U16-19
```

LED+저항으로 확인한다.

## 시험 예시
D입력을 `01010101`로 만든 뒤 버튼을 한 번 누른다.

Q도 `01010101`이 되어야 한다.

D입력을 다른 값으로 바꿔도 Clock 버튼을 다시 누르기 전까지 Q는 그대로여야 한다.

---

# 5. 이제 MAR 출력을 PC의 Load 입력에 연결한다

U2/U3의 3~6번에 임시로 연결했던 GND선을 제거한다.

다음처럼 연결한다.

## 아래 4bit

```text
U16-2  → U2-3
U16-5  → U2-4
U16-6  → U2-5
U16-9  → U2-6
```

## 위 4bit

```text
U16-12 → U3-3
U16-15 → U3-4
U16-16 → U3-5
U16-19 → U3-6
```

모두 주소값을 전달하므로 🟨 노랑선을 사용한다.

아직 U2/U3의 9번 `/LOAD`는 +5V에 둔다.

자동 점프 기능은 나중에 만든다.

---

# 6. Address MUX를 만든다

이제 PC와 MAR 중 어느 주소를 사용할지 고를 차례다.

U21, U22 두 개의 74HC157을 사용한다.

- U21 = 아래 4bit 선택
- U22 = 위 4bit 선택

`S`라는 Select 핀이 0이면 A입력, 1이면 B입력을 고른다.

이번 설계에서는:

```text
S=0 → PC
S=1 → MAR
```

이다.

## U21 연결

1. U21-16 → +5V — 🟥
2. U21-8 → GND — ⬛
3. U21-15 → GND — ⬛ 출력 항상 허용
4. U21-2 ← U2-14
5. U21-3 ← U16-2
6. U21-4 = 새 주소선 A0
7. U21-5 ← U2-13
8. U21-6 ← U16-5
9. U21-7 = A1
10. U21-11 ← U2-12
11. U21-10 ← U16-6
12. U21-9 = A2
13. U21-14 ← U2-11
14. U21-13 ← U16-9
15. U21-12 = A3

U21-1 Select는 아직 자동회로가 없으므로 테스트용 점퍼를 사용한다.

- GND → PC 선택
- +5V → MAR 선택

## U22 연결

1. U22-16 → +5V — 🟥
2. U22-8 → GND — ⬛
3. U22-15 → GND — ⬛
4. U22-2 ← U3-14
5. U22-3 ← U16-12
6. U22-4 = A4
7. U22-5 ← U3-13
8. U22-6 ← U16-15
9. U22-7 = A5
10. U22-11 ← U3-12
11. U22-10 ← U16-16
12. U22-9 = A6
13. U22-14 ← U3-11
14. U22-13 ← U16-19
15. U22-12 = A7
16. U22-1은 U21-1과 같은 Select 점퍼에 연결

U21/U22 각각 VCC-GND 사이에 0.1µF를 둔다.

---

# 7. 처음으로 Address Bus라는 이름을 붙인다

방금 만든 8개의 출력:

```text
A0 A1 A2 A3 A4 A5 A6 A7
```

을 합쳐서 **Address Bus**라고 부른다.

쉽게 말하면:

> CPU가 지금 어느 번호의 메모리를 보고 있는지 전달하는 8개 주소선

이다.

모두 🟨 노랑선이다.

## 테스트

1. PC를 눈에 띄는 값, 예: `00001111`로 만든다.
2. MAR에는 다른 값, 예: `10100000`을 저장한다.
3. Select=0 → A7~A0가 PC값이어야 한다.
4. Select=1 → A7~A0가 MAR값이어야 한다.

성공하면 Address Bus 완성이다.

# 8. U26 RAM Bank Decoder를 만든다

아직 RAM 자체는 연결하지 않는다.

먼저 상위 주소 A7,A6,A5를 보고 **어느 RAM 칩을 고를지** 만드는 회로만 만든다.

U26은 74HC138이다.

## 연결

1. **U26-16 → +5V** — 🟥
2. **U26-8 → GND** — ⬛
3. **U26-4 → GND** — ⬛
4. **U26-5 → GND** — ⬛
5. **U26-6 → +5V** — 🟥
6. **U26-1 ← A5 = U22-7** — 🟨
7. **U26-2 ← A6 = U22-9** — 🟨
8. **U26-3 ← A7 = U22-12** — 🟨

U26-16과 U26-8 사이 0.1µF를 둔다.

출력 Y0~Y7은 Active-Low다.

```text
Y0 = U26-15
Y1 = U26-14
Y2 = U26-13
Y3 = U26-12
Y4 = U26-11
Y5 = U26-10
Y6 = U26-9
Y7 = U26-7
```

아직 RAM에 연결하지 않는다.

## LED 테스트
각 출력은:

```text
+5V → 1kΩ → LED → Y핀
```

으로 임시 테스트한다.

## 정상 결과

A7 A6 A5가:

```text
000 → Y0만 LOW
001 → Y1만 LOW
010 → Y2만 LOW
011 → Y3만 LOW
100 → Y4만 LOW
101 → Y5만 LOW
110 → Y6만 LOW
111 → Y7만 LOW
```

여야 한다.

특히 네가 전에 이상했던 `010`, `011`을 다시 확인한다.

# 9. 2단계가 끝났을 때 실제로 존재하는 것

```text
U1 Clock
↓
U2 + U3 = 8bit PC

U16 = MAR

PC ─┐
    ├→ U21/U22 → A0~A7 Address Bus
MAR ┘
                  ↓
                 U26
```

아직 만들지 않은 것:

```text
DATA BUS
RAM 데이터선
A Register
ALU
명령어 Decoder 자동제어
```

이 단어들은 다음 단계부터 설명한다.
