# 2단계 — PC → MAR → Address MUX → RAM Bank Decoder

이 파일에서는 **주소를 만드는 부분만** 만든다.

아직 `DATA BUS`, `U28~U49 제어회로`, `Boot ROM`은 만들지 않는다.

이 파일에서 처음 나오는 말은 바로 설명하고, 아직 없는 부품으로 가는 선은 **나중에 연결**한다고 표시한다.

---

# 2-0. 먼저 알아둘 말

## PC

`Program Counter`의 약자다.

쉽게 말하면:

> 지금 몇 번째 명령어를 읽을지 기억하는 숫자 카운터

이다.

이번에는 74HC161 두 개를 이어서 8bit PC를 만든다.

```text
U3 = 위쪽 4bit
U2 = 아래쪽 4bit

PC7 PC6 PC5 PC4 | PC3 PC2 PC1 PC0
```

## bit

0 또는 1 한 칸을 뜻한다.

8bit면 0~255까지 표현할 수 있다.

## RESET

값을 0으로 되돌리는 신호다.

이번 단계에서는 최종 RESET 회로 대신 **테스트용 점퍼**로 잠깐 GND에 내렸다가 다시 +5V로 올려 시험한다.

## ADDRESS

RAM에서 **몇 번째 칸을 볼지** 나타내는 번호다.

이번 단계 후반에 A0~A7이라는 8개의 주소선을 만든다.

---

# 2-1. U2 74HC161 하나만 먼저 꽂기

U2는 PC의 아래 4bit를 담당한다.

```text
             홈
        ┌───────────┐
 /CLR  1│           │16 VCC
 CLK   2│ 74HC161   │15 RCO
 A     3│           │14 QA
 B     4│           │13 QB
 C     5│           │12 QC
 D     6│           │11 QD
 ENP   7│           │10 ENT
 GND   8│           │9 /LOAD
        └───────────┘
```

### 지금 연결할 것만 연결

1. U2-16 → +5V **[빨강]**
2. U2-8 → GND **[검정]**
3. U2-7(ENP) → +5V **[빨강]**
4. U2-10(ENT) → +5V **[빨강]**
5. U2-9(/LOAD) → +5V **[빨강]**
6. U2-1(/CLR) → +5V **[파랑]**
7. U2-2(CLK) ← U1-3(NE555 출력) **[파랑]**
8. U2-3,4,5,6 → 지금은 GND에 임시 연결 **[검정]**

왜 3~6번을 GND에 두냐면 지금은 병렬 Load 기능을 쓰지 않기 때문이다.

### 출력 LED

각 출력에 LED+1kΩ을 임시로 단다.

- U2-14 = PC0
- U2-13 = PC1
- U2-12 = PC2
- U2-11 = PC3

출력은 나중에 주소선이 되므로 점퍼선 색은 **노랑**으로 생각하면 된다.

### 테스트

NE555를 아주 느리게 한다.

LED가:

```text
0000
0001
0010
0011
...
1111
0000
```

순서로 바뀌면 U2는 정상이다.

### RESET 테스트

U2-1을 잠깐 GND로 내린다.

모든 출력이 `0000`이 되면 정상이다.

그 뒤 U2-1은 다시 +5V로 올린다.

---

# 2-2. U3 74HC161 추가해서 8bit로 만들기

U3는 위쪽 4bit를 담당한다.

### U3 기본 연결

1. U3-16 → +5V **[빨강]**
2. U3-8 → GND **[검정]**
3. U3-7(ENP) → +5V **[빨강]**
4. U3-9(/LOAD) → +5V **[빨강]**
5. U3-1(/CLR) → U2-1과 같은 RESET 선 **[파랑]**
6. U3-2(CLK) → U2-2와 같은 U1-3 Clock **[파랑]**
7. U3-3,4,5,6 → 지금은 GND **[검정]**

### 두 칩을 이어주는 가장 중요한 선

- **U2-15(RCO) → U3-10(ENT)** **[주황]**

이 선 때문에 U2가 15에서 넘칠 때 U3가 1 증가한다.

> U2의 QD를 U3 Clock에 연결하는 것이 아니다.

### U3 출력

- U3-14 = PC4
- U3-13 = PC5
- U3-12 = PC6
- U3-11 = PC7

### 8bit 테스트

8개 LED를 보면:

```text
00000000
00000001
...
00001111
00010000
```

이 되어야 한다.

특히 **15 → 16**을 꼭 본다.

---

# 2-3. 지금 PC에서 아직 연결하지 않는 핀

최종 설계에서는 나중에 더 연결되지만 **지금은 하지 않는다.**

- U2/U3 3~6번 ← MAR 출력: 아직 X
- U2/U3 9번 ← 최종 PC_LOAD 제어: 아직 X
- U2-10 ← 최종 PC_COUNT 제어: 아직 X
- PC 출력 → Boot ROM: 아직 X

현재 테스트 회로에서는:

```text
/LOAD = +5V
U2 ENT = +5V
U3 ENT = U2 RCO
Clock = U1-3
```

으로 둔다.

---

# 2-4. MAR란?

이제 U16을 만든다.

MAR는 `Memory Address Register`다.

쉽게 말하면:

> RAM의 어느 주소를 볼지 잠깐 기억하는 8bit 저장소

이다.

아직 DATA BUS는 만들지 않았으므로 입력은 **임시 점퍼**로 넣어 테스트한다.

---

# 2-5. U16 74HC273 MAR 만들기

```text
                 홈
            ┌───────────┐
 /CLR    1  │           │20 VCC
 Q0      2  │           │19 Q7
 D0      3  │ 74HC273   │18 D7
 D1      4  │           │17 D6
 Q1      5  │           │16 Q6
 Q2      6  │           │15 Q5
 D2      7  │           │14 D5
 D3      8  │           │13 D4
 Q3      9  │           │12 Q4
 GND    10  │           │11 CLK
            └───────────┘
```

### 기본 연결

1. U16-20 → +5V **[빨강]**
2. U16-10 → GND **[검정]**
3. U16-1(/CLR) → +5V **[파랑]**
4. 0.1µF → U16-20과 U16-10 바로 옆

### 입력 D0~D7

아직 DATA BUS가 없으므로 임시로 +5V/GND를 골라 넣는다.

- D0 = U16-3
- D1 = U16-4
- D2 = U16-7
- D3 = U16-8
- D4 = U16-13
- D5 = U16-14
- D6 = U16-17
- D7 = U16-18

### 출력 Q0~Q7

- Q0 = U16-2
- Q1 = U16-5
- Q2 = U16-6
- Q3 = U16-9
- Q4 = U16-12
- Q5 = U16-15
- Q6 = U16-16
- Q7 = U16-19

출력에는 테스트 LED를 달아도 된다.

### Clock 테스트

U16-11에 **깨끗한 상승 펄스 한 번**을 넣어야 저장된다.

가장 쉬운 테스트는:

1. D0~D7에 예: `01010101` 설정
2. U16-11을 LOW 상태에서 HIGH로 한 번 올림
3. Q 출력이 `01010101`인지 확인
4. 입력을 바꿔도 Clock을 다시 주기 전까지 Q가 유지되는지 확인

### RESET 테스트

U16-1을 잠깐 GND로 내리면 Q0~Q7이 모두 0이 되어야 한다.

---

# 2-6. 이제 MAR를 PC의 병렬 입력에 연결

MAR 테스트가 끝났다면 이제 PC의 A/B/C/D 입력을 MAR와 연결한다.

### U2 하위 PC

- U16-2(Q0) → U2-3(A) **[노랑]**
- U16-5(Q1) → U2-4(B) **[노랑]**
- U16-6(Q2) → U2-5(C) **[노랑]**
- U16-9(Q3) → U2-6(D) **[노랑]**

### U3 상위 PC

- U16-12(Q4) → U3-3(A) **[노랑]**
- U16-15(Q5) → U3-4(B) **[노랑]**
- U16-16(Q6) → U3-5(C) **[노랑]**
- U16-19(Q7) → U3-6(D) **[노랑]**

> 지금은 /LOAD가 +5V라서 PC가 MAR 값을 실제로 Load하지 않는다. 나중 제어회로에서 /LOAD를 제어한다.

---

# 2-7. Address MUX란?

PC와 MAR 둘 다 주소를 가지고 있다.

그런데 실제 주소선은 하나다.

그래서 74HC157 두 개로:

```text
PC ──┐
     ├─ 선택 → A0~A7
MAR ─┘
```

을 만든다.

이때 A0~A7을 **ADDRESS BUS**라고 부른다.

> ADDRESS BUS = RAM에서 몇 번째 칸을 볼지 나타내는 8개의 노랑 선

---

# 2-8. U21 74HC157 — A0~A3

1. U21-16 → +5V **[빨강]**
2. U21-8 → GND **[검정]**
3. U21-15(/G) → GND **[검정]**
4. U21-2 ← U2-14(PC0) **[노랑]**
5. U21-3 ← U16-2(MAR0) **[노랑]**
6. U21-4 = A0 **[노랑]**
7. U21-5 ← U2-13(PC1) **[노랑]**
8. U21-6 ← U16-5(MAR1) **[노랑]**
9. U21-7 = A1 **[노랑]**
10. U21-11 ← U2-12(PC2) **[노랑]**
11. U21-10 ← U16-6(MAR2) **[노랑]**
12. U21-9 = A2 **[노랑]**
13. U21-14 ← U2-11(PC3) **[노랑]**
14. U21-13 ← U16-9(MAR3) **[노랑]**
15. U21-12 = A3 **[노랑]**

U21-1은 Select다.

**지금은 최종 제어회로에 연결하지 않는다.**

테스트할 때:

- U21-1 = GND → PC 선택
- U21-1 = +5V → MAR 선택

---

# 2-9. U22 74HC157 — A4~A7

1. U22-16 → +5V **[빨강]**
2. U22-8 → GND **[검정]**
3. U22-15(/G) → GND **[검정]**
4. U22-2 ← U3-14(PC4) **[노랑]**
5. U22-3 ← U16-12(MAR4) **[노랑]**
6. U22-4 = A4 **[노랑]**
7. U22-5 ← U3-13(PC5) **[노랑]**
8. U22-6 ← U16-15(MAR5) **[노랑]**
9. U22-7 = A5 **[노랑]**
10. U22-11 ← U3-12(PC6) **[노랑]**
11. U22-10 ← U16-16(MAR6) **[노랑]**
12. U22-9 = A6 **[노랑]**
13. U22-14 ← U3-11(PC7) **[노랑]**
14. U22-13 ← U16-19(MAR7) **[노랑]**
15. U22-12 = A7 **[노랑]**

U22-1도 Select다.

**U21-1과 U22-1을 서로 연결해서 한 가닥으로 같이 제어한다.**

테스트할 때:

- Select = GND → PC 주소
- Select = +5V → MAR 주소

---

# 2-10. Address MUX 테스트

1. PC를 예: `00001111`로 만든다.
2. MAR에는 예: `10100000`을 저장한다.
3. Select를 GND로 둔다.
4. A0~A7이 `00001111`인지 확인한다.
5. Select를 +5V로 바꾼다.
6. A0~A7이 `10100000`인지 확인한다.

정상이면 Address MUX 완성이다.

---

# 2-11. U26 RAM Bank Decoder란?

RAM은 총 5개를 쓸 예정이다.

U26은 주소의 위쪽 3bit `A7,A6,A5`를 보고 **어느 RAM 하나를 선택할지** 정한다.

```text
A7 A6 A5
000 → RAM #1
001 → RAM #2
010 → RAM #3
011 → RAM #4
100 → RAM #5
```

74HC138 출력은 **Active-Low**다.

즉 선택된 출력만 `0V(LOW)`가 된다.

---

# 2-12. U26 74HC138 연결

```text
             홈
        ┌───────────┐
 A    1 │           │16 VCC
 B    2 │ 74HC138   │15 Y0
 C    3 │           │14 Y1
/G2A  4 │           │13 Y2
/G2B  5 │           │12 Y3
 G1   6 │           │11 Y4
 Y7   7 │           │10 Y5
 GND  8 │           │9  Y6
        └───────────┘
```

### 연결

1. U26-16 → +5V **[빨강]**
2. U26-8 → GND **[검정]**
3. U26-4 → GND **[검정]**
4. U26-5 → GND **[검정]**
5. U26-6 → +5V **[빨강]**
6. U26-1(A) ← U22-7(A5) **[노랑]**
7. U26-2(B) ← U22-9(A6) **[노랑]**
8. U26-3(C) ← U22-12(A7) **[노랑]**

### 지금 연결하지 않는 출력

RAM은 다음 파일에서 만든다.

그러므로 지금은:

- U26-15(Y0)
- U26-14(Y1)
- U26-13(Y2)
- U26-12(Y3)
- U26-11(Y4)

를 RAM에 아직 연결하지 않는다.

먼저 LED로 Decoder 자체를 시험한다.

---

# 2-13. U26 테스트

74HC138 출력은 선택되면 LOW가 되므로 LED는 이렇게 단다.

```text
+5V → 1kΩ → LED → Y출력
```

Y0~Y4에 LED를 각각 달아 본다.

Select를 MAR 쪽으로 놓고 MAR 값을 바꾸면 테스트하기 쉽다.

### 확인값

```text
A7 A6 A5 = 000 → Y0만 LOW
A7 A6 A5 = 001 → Y1만 LOW
A7 A6 A5 = 010 → Y2만 LOW
A7 A6 A5 = 011 → Y3만 LOW
A7 A6 A5 = 100 → Y4만 LOW
```

이 다섯 경우가 정확하면 U26은 정상이다.

# 2단계 완료 상태

이제 실제로 만들어진 흐름은:

```text
NE555
  ↓
PC(U2,U3)
  │
  ├──────────┐
  │          │
  │        MAR(U16)
  │          │
  └──→ U21/U22 ←──┘
           ↓
        A0~A7
           ↓
         U26
```

아직 DATA BUS와 RAM 데이터선은 없다.
