# 2단계 — Program Counter → 메모리 주소 레지스터 → 주소 선택기 → RAM 뱅크 디코더

> 이 파일에서는 칩 번호 별칭을 쓰지 않는다. 같은 종류의 칩이 여러 개면 **역할 이름**으로 구분한다.

이번 파일은 아래 순서대로 한다.

```text
74HC161 PC 하위 4비트 카운터
        ↓
74HC161 PC 상위 4비트 카운터
        ↓
8비트 Program Counter 완성
        ↓
74HC273 메모리 주소 레지스터(MAR)
        ↓
74HC157 주소 선택 MUX 하위/상위
        ↓
8비트 ADDRESS BUS
        ↓
74HC138 RAM 뱅크 디코더
```

아직 RAM 자체는 연결하지 않는다.

---

# 2-1. Program Counter가 뭔가

Program Counter, 줄여서 PC는 **지금 실행할 명령어가 메모리 몇 번 주소에 있는지 기억하는 숫자**다.

이 컴퓨터는 8비트 주소를 쓰므로 0~255까지 셀 수 있어야 한다.

74HC161 하나는 4비트만 셀 수 있기 때문에 두 개를 사용한다.

- 74HC161 PC 하위 4비트 카운터 = PC0~PC3
- 74HC161 PC 상위 4비트 카운터 = PC4~PC7

---

# 2-2. 74HC161 PC 하위 4비트 카운터 단독 테스트

## 핀

```text
              홈
         ┌─────────┐
 /CLR  1 │         │16 VCC
 CLK   2 │ 74HC161 │15 RCO
 A     3 │         │14 QA
 B     4 │         │13 QB
 C     5 │         │12 QC
 D     6 │         │11 QD
 ENP   7 │         │10 ENT
 GND   8 │         │9 /LOAD
         └─────────┘
```

## 지금 연결

1. 1번 `/CLR` → +5V → 🟦 파랑 계열 Reset 선이지만 지금은 +5V에 임시 고정
2. 2번 `CLK` → NE555 클럭 발생기 3번 핀 → 🟦 파랑
3. 3번 A → GND → 테스트용 임시 연결
4. 4번 B → GND
5. 5번 C → GND
6. 6번 D → GND
7. 7번 ENP → +5V → 🟥 빨강
8. 8번 GND → GND → ⬛ 검정
9. 9번 `/LOAD` → +5V → 테스트용 임시 연결
10. 10번 ENT → +5V → 테스트용 임시 연결
11. 14번 QA → LED+저항
12. 13번 QB → LED+저항
13. 12번 QC → LED+저항
14. 11번 QD → LED+저항
15. 16번 VCC → +5V → 🟥 빨강
16. 16번과 8번 가까이에 0.1µF 세라믹 커패시터

15번 RCO는 지금은 연결하지 않는다.

## 테스트

Clock을 느리게 한다.

LED가 아래처럼 증가하면 정상이다.

```text
0000
0001
0010
0011
0100
...
1111
0000
```

Reset 테스트는 1번 `/CLR`을 잠깐 GND로 내렸다가 다시 +5V로 올린다. 출력이 0000이 되면 정상이다.

---

# 2-3. 74HC161 PC 상위 4비트 카운터 추가

두 번째 74HC161을 꽂는다.

## 지금 연결

1. 74HC161 PC 상위 4비트 카운터 1번 `/CLR` → +5V
2. 2번 `CLK` → NE555 클럭 발생기 3번 핀
3. 3~6번 A~D → GND 임시 연결
4. 7번 ENP → +5V
5. 8번 GND → GND
6. 9번 `/LOAD` → +5V
7. 10번 ENT ← 74HC161 PC 하위 4비트 카운터 15번 RCO
8. 16번 VCC → +5V
9. 14/13/12/11번 QA/QB/QC/QD → LED+저항

그리고 **74HC161 PC 하위 4비트 카운터 10번 ENT는 계속 +5V**다.

두 카운터의 2번 Clock은 같은 NE555 Clock을 받는다.

## 테스트

8개 LED를 다음 순서로 본다.

```text
PC7 PC6 PC5 PC4 | PC3 PC2 PC1 PC0
```

특히 아래가 되어야 한다.

```text
00001110
00001111
00010000
00010001
```

15 다음에 16으로 정확히 넘어가면 8비트 Program Counter가 완성된 것이다.

---

# 2-4. 메모리 주소 레지스터(MAR)가 뭔가

MAR는 Memory Address Register의 약자다.

쉽게 말하면 **나중에 RAM에서 읽거나 쓸 주소를 잠깐 기억하는 8비트 메모장**이다.

Program Counter와 MAR의 차이:

- Program Counter = 다음 명령어 주소
- MAR = LDA/STA/ADD/SUB/JMP 등이 사용할 목적지 주소

이번에는 74HC273 한 개를 사용한다.

---

# 2-5. 74HC273 메모리 주소 레지스터(MAR) 단독 테스트

## 핀 방향

```text
                 홈
            ┌───────────┐
 /CLR    1  │           │20 VCC
 Q0      2  │ 74HC273   │19 Q7
 D0      3  │           │18 D7
 D1      4  │           │17 D6
 Q1      5  │           │16 Q6
 Q2      6  │           │15 Q5
 D2      7  │           │14 D5
 D3      8  │           │13 D4
 Q3      9  │           │12 Q4
 GND    10  │           │11 CLK
            └───────────┘
```

## 지금 연결

1. 1번 `/CLR` → +5V
2. 10번 GND → GND
3. 20번 VCC → +5V
4. 20번과 10번 가까이에 0.1µF 커패시터
5. D 입력 8개는 아직 데이터 버스가 없으므로 임시 점퍼로 HIGH/LOW를 넣는다.

D 입력 핀:

- D0 = 3번
- D1 = 4번
- D2 = 7번
- D3 = 8번
- D4 = 13번
- D5 = 14번
- D6 = 17번
- D7 = 18번

Q 출력 핀:

- Q0 = 2번
- Q1 = 5번
- Q2 = 6번
- Q3 = 9번
- Q4 = 12번
- Q5 = 15번
- Q6 = 16번
- Q7 = 19번

11번 Clock에는 **수동으로 깨끗한 상승 펄스**를 한 번씩 넣어 테스트한다.

## 테스트 예시

1. `/CLR`을 잠깐 LOW로 해서 Q=00000000인지 확인한다.
2. D 입력을 `01010101`로 만든다.
3. 11번 Clock에 LOW→HIGH 한 번을 준다.
4. Q 출력이 `01010101`인지 확인한다.
5. D 입력을 `11110000`으로 바꾼다.
6. Clock을 주지 않았을 때 Q가 계속 `01010101`인지 확인한다.
7. Clock 한 번을 주면 Q가 `11110000`으로 바뀌는지 확인한다.

정상이면 MAR 저장 기능 완성이다.

---

# 2-6. Program Counter와 MAR의 최종 Load 연결

이제 MAR의 Q 출력 8개를 Program Counter의 병렬 입력 A~D에 연결한다. 이 연결은 점프할 때 `PC ← MAR`를 하기 위해 필요하다.

## 하위 4비트

- 74HC273 메모리 주소 레지스터 2번 Q0 → 74HC161 PC 하위 4비트 카운터 3번 A → 🟨 노랑
- 5번 Q1 → 74HC161 PC 하위 4비트 카운터 4번 B
- 6번 Q2 → 74HC161 PC 하위 4비트 카운터 5번 C
- 9번 Q3 → 74HC161 PC 하위 4비트 카운터 6번 D

## 상위 4비트

- 74HC273 메모리 주소 레지스터 12번 Q4 → 74HC161 PC 상위 4비트 카운터 3번 A
- 15번 Q5 → 74HC161 PC 상위 4비트 카운터 4번 B
- 16번 Q6 → 74HC161 PC 상위 4비트 카운터 5번 C
- 19번 Q7 → 74HC161 PC 상위 4비트 카운터 6번 D

아직 자동 `/LOAD` 제어회로는 만들지 않았으므로 9번 `/LOAD`는 테스트할 때 수동으로 LOW를 준다.

---

# 2-7. Address MUX가 뭔가

MUX는 여러 입력 중 하나를 선택하는 전자 스위치다.

주소를 내보내는 장치가 두 개다.

```text
Program Counter ─┐
                 ├→ 주소 선택기 → ADDRESS A0~A7
MAR ─────────────┘
```

- Select=LOW → Program Counter 주소
- Select=HIGH → MAR 주소

74HC157 두 개를 사용한다.

---

# 2-8. 74HC157 주소 선택 MUX 하위칩 연결

이 칩은 A0~A3을 만든다.

1. 1번 S → 테스트용 점퍼. 처음에는 GND
2. 2번 1A ← 74HC161 PC 하위 4비트 카운터 14번 QA
3. 3번 1B ← 74HC273 메모리 주소 레지스터 2번 Q0
4. 4번 1Y = ADDRESS A0
5. 5번 2A ← PC 하위 카운터 13번 QB
6. 6번 2B ← MAR 5번 Q1
7. 7번 2Y = ADDRESS A1
8. 8번 → GND
9. 9번 3Y = ADDRESS A2
10. 10번 3B ← MAR 6번 Q2
11. 11번 3A ← PC 하위 카운터 12번 QC
12. 12번 4Y = ADDRESS A3
13. 13번 4B ← MAR 9번 Q3
14. 14번 4A ← PC 하위 카운터 11번 QD
15. 15번 `/G` → GND
16. 16번 → +5V

주소선 A0~A3은 🟨 노랑으로 만든다.

---

# 2-9. 74HC157 주소 선택 MUX 상위칩 연결

이 칩은 A4~A7을 만든다.

1. 1번 S → 하위 주소 선택기 1번 S와 같이 연결
2. 2번 1A ← 74HC161 PC 상위 4비트 카운터 14번 QA
3. 3번 1B ← MAR 12번 Q4
4. 4번 1Y = ADDRESS A4
5. 5번 2A ← PC 상위 카운터 13번 QB
6. 6번 2B ← MAR 15번 Q5
7. 7번 2Y = ADDRESS A5
8. 8번 → GND
9. 9번 3Y = ADDRESS A6
10. 10번 3B ← MAR 16번 Q6
11. 11번 3A ← PC 상위 카운터 12번 QC
12. 12번 4Y = ADDRESS A7
13. 13번 4B ← MAR 19번 Q7
14. 14번 4A ← PC 상위 카운터 11번 QD
15. 15번 `/G` → GND
16. 16번 → +5V

---

# 2-10. 주소 선택기 테스트

1. Program Counter를 `00001111`로 만든다.
2. MAR에는 `10100000`을 저장한다.
3. 두 주소 선택기의 1번 S를 GND에 연결한다.
4. ADDRESS A0~A7이 `00001111`인지 확인한다.
5. 1번 S를 +5V로 바꾼다.
6. ADDRESS A0~A7이 `10100000`으로 바뀌는지 확인한다.

정상이면 **하나의 ADDRESS BUS가 Program Counter와 MAR 사이에서 바뀌는 것**이다.

---

# 2-11. RAM Bank Decoder란

RAM은 32바이트짜리 칩 5개를 사용할 예정이다.

상위 주소 A7,A6,A5를 보고 어느 RAM을 선택할지 정해야 한다.

74HC138 RAM 뱅크 디코더가 이 역할을 한다.

```text
A7 A6 A5
000 → RAM #1
001 → RAM #2
010 → RAM #3
011 → RAM #4
100 → RAM #5
101 → I/O 영역
```

74HC138 출력은 **Active-Low**다. 선택된 출력만 LOW가 된다.

---

# 2-12. 74HC138 RAM 뱅크 디코더 연결

1. 1번 A ← 74HC157 주소 선택 MUX 상위칩 7번 = ADDRESS A5 → 🟨 노랑
2. 2번 B ← 주소 선택 MUX 상위칩 9번 = ADDRESS A6
3. 3번 C ← 주소 선택 MUX 상위칩 12번 = ADDRESS A7
4. 4번 `/G2A` → GND
5. 5번 `/G2B` → GND
6. 6번 `G1` → +5V
7. 8번 → GND
8. 16번 → +5V

출력은 지금 LED로만 테스트한다.

- 15번 Y0 = RAM #1 선택
- 14번 Y1 = RAM #2 선택
- 13번 Y2 = RAM #3 선택
- 12번 Y3 = RAM #4 선택
- 11번 Y4 = RAM #5 선택
- 10번 Y5 = 나중에 I/O 영역

Active-Low LED는:

```text
+5V → 1kΩ → LED → 74HC138 출력
```

으로 연결한다.

---

# 2-13. RAM 뱅크 디코더 테스트

ADDRESS A7 A6 A5를 바꾸며 확인한다.

| A7 A6 A5 | LOW가 되어야 하는 핀 |
|---|---|
| 000 | 15번 Y0 |
| 001 | 14번 Y1 |
| 010 | 13번 Y2 |
| 011 | 12번 Y3 |
| 100 | 11번 Y4 |
| 101 | 10번 Y5 |

예를 들어 `010`이면 **13번 Y2만 LOW**여야 한다.
