# 3단계 — U2/U3 8bit Program Counter

> **초보자 공통 규칙**
>
> - 전원을 끈 상태에서 배선한다.
> - IC 홈(노치)을 위로 두고 핀 번호를 확인한다.
> - 모든 IC는 +5V, 모든 GND는 공통이다.
> - 각 IC의 VCC-GND 바로 옆에 0.1µF 세라믹 커패시터를 하나 단다.
> - LED 테스트에는 반드시 330Ω~1kΩ 직렬 저항을 사용한다.
> - 사용하지 않는 74HC 입력은 떠 있게 두지 않는다.
> - 한 단계가 정상 동작한 뒤에만 다음 단계로 넘어간다.

## 이번 단계 목표

두 개의 74HC161을 이어 0~255까지 세는 8bit PC를 만든다.

## 왜 이 부품이 필요한가

PC는 현재 실행할 명령어의 주소를 기억한다. U2가 하위 4bit, U3가 상위 4bit다.

## 점퍼선 색 규칙

| 색 | 의미 |
|---|---|
| 🟥 빨강 | +5V 전원 |
| ⬛ 검정 | GND |
| 🟩 초록 | DATA |
| 🟨 노랑 | ADDRESS |
| 🟦 파랑 | CLOCK / RESET |
| 🟧 주황 | CONTROL |
| ⬜ 흰색 | STATUS / FLAG / SPECIAL |

## 실제 핀 배선

아래 핀 번호는 최종 `컴퓨터만들기.md`와 동일하다. **한 줄씩 연결하고 체크 표시하면서 진행**한다.

## U2 — 74HC161
**8bit PC 하위 4bit, PC0~PC3**

1. 🟦 **파랑** — RESET_N
2. 🟦 **파랑** — CPU_CLK ← U28-3
3. 🟨 **노랑** — A ← U16-2
4. 🟨 **노랑** — B ← U16-5
5. 🟨 **노랑** — C ← U16-6
6. 🟨 **노랑** — D ← U16-9
7. 🟥 **빨강** — ENP → +5V
8. ⬛ **검정** — GND
9. 🟧 **주황** — /LOAD ← U41-3
10. 🟧 **주황** — ENT ← U39-8
11. 🟨 **노랑** — QD = PC3 → U21-14, U60-7
12. 🟨 **노랑** — QC = PC2 → U21-11, U60-8
13. 🟨 **노랑** — QB = PC1 → U21-5, U60-9
14. 🟨 **노랑** — QA = PC0 → U21-2, U60-10
15. 🟧 **주황** — RCO → U3-10
16. 🟥 **빨강** — +5V

## U3 — 74HC161
**8bit PC 상위 4bit, PC4~PC7**

1. 🟦 **파랑** — RESET_N
2. 🟦 **파랑** — CPU_CLK ← U28-3
3. 🟨 **노랑** — A ← U16-12
4. 🟨 **노랑** — B ← U16-15
5. 🟨 **노랑** — C ← U16-16
6. 🟨 **노랑** — D ← U16-19
7. 🟥 **빨강** — ENP → +5V
8. ⬛ **검정** — GND
9. 🟧 **주황** — /LOAD ← U41-3
10. 🟧 **주황** — ENT ← U2-15
11. 🟨 **노랑** — QD = PC7 → U22-14, U60-3
12. 🟨 **노랑** — QC = PC6 → U22-11, U60-4
13. 🟨 **노랑** — QB = PC5 → U22-5, U60-5
14. 🟨 **노랑** — QA = PC4 → U22-2, U60-6
15. — **배선 없음** — RCO → 미사용
16. 🟥 **빨강** — +5V

## 테스트 방법

처음에는 최종 제어회로 대신 테스트용으로 /LOAD를 HIGH, Count Enable을 HIGH가 되게 만든 뒤 Clock을 넣는다.

1. U2의 QA/QB/QC/QD와 U3의 QA/QB/QC/QD에 각각 LED+저항을 임시로 단다.
2. Clock을 아주 느리게 한다.
3. 00000000 → 00000001 → 00000010 순서로 증가하는지 본다.
4. 특히 00001111 다음에 00010000이 되는지 확인한다.
5. RESET_N을 잠깐 LOW로 내려 00000000이 되는지 확인한다.

## 정상이라면

1씩 정확히 증가하고 15→16 rollover가 정확하다. RESET하면 0이 된다.

## 안 되면 여기부터 확인

두 칩 모두 같은 Clock을 받아야 한다. U2-15(RCO)→U3-10(ENT)을 확인한다. Clock 선이 떠 있거나 너무 길면 2씩 증가할 수 있다.

- [ ] 테스트 결과 정상

# 4단계 — U16 MAR

> **초보자 공통 규칙**
>
> - 전원을 끈 상태에서 배선한다.
> - IC 홈(노치)을 위로 두고 핀 번호를 확인한다.
> - 모든 IC는 +5V, 모든 GND는 공통이다.
> - 각 IC의 VCC-GND 바로 옆에 0.1µF 세라믹 커패시터를 하나 단다.
> - LED 테스트에는 반드시 330Ω~1kΩ 직렬 저항을 사용한다.
> - 사용하지 않는 74HC 입력은 떠 있게 두지 않는다.
> - 한 단계가 정상 동작한 뒤에만 다음 단계로 넘어간다.

## 이번 단계 목표

DATA BUS에서 받은 8bit 주소를 저장하고 계속 유지하는 MAR를 만든다.

## 왜 이 부품이 필요한가

MAR는 LDA/STA/ADD/SUB/JMP 등이 사용할 “목적지 주소”를 잠깐 기억한다.

## 점퍼선 색 규칙

| 색 | 의미 |
|---|---|
| 🟥 빨강 | +5V 전원 |
| ⬛ 검정 | GND |
| 🟩 초록 | DATA |
| 🟨 노랑 | ADDRESS |
| 🟦 파랑 | CLOCK / RESET |
| 🟧 주황 | CONTROL |
| ⬜ 흰색 | STATUS / FLAG / SPECIAL |

## 실제 핀 배선

## U16 — 74HC273
**MAR**

1. 🟦 **파랑** — RESET_N
2. 🟨 **노랑** — Q0 → U21-3, U2-3
3. 🟩 **초록** — D0 ← DB0
4. 🟩 **초록** — D1 ← DB1
5. 🟨 **노랑** — Q1 → U21-6, U2-4
6. 🟨 **노랑** — Q2 → U21-10, U2-5
7. 🟩 **초록** — D2 ← DB2
8. 🟩 **초록** — D3 ← DB3
9. 🟨 **노랑** — Q3 → U21-13, U2-6
10. ⬛ **검정** — GND
11. 🟦 **파랑** — CLK ← U29-6
12. 🟨 **노랑** — Q4 → U22-3, U3-3
13. 🟩 **초록** — D4 ← DB4
14. 🟩 **초록** — D5 ← DB5
15. 🟨 **노랑** — Q5 → U22-6, U3-4
16. 🟨 **노랑** — Q6 → U22-10, U3-5
17. 🟩 **초록** — D6 ← DB6
18. 🟩 **초록** — D7 ← DB7
19. 🟨 **노랑** — Q7 → U22-13, U3-6
20. 🟥 **빨강** — +5V

## 테스트 방법

최종 DATA BUS가 아직 없다면 U16의 D0~D7에 임시 스위치/점퍼로 0과 1을 넣는다.

1. RESET_N을 LOW로 했다가 HIGH로 한다. Q0~Q7이 0인지 본다.
2. D0~D7에 예를 들어 01010101을 만든다.
3. U16-11에 한 번의 깨끗한 상승 Clock pulse를 준다.
4. Q 출력이 01010101로 저장되는지 확인한다.
5. D 입력을 바꿔도 Clock을 주지 않으면 Q가 그대로인지 확인한다.

## 정상이라면

Clock 상승 순간에만 값이 바뀌고, 이후 입력을 바꿔도 저장값이 유지된다.

## 안 되면 여기부터 확인

U16-11 Clock이 떠 있지 않은지, U16-1 RESET_N이 정상 HIGH인지, D/Q 핀 번호가 뒤바뀌지 않았는지 확인한다.

# 5단계 — U21/U22 Address MUX

## 이번 단계 목표
PC 주소와 MAR 주소 중 하나를 선택해 ADDRESS BUS A0~A7로 내보낸다.

## U21 — 74HC157
**PC/MAR 하위 Address MUX**

1. 🟧 **주황** — S ← U47-8
2. 🟨 **노랑** — 1A ← U2-14
3. 🟨 **노랑** — 1B ← U16-2
4. 🟨 **노랑** — 1Y → A0
5. 🟨 **노랑** — 2A ← U2-13
6. 🟨 **노랑** — 2B ← U16-5
7. 🟨 **노랑** — 2Y → A1
8. ⬛ **검정** — GND
9. 🟨 **노랑** — 3Y → A2
10. 🟨 **노랑** — 3B ← U16-6
11. 🟨 **노랑** — 3A ← U2-12
12. 🟨 **노랑** — 4Y → A3
13. 🟨 **노랑** — 4B ← U16-9
14. 🟨 **노랑** — 4A ← U2-11
15. ⬛ **검정** — /G → GND
16. 🟥 **빨강** — +5V

## U22 — 74HC157
**PC/MAR 상위 Address MUX**

1. 🟧 **주황** — S ← U47-8
2. 🟨 **노랑** — 1A ← U3-14
3. 🟨 **노랑** — 1B ← U16-12
4. 🟨 **노랑** — 1Y → A4
5. 🟨 **노랑** — 2A ← U3-13
6. 🟨 **노랑** — 2B ← U16-15
7. 🟨 **노랑** — 2Y → A5
8. ⬛ **검정** — GND
9. 🟨 **노랑** — 3Y → A6
10. 🟨 **노랑** — 3B ← U16-16
11. 🟨 **노랑** — 3A ← U3-12
12. 🟨 **노랑** — 4Y → A7
13. 🟨 **노랑** — 4B ← U16-19
14. 🟨 **노랑** — 4A ← U3-11
15. ⬛ **검정** — /G → GND
16. 🟥 **빨강** — +5V

## 테스트 방법

1. PC에 눈에 띄는 값(예: 00001111)을 만든다.
2. MAR에는 다른 값(예: 10100000)을 저장한다.
3. U21/U22의 Select를 PC 쪽으로 놓고 A0~A7을 확인한다.
4. Select를 MAR 쪽으로 바꾼다.
5. A0~A7이 MAR 값으로 바뀌는지 본다.

## 정상이라면
Select 한 가닥을 바꾸는 것만으로 ADDRESS BUS가 PC 값과 MAR 값 사이에서 정확히 전환된다.

# 6단계 — U26 RAM Bank Decoder

## U26 — 74HC138
**RAM Bank Decoder**

1. 🟨 **노랑** — A ← U22-7(A5)
2. 🟨 **노랑** — B ← U22-9(A6)
3. 🟨 **노랑** — C ← U22-12(A7)
4. ⬛ **검정** — /G2A → GND
5. ⬛ **검정** — /G2B → GND
6. 🟥 **빨강** — G1 → +5V
7. 🟧 **주황** — Y7 → U34-2
8. ⬛ **검정** — GND
9. 🟧 **주황** — Y6 → U33-13
10. 🟧 **주황** — Y5 → U33-12, U50-4
11. 🟧 **주황** — Y4 → U9-15
12. 🟧 **주황** — Y3 → U8-15
13. 🟧 **주황** — Y2 → U7-15
14. 🟧 **주황** — Y1 → U6-15
15. 🟧 **주황** — Y0 → U5-15
16. 🟥 **빨강** — +5V

## 테스트 방법
LED는 Active-Low 확인이 쉽도록 `+5V → 1kΩ → LED → Y핀`으로 단다.

- MAR=0 → Y0만 선택
- MAR=32 → Y1
- MAR=64 → Y2
- MAR=96 → Y3
- MAR=128 → Y4

한 순간에 두 LED가 선택되면 다음 단계로 가지 않는다.
