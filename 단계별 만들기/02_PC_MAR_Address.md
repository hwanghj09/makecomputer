# 2단계 — Program Counter → MAR → 주소 선택기 → RAM 뱅크 디코더

이 파일에서는 아래 순서대로 하나씩 만든다.

```text
74HC161 PC 하위 4비트 카운터
↓
74HC161 PC 상위 4비트 카운터
↓
8비트 Program Counter
↓
74HC273 메모리 주소 레지스터(MAR)
↓
74HC157 주소 선택 MUX 2개
↓
8비트 ADDRESS BUS
↓
74HC138 RAM 뱅크 디코더
```

아직 RAM 자체는 연결하지 않는다.

## 점퍼선 색

- 🟥 빨강 = +5V / 테스트용 HIGH
- ⬛ 검정 = GND / 테스트용 LOW
- 🟩 초록 = DATA
- 🟨 노랑 = ADDRESS
- 🟦 파랑 = CLOCK / RESET
- 🟧 주황 = CONTROL
- ⬜ 흰색 = STATUS / SPECIAL

---

# 2-1. 74HC161 PC 하위 4비트 카운터

Program Counter는 **다음에 실행할 명령어 주소**를 기억한다.
먼저 4비트만 단독 테스트한다.

```text
              홈
         ┌─────────┐
 /CLR  1 │         │16 VCC
 CLK   2 │ 74HC161 │15 RCO
 A     3 │         │14 QA
 B     4 │         │13 QB
 C     5 │         │12 QC
 D     6 │         │11 QD
 ENP   7 │         │10 ENT
 GND   8 │         │9 /LOAD
         └─────────┘
```

## 지금 연결

1. 🟦 **파랑** — 1번 `/CLR` → +5V에 임시 고정. Reset 시험 때만 잠깐 GND
2. 🟦 **파랑** — 2번 `CLK` ← NE555 클럭 발생기 3번 핀
3. ⬛ **검정** — 3번 `A` → GND 임시 고정
4. ⬛ **검정** — 4번 `B` → GND 임시 고정
5. ⬛ **검정** — 5번 `C` → GND 임시 고정
6. ⬛ **검정** — 6번 `D` → GND 임시 고정
7. 🟥 **빨강** — 7번 `ENP` → +5V
8. ⬛ **검정** — 8번 `GND` → GND
9. 🟥 **빨강** — 9번 `/LOAD` → +5V 임시 고정
10. 🟥 **빨강** — 10번 `ENT` → +5V 임시 고정
11. 🟨 **노랑** — 14번 `QA(PC0)` → LED+저항 임시 테스트점
12. 🟨 **노랑** — 13번 `QB(PC1)` → LED+저항 임시 테스트점
13. 🟨 **노랑** — 12번 `QC(PC2)` → LED+저항 임시 테스트점
14. 🟨 **노랑** — 11번 `QD(PC3)` → LED+저항 임시 테스트점
15. — **배선 없음** — 15번 `RCO`는 아직 연결하지 않음
16. 🟥 **빨강** — 16번 `VCC` → +5V
17. 🟥/⬛ — 0.1µF: 16번 VCC 쪽 🟥 빨강, 8번 GND 쪽 ⬛ 검정

### 테스트

Clock을 아주 느리게 해서 `0000 → 0001 → 0010 ... → 1111 → 0000`이 되는지 본다.
1번 `/CLR`를 잠깐 GND로 내리면 0000으로 돌아가야 한다.

# 2-2. 74HC161 PC 상위 4비트 카운터 추가

두 번째 74HC161을 꽂는다.

## 지금 연결

1. 🟦 **파랑** — 상위 카운터 1번 `/CLR` → 하위 카운터 1번 `/CLR`와 같은 Reset 선
2. 🟦 **파랑** — 상위 카운터 2번 `CLK` ← NE555 클럭 발생기 3번 핀
3. ⬛ **검정** — 상위 카운터 3번 `A` → GND 임시
4. ⬛ **검정** — 상위 카운터 4번 `B` → GND 임시
5. ⬛ **검정** — 상위 카운터 5번 `C` → GND 임시
6. ⬛ **검정** — 상위 카운터 6번 `D` → GND 임시
7. 🟥 **빨강** — 상위 카운터 7번 `ENP` → +5V
8. ⬛ **검정** — 상위 카운터 8번 `GND` → GND
9. 🟥 **빨강** — 상위 카운터 9번 `/LOAD` → +5V 임시
10. 🟧 **주황** — 하위 카운터 15번 `RCO` → 상위 카운터 10번 `ENT`
11. 🟨 **노랑** — 상위 카운터 14번 `QA(PC4)` → LED+저항
12. 🟨 **노랑** — 상위 카운터 13번 `QB(PC5)` → LED+저항
13. 🟨 **노랑** — 상위 카운터 12번 `QC(PC6)` → LED+저항
14. 🟨 **노랑** — 상위 카운터 11번 `QD(PC7)` → LED+저항
15. — **배선 없음** — 상위 카운터 15번 `RCO`
16. 🟥 **빨강** — 상위 카운터 16번 `VCC` → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

하위 카운터 10번 ENT는 계속 +5V다.

### 테스트

특히 아래 전환이 정확해야 한다.

```text
00001110
00001111
00010000
00010001
```

# 2-3. 74HC273 메모리 주소 레지스터(MAR)

MAR는 나중에 RAM에서 읽거나 쓸 **목적지 주소를 잠깐 기억하는 8비트 레지스터**다.

```text
                 홈
            ┌───────────┐
 /CLR    1  │           │20 VCC
 Q0      2  │ 74HC273   │19 Q7
 D0      3  │           │18 D7
 D1      4  │           │17 D6
 Q1      5  │           │16 Q6
 Q2      6  │           │15 Q5
 D2      7  │           │14 D5
 D3      8  │           │13 D4
 Q3      9  │           │12 Q4
 GND    10  │           │11 CLK
            └───────────┘
```

## 단독 테스트용 연결

1. 🟦 **파랑** — 1번 `/CLR` → +5V. Reset할 때만 잠깐 GND
2. ⬛ **검정** — 10번 `GND` → GND
3. 🟥 **빨강** — 20번 `VCC` → +5V
4. 🟦 **파랑** — 11번 `CLK` → 수동 Clock pulse 테스트선
5. 🟩 **초록** — 3번 `D0` → 테스트용 0/1 입력
6. 🟩 **초록** — 4번 `D1` → 테스트용 0/1 입력
7. 🟩 **초록** — 7번 `D2` → 테스트용 0/1 입력
8. 🟩 **초록** — 8번 `D3` → 테스트용 0/1 입력
9. 🟩 **초록** — 13번 `D4` → 테스트용 0/1 입력
10. 🟩 **초록** — 14번 `D5` → 테스트용 0/1 입력
11. 🟩 **초록** — 17번 `D6` → 테스트용 0/1 입력
12. 🟩 **초록** — 18번 `D7` → 테스트용 0/1 입력
13. 🟨 **노랑** — 2번 `Q0` → LED 테스트점
14. 🟨 **노랑** — 5번 `Q1` → LED 테스트점
15. 🟨 **노랑** — 6번 `Q2` → LED 테스트점
16. 🟨 **노랑** — 9번 `Q3` → LED 테스트점
17. 🟨 **노랑** — 12번 `Q4` → LED 테스트점
18. 🟨 **노랑** — 15번 `Q5` → LED 테스트점
19. 🟨 **노랑** — 16번 `Q6` → LED 테스트점
20. 🟨 **노랑** — 19번 `Q7` → LED 테스트점
21. 🟥/⬛ — 0.1µF: 20번 쪽 🟥, 10번 쪽 ⬛

### 테스트

D0~D7에 예를 들어 `01010101`을 만든 뒤 11번에 한 번의 상승 Clock을 준다.
Q0~Q7에 같은 값이 저장되고, D 입력을 바꿔도 다음 Clock 전까지 Q가 유지되면 정상이다.

> 3,4,7,8,13,14,17,18번 D 입력은 3단계에서 DATA BUS에 연결한다. 지금은 테스트용 초록 점퍼만 사용한다.

# 2-4. 74HC157 주소 선택 MUX 2개

이제 PC 주소와 MAR 주소 중 하나를 고르는 스위치를 만든다.

`Select=LOW`이면 PC, `Select=HIGH`이면 MAR를 선택한다.

## 74HC157 주소 선택 MUX 하위칩

1. 🟧 **주황** — 1번 `S` → 테스트용 Select 점퍼
2. 🟨 **노랑** — 2번 `1A` ← PC 하위 카운터 14번 `PC0`
3. 🟨 **노랑** — 3번 `1B` ← MAR 2번 `Q0`
4. 🟨 **노랑** — 4번 `1Y` → ADDRESS `A0`
5. 🟨 **노랑** — 5번 `2A` ← PC 하위 카운터 13번 `PC1`
6. 🟨 **노랑** — 6번 `2B` ← MAR 5번 `Q1`
7. 🟨 **노랑** — 7번 `2Y` → ADDRESS `A1`
8. ⬛ **검정** — 8번 GND → GND
9. 🟨 **노랑** — 9번 `3Y` → ADDRESS `A2`
10. 🟨 **노랑** — 10번 `3B` ← MAR 6번 `Q2`
11. 🟨 **노랑** — 11번 `3A` ← PC 하위 카운터 12번 `PC2`
12. 🟨 **노랑** — 12번 `4Y` → ADDRESS `A3`
13. 🟨 **노랑** — 13번 `4B` ← MAR 9번 `Q3`
14. 🟨 **노랑** — 14번 `4A` ← PC 하위 카운터 11번 `PC3`
15. ⬛ **검정** — 15번 `/G` → GND
16. 🟥 **빨강** — 16번 VCC → +5V

## 74HC157 주소 선택 MUX 상위칩

1. 🟧 **주황** — 1번 `S` → 하위 MUX 1번과 같은 Select 점퍼
2. 🟨 **노랑** — 2번 `1A` ← PC 상위 카운터 14번 `PC4`
3. 🟨 **노랑** — 3번 `1B` ← MAR 12번 `Q4`
4. 🟨 **노랑** — 4번 `1Y` → ADDRESS `A4`
5. 🟨 **노랑** — 5번 `2A` ← PC 상위 카운터 13번 `PC5`
6. 🟨 **노랑** — 6번 `2B` ← MAR 15번 `Q5`
7. 🟨 **노랑** — 7번 `2Y` → ADDRESS `A5`
8. ⬛ **검정** — 8번 GND → GND
9. 🟨 **노랑** — 9번 `3Y` → ADDRESS `A6`
10. 🟨 **노랑** — 10번 `3B` ← MAR 16번 `Q6`
11. 🟨 **노랑** — 11번 `3A` ← PC 상위 카운터 12번 `PC6`
12. 🟨 **노랑** — 12번 `4Y` → ADDRESS `A7`
13. 🟨 **노랑** — 13번 `4B` ← MAR 19번 `Q7`
14. 🟨 **노랑** — 14번 `4A` ← PC 상위 카운터 11번 `PC7`
15. ⬛ **검정** — 15번 `/G` → GND
16. 🟥 **빨강** — 16번 VCC → +5V

두 MUX 모두 0.1µF를 VCC-GND 사이에 단다: VCC 쪽 🟥, GND 쪽 ⬛.

### 테스트

PC와 MAR에 서로 다른 값을 만든다.

- 🟧 Select를 ⬛ GND(LOW)에 임시 연결 → A0~A7이 PC 값
- 🟧 Select를 🟥 +5V(HIGH)에 임시 연결 → A0~A7이 MAR 값

# 2-5. 74HC138 RAM 뱅크 디코더

상위 주소 A7~A5를 보고 RAM #1~#5 중 하나를 고르는 칩이다.
출력은 **Active-Low**, 즉 선택된 출력만 LOW가 된다.

1. 🟨 **노랑** — 1번 `A` ← 주소 선택 MUX 상위칩 7번 `A5`
2. 🟨 **노랑** — 2번 `B` ← 주소 선택 MUX 상위칩 9번 `A6`
3. 🟨 **노랑** — 3번 `C` ← 주소 선택 MUX 상위칩 12번 `A7`
4. ⬛ **검정** — 4번 `/G2A` → GND
5. ⬛ **검정** — 5번 `/G2B` → GND
6. 🟥 **빨강** — 6번 `G1` → +5V
7. 🟧 **주황** — 7번 `Y7` → 지금은 LED 테스트점
8. ⬛ **검정** — 8번 GND → GND
9. 🟧 **주황** — 9번 `Y6` → 지금은 LED 테스트점
10. 🟧 **주황** — 10번 `Y5` → 지금은 LED 테스트점
11. 🟧 **주황** — 11번 `Y4` → 나중에 RAM #5 CS
12. 🟧 **주황** — 12번 `Y3` → 나중에 RAM #4 CS
13. 🟧 **주황** — 13번 `Y2` → 나중에 RAM #3 CS
14. 🟧 **주황** — 14번 `Y1` → 나중에 RAM #2 CS
15. 🟧 **주황** — 15번 `Y0` → 나중에 RAM #1 CS
16. 🟥 **빨강** — 16번 VCC → +5V
17. 🟥/⬛ — 0.1µF: VCC 쪽 🟥, GND 쪽 ⬛

### LED 테스트 연결

각 Y출력은 다음 방식으로 본다.

```text
+5V ─ 🟥 ─ 1kΩ ─ LED ─ 🟧 ─ Y출력
```

MAR를 주소원으로 선택한 뒤 다음을 확인한다.

- 주소 0 → Y0만 LOW
- 주소 32 → Y1만 LOW
- 주소 64 → Y2만 LOW
- 주소 96 → Y3만 LOW
- 주소 128 → Y4만 LOW

한 순간에 두 출력이 선택되면 다음 단계로 가지 않는다.
