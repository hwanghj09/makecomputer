# 26단계 — 전체 통합 최종 테스트

> 지금까지 **각각 통과한 모듈만** 하나씩 합친다. 문제가 생기면 전체를 뜯지 말고 마지막으로 추가한 모듈부터 분리해서 본다.

## 통합 순서

1. Clock + PC + MAR + Address MUX
2. RAM Bank Decoder + RAM #1
3. U18 DATA BUS
4. Manual Input + A Register
5. ALU + A/ALU BUS
6. IR + Opcode Decoder
7. Microstep
8. Control Logic
9. Z/MONITOR/HALT
10. Boot ROM
11. I/O Decoder + LCD
12. PS/2 Keyboard

## DATA BUS 충돌 체크

한 순간에 DATA BUS를 구동하는 장치는 원칙적으로 하나다.

| 동작 | BUS Driver |
|---|---|
| Monitor Fetch | U61만 ON |
| RAM Fetch/LDA | U18만 ON |
| ADD/SUB 결과 | U19만 ON |
| CMP | BUS Driver 모두 OFF |
| Keyboard LDA | U59만 ON |
| STA RAM | U19가 BUS 구동 + U18은 BUS→RAM 방향 |

## 첫 CPU 프로그램 테스트

처음부터 키보드/LCD까지 시험하지 말고 가장 작은 프로그램부터 시작한다.

```text
LDI 5
OUT
HLT
```

확인할 것:

1. T1에서 IR이 LDI를 읽는가
2. T3에서 A=5가 되는가
3. OUT의 T5에서 U17=5가 되는가
4. HLT 후 CPU Clock이 더 이상 전달되지 않는가
5. RESET으로 다시 실행되는가

그 다음 순서:

1. LDA / STA
2. ADD / SUB
3. JMP
4. CMP
5. JZ / JNZ
6. RUN
7. Boot ROM
8. LCD
9. PS/2 Keyboard

## 문제가 생기면

전체 배선을 한 번에 의심하지 않는다.

```text
방금 추가한 모듈 제거
↓
이전 상태가 정상인지 확인
↓
추가한 모듈만 독립 테스트
↓
다시 연결
```

이 방식으로 진행하면 수십 개 IC가 있어도 문제 위치를 찾을 수 있다.
