# MAKECOMPUTER/8 단계별 만들기 — 시작하기

이 폴더는 `컴퓨터만들기.md`의 최종 배선을 **초보자가 실제로 한 단계씩 만들고 테스트할 수 있게** 다시 나눈 설명서다.

> **초보자 공통 규칙**
>
> - 전원을 끈 상태에서 배선한다.
> - IC 홈(노치)을 위로 두고 핀 번호를 확인한다.
> - 모든 IC는 +5V, 모든 GND는 공통이다.
> - 각 IC의 VCC-GND 바로 옆에 0.1µF 세라믹 커패시터를 하나 단다.
> - LED 테스트에는 반드시 330Ω~1kΩ 직렬 저항을 사용한다.
> - 사용하지 않는 74HC 입력은 떠 있게 두지 않는다.
> - 한 단계가 정상 동작한 뒤에만 다음 단계로 넘어간다.

## 이 폴더를 쓰는 방법

1. 반드시 번호 순서대로 진행한다.
2. 각 문서의 **실제 핀 배선**을 한 줄씩 연결한다.
3. 바로 아래 **테스트 방법**으로 그 단계만 따로 확인한다.
4. 정상일 때만 다음 파일로 넘어간다.
5. 문제가 있으면 다음 단계를 만들지 말고 현재 단계에서 멈춘다.
