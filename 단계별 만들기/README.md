# MAKECOMPUTER/8 단계별 만들기

이 폴더는 `컴퓨터만들기.md`의 최종 배선표를 **처음 만드는 사람도 그대로 따라갈 수 있는 실제 제작 순서**로 다시 설명한 초보자용 설명서다.

## 가장 중요한 이름 규칙

이 폴더에서는 `U1`, `U2`, `U18` 같은 칩 번호 별칭을 쓰지 않는다.
항상 **부품명 + 역할 + 실제 핀 번호**로 쓴다.

예:

```text
74HC161 PC 하위 4비트 카운터 14번 핀(QA)
→ 74HC157 주소 선택 MUX 하위칩 2번 핀(1A)
```

## 가장 중요한 점퍼선 색 규칙

이 폴더에서는 **실제로 꽂는 점퍼선마다 색을 정확히 적는다.**
배선 줄 앞에 적힌 색의 점퍼선을 그대로 사용한다.

| 색 | 실제 용도 |
|---|---|
| 🟥 **빨강** | +5V 전원, 테스트용 HIGH 고정 |
| ⬛ **검정** | GND, 테스트용 LOW 고정 |
| 🟩 **초록** | DATA 비트가 이동하는 선 |
| 🟨 **노랑** | ADDRESS 비트가 이동하는 선 |
| 🟦 **파랑** | CLOCK / RESET / CLEAR |
| 🟧 **주황** | CONTROL: Enable, Select, Read, Write, Load, Decoder 출력 |
| ⬜ **흰색** | STATUS / FLAG / SPECIAL: Z, KEY_READY, HALT, MONITOR_MODE 등 |

### 읽는 예

```text
🟨 노랑 — 74HC161 PC 하위 4비트 카운터 14번 핀(QA)
          → 74HC157 주소 선택 MUX 하위칩 2번 핀(1A)
```

이렇게 적혀 있으면 **두 핀 사이를 노란 점퍼선으로 연결**한다.

```text
🟥 빨강 — 16번 VCC → +5V
⬛ 검정 — 8번 GND → GND
🟦 파랑 — 2번 CLK → Clock
— 배선 없음 — 사용하지 않는 출력
```

`배선 없음`은 점퍼선을 꽂지 않는다는 뜻이다.

### 테스트용 임시 점퍼선도 같은 규칙을 쓴다

- 임시로 +5V에 고정 → 🟥 빨강
- 임시로 GND에 고정 → ⬛ 검정
- 직접 Clock pulse를 넣음 → 🟦 파랑
- 직접 Reset/Clear pulse를 넣음 → 🟦 파랑
- 테스트용 데이터 0/1 입력 → 🟩 초록
- 테스트용 주소 0/1 입력 → 🟨 노랑

## 제작 원칙

1. 처음 나오는 용어는 연결 전에 뜻부터 설명한다.
2. 아직 만들지 않은 회로는 미리 연결하지 않는다.
3. 한 번에 한 부품 또는 한 기능만 만든다.
4. 단독 테스트를 통과한 뒤 앞 단계와 연결한다.
5. 문제가 생기면 마지막으로 추가한 부분만 확인한다.
6. 각 IC에는 0.1µF 디커플링 커패시터를 VCC-GND 바로 옆에 단다.
7. 0.1µF 커패시터의 VCC 쪽 연결은 🟥 빨강, GND 쪽 연결은 ⬛ 검정으로 본다.
